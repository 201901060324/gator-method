# 鳄鱼派方法论 · 结构化提炼

把一个 A 股复盘博主（公众号「像鳄鱼一样思考」/「获得信息差」，B 站同名）**四年公开内容**，
从 700+ 篇文章、80 场直播、5 篇体系长文里，提炼成一套**可计算、可检索的判断规则体系**。

这不是原文合集，也不是投资建议。这是一份**关于"一个人怎么做投资判断"的结构化笔记**。

---

## 这份东西是什么

博主每天写复盘，四年写了 700 多篇。他的判断散落在日复一日的流水里，经验有效但不成体系——
他自己在直播里也说过，很多东西是"凭感觉"。

这个项目做的事：

1. 把他四年的公开表达（文章、视频、直播）全量收集
2. 逐层提炼：世界观 → 决策流程 → 判断规则 → 语言风格
3. **把模糊的经验翻译成 `IF…THEN…` 规则，尽量带上数字阈值**
4. 拿真实行情回测，检验这套规则是不是真的成立

最终产物是 **48 章规则体系**（`03-规则体系.md`），其中带 `[可计算]` 标记的章节可以直接写成代码。

## 为什么值得看

- **有数字**。不是"量能不足要谨慎"，而是"`IF 微盘股跌 >= 3% AND 跌停家数 > 30 AND 上证跌 > 2% THEN 视为短期情绪冰点`"。
