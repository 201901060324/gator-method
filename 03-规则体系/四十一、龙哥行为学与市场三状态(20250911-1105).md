## 四十一、龙哥行为学与市场三状态（20250911/1105）`[核心]`

**A股三种大状态**：
| 状态 | 特征 | 应对 |
|---|---|---|
| 自由野马（无干预） | 情绪来了扶摇直上，退潮A杀 | 炒到癫狂须逃顶（十年难遇两次） |
| 蜗牛（强干预） | 指数慢涨、情绪低迷 | 打不过就加入，或等情绪好再做 |
| 遛狗（常态） | 斜率一高收绳子（砸银行保险降温），冷清扔骨头（拉金融/放利好） | 不激动、做波段 |

**龙哥大操作/微操作判别**（强化第十二章）：
```text
大操作：大时间节点，日K分时异常放量一眼可见（24年1月/24年7月/924前/25年4月/625）
微操作：
① IF 低开下杀时 上证50→沪深300→中证500ETF 先后放量 THEN 龙哥进场（"换着买避免被看出来"）
② IF 大跌日 银行/两桶油异常放量拉升 THEN 龙哥护盘（"大跌环境里买银行的傻户吗？"）
③ IF 证券出现"头上长草"的上影线 THEN 不是骗筹码，是"敲一笔买盘歇一歇"的机构建仓
④ 龙哥卖点：大金融大涨后第二/三天冲高回落出货——IF 大金融收约3个大阳线 THEN 次日跟着卖基本不出大问题【仅限大金融】
⑤ 证券买点=缩量横盘时；"稍微横盘几天就卖、再冲再买"是多数人玩证券亏钱的原因
砸银行不砸科技的原因：银行筹码在龙哥手里（控得住），科技筹码太自由
证券不能持续买："牛市旗手继续买那还不疯（指数）了？"
```

**情绪三维度**（机构大票/游资小票/龙哥龙票，"三股势力并不共振，各玩各的"）：
- 机构大票：融资余额趋势 + 沪深300成分股有无机构砍仓（分时台阶式出货=主动清仓；阶梯放量下杀=被动砍仓）
- 游资小票：中证2000、微盘、北证、涨停家数、高标妖股
- 龙哥龙票：工具银（四大行）、保险证券（换着用）、巨型中字头（三桶油/移动/电信/神华/长电）
```text
IF 机构过冷修复 AND 游资过热 THEN 分歧大，短期做好游资回落准备（游资"吃相比机构难看，吃干抹净就走"）
```

**市场热度四量表**（以15年末/924=100 分基准）：
| 维度 | 峰值读数 | 判读 |
|---|---|---|
| 两融占流通市值比 | 接近 6%（15年） | 2025.9 约 2.5% = 黄灯，远没到底 |
| 融资盘占成交量比 | 10.8=3万亿成交对1.5万亿融资 | 红灯——"要降这个红灯就得放量到3、4万亿" |
| 散户参与度（开户+搬家结构） | 15年大学生开户新高 | 本轮主要是大户搬家，散户信任未从21年抱团崩塌恢复 |
| 涨跌家数比 | 15年末 1000:1 癫狂 | 未癫狂 |
```text
IF 各维度均未达 100 分 THEN 大级别顶未到，"本轮牛市可能比大家想象中的要长一些"
```

**飞行员（空头）行为学**：
```text
IF 一两天维度 THEN 空 IM（博小票连炒几天的回落）；IF 几周维度 THEN 空 IF（博机构抱团瓦解/基民赎回，此时 IF 基差最难看）
IF 龙哥自己都在砸（大金融领跌） THEN 空头无顾忌（天时地利人和）；IF 龙哥在买你做空 THEN 找打
IF 基差拉大+空单激增 THEN 三种可能：纯做空/对冲/套利，不必惊慌；IF IM 基差反而缩小 THEN 真刀真枪的多空对决
"不是空头砸下来的，是空头看到大概率会下去才去做"
```

**市场制度体质观**：越是靠打针（护盘）活的市场越容易出问题；投资角度全球最好=美股，投机角度最好=A股+港股（"能把垃圾炒很高，也能把价值压很低"）。
