## 三十八、融资盘选股法与杠杆牛（20250710，强化 23.2/26.2 章）`[核心][可计算]`

```text
融资余额/流通市值 > 3% = 融资客扎堆（股性/杠杆资金喜爱度）
吃鱼头：IF 当日融资净买入占成交 5–15% AND 短期涨幅 <15% THEN 埋伏（融资数据次日早8:50更新，看的是昨日）
吃鱼身：IF 短期涨幅 15–30% AND 融资占比 >3% THEN 参与；涨幅>30% = 鱼尾（杠杆资金已赚60个点），危险
IF 融资买入占比过高（如 26%） THEN 危险——"全是狼没有羊"，稍微丢点肉狼就跑了
IF 融资余额连续下降 3–4 天 THEN 提高杠杆资金撤离警惕（偶尔 1–2 天减少不足以据此判定）
IF 大跌次日融资买入暴增（抢反弹票） THEN 不做——不顺势
```

**融资余额的两用读法（方向相反，勿混用）**：
```text
用法 A（撤离警报，本条既有）：连降 3–4 天 → 减仓/提高警惕
用法 B（上涨前置条件，2026-10-16）：**融资余额不转向，大涨就不会来**
  "融资余额五连跌，这一整周都是在杀杠杆……要出现大涨，杠杆哥的贡献必不可少"
  → 即：融资余额是"能否进入加速段"的**必要条件**，不是充分条件
用法 C（右侧信号之一，2026-10-19）：**连增**才计数，单日回升不算（见 1.5 的 2026 版清单）
```
- 三种用法共用同一个读数，但**方向不同**：连降=防守，连增=进攻许可，单日波动=噪音（不构成信号）。
- 前提：融资余额持续增长（杠杆牛延续中）；环境变了此法失效——"策略一定要跟行情相结合，千万别刻舟求剑"
- 杠杆扩散链：融资做妖股赚钱→融资买趋势股→场外配资/信贷；**不带 R 标识的票 = 场外杠杆聚集地，无缘无故暴涨警惕做庄**（配资多为虚拟盘对赌）
- 高低切融资信号：同板块内大票融资余额降+小票占比升 = 资金卖大买小进行中
- 银行的真实逻辑 = 工具银+资产荒抱团，不是估值："IF 有人用 PE 低劝你买银行 THEN 远离"（PE 只与自身历史纵向比）；银行抱团后期会有不小回撤
