## 四十三、市场情绪的节奏：上涨三波与末日轮（20260928 直播）`[核心]`

> 2026-09-28 月度直播《市场情绪的节奏》主讲知识点。东西方两套框架在本章统一：**上涨只有三波**。

### 43.1 两套同位框架

| | 西方波浪理论 | 东方"一鼓作气，再而衰，三而竭" |
|---|---|---|
| 最强一波 | **第三浪（主升浪）** | **第一波**（连板大阳线直冲） |
| 节奏 | 1浪涨→2浪回调（可深至1浪起点）→3浪主升→4浪→5浪鱼尾 | 一波不如一波，三而竭没新高 |
| 适用 | 权重/趋势股（耗时大半年~一两年，参考 2021 茅台/宁德/比亚迪） | 妖股/题材股（半年不到走完，哪来的回哪去） |
| 顶部 | 5浪量能/MACD 背离=鱼尾；5浪≈双顶，B浪反弹再成头肩顶（右肩可弹到5浪附近） | 三而竭后直接 A 杀 |

```text
IF 用波浪看权重趋势股 THEN 最猛的第三浪做完就可以走（扛过四浪回调、五浪做个双顶再走）
IF 看题材妖股 THEN 按一鼓作气/再而衰/三而竭，第一波最猛
IF 三而竭都没创新高 THEN 情绪结束，不要再去博二波三波
```

### 43.2 为什么是"三"（行为金融）

```text
第一波：多数人看不到/不敢信（尤其题材妖股）→ 第二波：犹豫，看别人赚钱忍不住跟进
→ 第三波：之前不信的都信了 → 前期信得早的人正好卖给后知后觉者 = 顶
题材第一忌讳：要么不信，要么早信（第一波没早信、第二波犹豫、第三波梭哈 = 标准接盘）
IF 能走完两到三波 THEN 已是市场给了莫大机会（多数标的是直接 A 杀）
IF 板块很久没出现过涨停 THEN 该板块短期已被资金抛弃，短线不做
```

### 43.3 末日轮 `[核心][可计算]`

```text
定义：三波走完 → 本该走 B 浪反弹（弹个 2、20% 就该死）→ 却打出新高/多弹一截
      且没有强力驱动（基本面没质变、美债/流动性仍压制、成交量不支持）
IF 多个高标/情绪指标同时走末日轮 THEN 市场不支持继续往上嗨 → 做空胜率大幅提升
IF 越往上涨需要的钱越多 AND 成交量跟不上（前期 2.5-2.6 万亿、本波最多 2 万亿） THEN 末日轮必回落
实例：药的高标（AI 熄火后靠高标反复走一个多月，高标一倒药就成死狗）、农业高标"大米"
IF 已走到第三波 THEN 之前没参与就干脆不参与（赌第四波=赌上头）
IF 参与 THEN 只在第一波、第二波；行情是走出来的，不是规划出来的
```

### 43.4 打破常规：新周期的两个必要条件

```text
IF 三波走完还想再走一波 THEN 必须同时满足 ① 强驱动的基本面重大变化 ② 足够时间完成筹码交换
IF 三波走完没多久就接第四波 AND 无强驱动 THEN = 末日轮（不是新周期）
实例：AI 情绪股剑桥（2023-2026），三波后歇一段，靠 AI 产业链驱动又开启新三波
⚠️ 真出现新周期时，人们往往忽略前面行情、从中间重新数浪——必须回到完整图形看位置
IF 科技/AI 三浪走完且叙事续不上 THEN 按 A 浪下跌→B 浪反弹→C 浪阴跌走
IF 想再来 THEN 要么用空间换（把 C 浪跌完），要么用时间换（横半年到两年；妖股还两三年债的都有）
IF 你是冲短期逻辑去的 THEN 就按短期逻辑走，不要"短期变长期"
```

**新周期的"两步式"**（2026-09-29 补充，与 43.4 上述条件并列使用）：
```text
A股开启新周期行情，通常先「挖坑」→ 再由资金重新挖掘板块（两步，缺一不可）
IF 挖坑已完成 AND 资金仍在怼老主线（如元件/科技硬件） THEN 新行情不成立
（"如果继续怼元件这些，那就很难开启新行情"——看新板块是否被点火）
```

### 43.5 下跌侧对偶：下跌只有两波与下跌 2.0 判别（20261013 直播）`[核心][可计算]`

> 来源：2026-10-13 月播下半场（《什么是2.0》+《牛末不牛初的应对》，提炼见 06-video-extract J 批）。
> 上期（43.1/43.2）讲"三"（上涨三波），本期讲"二"（下跌两波），同一月播系列的连续知识点。
> **放宽说明**：本节为 `[单源]` 直播来源即整节进入（经用户 2026-10-13 拍板）——理由是
> **下跌侧知识在全部素材中极度稀缺**（719 篇文章 grep `下跌两波/A浪/C浪/主跌浪/技术性熊市/从中枢画` 零命中），
> 43 章此前只有上涨侧，本节补上对偶缺口。若后续直播/文章出现矛盾表述，按回测红线删除而非改写。

**① 下跌两波框架（A 回调错觉 → B 诱多 → C 绝望）**：
```text
为什么主跌浪只有 A、C 两下（涨却有三波）——行为学对偶（对照 43.2 的"三"）：
  A 浪 = 上涨刚结束时，大家当成普通回调（以为和 4 浪一样还会涨回来）
  B 浪 = 诱多反弹（希望燃起）——多头的残存力量博反弹
  C 浪 = 绝望的一浪（反弹搏进去的人走了，大梦初醒：已经结束了）
涨 = 慢慢相信的堆量过程（黄金式：成交量慢慢堆上去再加速）
跌 = 蜂拥出逃的挤兑过程（白银式：蹦一下掉下来，连稀缺性都顾不上）
"帝国大厦——跑上去两钟头，跳下来只要几秒钟"
IF 数主跌浪 THEN 只数 A 和 C（2/4 浪回调属主升浪内部子浪，不算主跌浪）
IF C 浪走完 THEN 杀伤力度和持续性都远超 A 浪
IF 经历 C 浪 THEN 最杀人诛心的不是跌幅是时间
   实例：22 年——第一波 -20%（技术性不牛）→ 反弹 → C 浪从反弹高点算仅 -20%、
   低点算不足 -10%，但走了两年（22 下半年 + 23 整年 + 24 年）
```

**② 20% 技术性牛熊标准与中枢画法**：
```text
技术性牛 = 从最近一轮低点上涨 ≥20%；技术性不牛 = 从最近一轮高点下跌 ≥20%
（国际管理惯例，非他自创，"20% 是恒定标准"——下跌波次的分界节点）
数波次的起点：从中枢（区间震荡平台）画比从下跌起始点画更科学——
   从中枢之上买入的人在该时段有利润（五六个月的行情），不是"一刀接一刀"
IF 某段反弹走了约五个月且幅度大、时间长 THEN 不再画为上一波延续，是新的下跌
⚠️ 熔断的年份：常说的"15 年熔断"实际是 16 年年初——15 年后半段的熊市只有两波
```

**③ 下跌 2.0 的判别三要件（本节核心判据）**：
```text
IF 1.0 之后反弹构筑平台，再跌破平台 THEN ≠ 2.0 开始
   （只是"刷新了区间的低点"，仍在区间震荡内）
IF 中枢以下跌幅 <20% THEN 判 1.0 的延续，不判 2.0
   实证（2026-10-13）：科创中枢以下仅 8% → 判 1.0 延续
IF 确认 2.0 THEN 需要时间与空间双条件：
   ① 平台位置震荡一到两个月（时间）② 跌幅区间继续扩大（空间）
IF 真要走 2.0 THEN 之前一定先构筑区间平台（平台往往=前一波上升浪之前的中枢）
IF 1.0 与 2.0 衔接 THEN 跌的造型和幅度基本一样，不能靠"跌幅像不像"区分
IF 要跌破平台 THEN 需要很强驱动（量级：海外 1.0 级指数下跌 / 科技巨头爆大雷）
```

**④ 2.0 vs 1.0 的盘面指纹（判阶段的实证校验）**：
```text
1.0 特征：有量、中途有反弹（创业板反弹五六个点"偷偷地给了机会"）、有拉扯有抵抗
2.0 特征：没量、大跌唰唰唰、想卖卖不出（开盘 30/31 个点直接跌停板），
          比 1.0 更猛、毫无抵抗、真正绝望的一波
IF 判断当下处于哪段 THEN 看指纹：明星股没像 1.0 时那样 10/20 厘米连砸 → 仍是 1.0 延续
   实证（2026-10-13）：易中天/存储系明星股没有 7 月那么跌 → 判 1.0 延续
```

- ⚠️ **命名冲突注意**：三十九章"疯牛 2.0 / 牛市 2.0 checklist"的 2.0 = **牛市第二波上涨**；
  本节 2.0 = **下跌第二波（熊市）**。同名不同义，引用时必须带"下跌 2.0"字样。
- 历史案例载体（1.0 与 2.0 之间的中枢结构）：21 年"林子/毛子"（转写存疑词，见 J 批第五节）、
  21 年白酒医药（中枢震荡好几个月，"以至于让你忘记了它才走下跌趋势"）、15 年反弹段刷新区间低点。
- 当下结论（2026-10-13，快照）：科创/创业板判 1.0 延续；短期剧本＝区间内上上下下，
  等新的向下驱动（不一定会有，可能晃几周/几个月/更久）。

### 43.6 主升浪的参与方式 `[核心][可计算]`

> 来源：2026-07-29（"质量的公司，大多数都还在1浪，有的在2浪震荡回调，后面走个小3浪的主升"）；2025-11-12（"多复复盘，翻一翻哪些个股是2浪和4浪的回调"）；2025-02-24（祖师爷体系分析）；回踩语料 16 篇。43.1 讲"三波"整体节奏，本小节讲**主升浪怎么进**。

```text
为什么不等 1 浪就参与？——等的是确定性买点：
  很多一浪上涨结束就没了（走不出完整波浪）；即便走出来，1 浪进去要经历 2 浪回调
  （右侧确认比左侧便宜更稳——与一章"放弃买在最低点的利润，赢得确定性的买点"同理）

主升浪两种参与法：
① 2 浪回调介入：1 浪上涨结束后的横盘/回落阶段介入（成本+时间优势）
   （"翻一翻哪些个股是2浪和4浪的回调，做好盈亏比和止盈止损"2025-11-12）
② 3 浪突破介入：突破 1 浪前高、创出新高后再动手（节约时间、牺牲成本优势）
   同样适用于判断板块："有的在2浪震荡回调，后面走个小3浪的主升，概率也不小"（2026-07-29）

离场：连续不创新高 / 跌破重要均线或支撑（与 4.6 离场信号同源）
复盘习惯：每天翻板块与个股的浪型位置（1浪/2浪/3浪/B 浪反弹）——
  "走主升浪需要天时地利人和……后面谁走主升浪，别去猜，坚持每天复盘"（2026-07-29）
```
