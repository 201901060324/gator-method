## 二十一、行业周期三拐点与长鞭效应 `[核心]`

来源：20250416《行业周期》、20260715《长鞭效应》《矛盾与统一》。

### 21.1 行业周期三拐点（20250416）

```text
盈利拐点：营收/扣非增速明显放缓（如 20%/30%→10%）→ 保持警惕查财报
供给拐点：跨界扩产/盲目扩产 = 行业上行周期加速结束
需求拐点：宏观 + 技术革新（必须"商用有普及苗头"，实验室突破不算）
周期长度参考：地产 20-30 年 / 金融 8-10 年 / 白酒 7-10 年 / 医药 5-8 年 /
  汽车 4-6 年 / 消费电子 3-5 年 / 养殖 3-4 年
去产能 = 走出寒冬的必经之路；跨界者最先被淘汰
IF 行业全行业内卷 THEN 找"熬死同行"的龙头——份额归它，下一个周期最亮的
```

### 21.2 长鞭效应（20260715）[核心]

终端真实需求的微小变化沿产业链逐级放大（+10% → 零售+20% → 批发+30-50% → 上游扩产100%）；下行时反向同样成立（各环节库存出清后，需求稍好就供不应求价格暴涨）。

```text
IF 工业品被宣称"供不应求将持续到20XX" THEN 高度存疑（工业品扩产快，只有农产品有刚性周期）
IF 关键环节数据是商业机密（如冻库库存） THEN 该品种放弃："收集不到就不做"
IF 各家销量目标集体+20~50% AND 行业总增幅预期仅+10% THEN 必有车企高估自己
  = 提前交易周期下行的做空依据（预期加总远大于行业总盘 → 做回归）
研报失真机制：券商只问上游订单（确实爆发了），没看中端零售；"每个环节都没说谎但合起来是错的"
屁股决定脑袋：产业链各环节都说自己最重要——研报按说话人立场折价
```

### 21.3 矛盾与统一（20260715）[核心]

```text
IF 供需两旺 AND 上中下游利润分配均衡 THEN 行情长久（20-21新能源全链齐涨）
IF 蛋糕做不大 AND 一家独大 THEN 行情不长久（新能源后期利润被中游电池吃掉）
IF 下游还没赚钱（B2B 闭环未走通，如当前 AI） THEN 该行业"从来没统一过"，
  把上游未来五六年需求按计算器是不合理的
下跌传导：最先吃压力的先跌（整车→上游原材料→中游电池）
IF 做短线（几天到几周） THEN 不需要看基本面——看形态/融资余额/成交量/OBV 即可
```

### 21.4 共识的对手面：转化判读 `[核心]`

> 来源：2025-02-24（"逼空之后，满仓的人就是最大的空头，逼多之后，空仓的人就是最大的多头"）。21.3 是产业供需视角；本节是**市场博弈侧的两条判读**。

```text
IF 市场资金都形成共识、觉得"没有矛盾一马平川" THEN 往往离犯错不远
  ——满仓的人就是最大的空头（逼空之后）；空仓的人就是最大的多头（逼多之后）
  （仓位重的人稍微反向波动就爆仓出局，"让对手盘慢慢变成你的帮手"）
IF 做短线 THEN 判断"谁在止盈"：游资主导的行情 → 短期重心看游资态度
  （连板、涨跌停数量、龙头、主线板块——这些不变短线机会就还在）
IF 提升效率 THEN 找共识转化的时机：交易预期时，离预期兑现越近离转化越近
  （开会炒预期——尘埃落定后之前的多头或转化成空头；预期兑现=止盈时点）
```

### 21.5 趋势打法与区间打法 `[核心]`

> 来源：2024-03-07（"很标准的趋势策略，但不一定适合你"）；越涨越卖/做T/回踩语料（4/127/16 篇）。价值股与成长股的**两种操作范式**。

```text
两种打法（互补）：
趋势打法：单边上涨过程中介入——介入点=新高介入或新高后回踩介入
  （"扛不住回踩的，就不优先考虑。不回踩，持续新高的，视为强者恒强"2024-05-20）
  离场=连续一段时间不新高/跌破重要均线或支撑
  突破打法是低胜率高赔率：假突破极多——突破后等回踩确认（回落不回区间=有效）
区间打法：价值股（传统成熟行业）按估值区间做——区间顶部/底部/中值搞清楚，
  低位分批配置、回归中值或顶部止盈
仓位纪律（扶摇直上阶段）：越涨越卖或做 T 保持总仓位（浮盈加仓是亏损主因之一）
执行自问：操作之前先问——"我做的是什么策略、什么工具理论、看什么市场信号"
```

### 21.6 行业阶段定位：成长与价值的护城河 `[核心]`

> 来源：护城河 6 篇（2025-08-04 长线选股五条之四）；戴维斯双击 1 篇（2026-07-10 医药"需求恢复、供给收缩……你看这像不像戴维斯双击"）；生命周期 3 篇。长线选股的**阶段定位框架**——"长线投资遵循宏观→行业→公司，自上而下"。

```text
行业阶段判断（成长期 vs 成熟期）：
  成长期：市场规模扩大、需求提升、利润增长 → 核心现象=戴维斯双击
    （盈利提升→股价涨→信任→更多钱→正反馈螺旋）
    ⚠️ 不能静态看市盈率：成长股"越涨估值反而越低"（业绩追上估值）；
    反之股价越跌估值越大 = 估值陷阱
  成熟期：增速走平、壁垒高 → 股价小幅上涨或区间震荡 → 估值分位法配置
  "所有成长股最终都会变成周期股，只隔一个主升浪"（20.4）

长线选股五条（2025-08-04 公开版）：①股息率 ②ROE ③业绩增速（营收和扣非）
  ④有护城河（"电信移动这种垄断的，银行保险这种有龙队撑腰的，也是护城河的一种"）
  ⑤下个季度有业绩预期（结合宏观政策/经济/行业情况判断）
投机者买猪（能蹭概念、盘子小），投资者买有翅膀的（17.1）
以动态眼光看行业位置：衰退行业也可能政策驱动/新技术走出复苏
```

### 21.7 指数的估值查询与分位判读 `[可计算]`

> 来源：2024-12-10《被利用的股民》（"这个方法，是免费的，不需要去官网查。中证1000指数估值历史分位点为62%。沪深300为58%"）。21.5 区间打法的**读数工具**。

```text
查法：看指数估值历史分位点（免费渠道可查，无需付费工具）
使用：与 21.5 区间打法配套——分位值是"区间顶部/底部/中值"的直接读数；
  成熟行业用长周期估值曲线，低分位=低估有回归潜力
注意："估值是滞后的，炒的是预期"——分位只是锚，还要看预期方向（同源 2024-12-10）
```
