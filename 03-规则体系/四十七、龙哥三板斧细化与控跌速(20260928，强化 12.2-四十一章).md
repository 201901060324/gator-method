## 四十七、龙哥三板斧细化与控跌速（20260928，强化 12.2 / 四十一章）`[核心]`

```text
① 先买中字头：三桶油、移动电信、电力/煤炭类中字头
② 再买金融：银行/保险/证券里挑一两个
③ 再买宽基 ETF，顺序：上证50 → 沪深300 → 中证500 → 中证1000 → 科创/创业板
④ 还不得劲 → 发利好（盘后利好）
⑤ 实在不行 → 强力护盘（如去年关税那次；今年已三个月没用强力护盘，靠①-④把火续上）
IF 这套流程走完仍护不住 THEN 才谈失守
```

**控跌速 = 情绪管理**（这是"龙哥为什么要守 3800"的答案）：
```text
同样是上证一个月跌 5%：
  两天跌完 5% → 第二个月不一定止得住血
  一天跌一点、反弹一点、再跌一点，慢慢跌一个月 → 第二个月就不见得继续跌
IF 跌多了 THEN 老乡别走、发点镇静剂 → 牛回速归 → 嗨完再降温 → 慢牛走得久
"守 3800"不是守点位（已数次刺破到 3700 多），而是在该位置**提供流动性与信心**
```

**胜率上限（强化 19.3）**：
```text
IF 再有把握 THEN 只能说到九成，永远留一成 = "人算不如天算" → 必须对市场有敬畏之心
开仓节奏：第一天轻仓 → 末日轮等验证点兑现 → 加到正常仓 → 把握 7 成 → 9 成
胜率取决于模式：他开仓少（8月做多、9月做空，两个月看胜率100%）；
  量化一天操作一两千只票，胜率 50% 也赚，靠赔率（亏 3-5 个点、赚 10 多个点）
```

**假期对冲判别** `[单源]`：
```text
IF 长假前海外大概率要跌 THEN 机构会放空单对冲：节后涨→平空单股票赚；节后跌→股票不动空单赚
成败关键 = 资金分配是否匹配（一头收益能否覆盖另一头亏损），覆盖不住 = 对冲失败
```
