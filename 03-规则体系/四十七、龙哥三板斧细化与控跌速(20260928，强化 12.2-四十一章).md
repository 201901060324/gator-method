## 四十七、龙哥三板斧细化与控跌速（20260928，强化 12.2 / 四十一章）`[核心]`

```text
① 先买中字头：三桶油、移动电信、电力/煤炭类中字头
② 再买金融：银行/保险/证券里挑一两个
③ 再买宽基 ETF，顺序：上证50 → 沪深300 → 中证500 → 中证1000 → 科创/创业板
④ 还不得劲 → 发利好（盘后利好）
⑤ 实在不行 → 强力护盘（如去年关税那次；今年已三个月没用强力护盘，靠①-④把火续上）
IF 这套流程走完仍护不住 THEN 才谈失守
```

**触发源与新增动作：窗口指导 → 回购 + 发利好 + 买宽基（2026-10-16 + 10-19）`[重要]`**：
```text
上表是"龙哥自己动手"的动作序列；现实中还有一条**由监管发起、公司执行**的路径：
  窗口指导（监管要求） → ① 上市公司**回购/增持** ② 继续发利好 ③ 汪汪队买宽基
IF 上述三动作**同日出现** THEN 判为一次有组织的干预（不是市场自发行为）
补充（2026-10-19）：维稳的具体形式被进一步明确为"**限制卖出 + 鼓励回购**"
```
- 与上表的关系：三板斧是**资金端动作**，本条补**行政端触发源**与**公司端动作**（原表没有"回购"这一项）。
- 与 24.5"回购增持密度＝政策底先行指标"配套：那条看多日累积，本条看单日组合。

**护盘波次可数化（2026-10-15）`[可计算]`**：
```text
数"这天护了几波"：宽基 ETF 的放量脉冲次数 ≈ 大金融脉冲次数（两个口径等价，取其一即可）
IF 单日出现 N 次脉冲 THEN 记为 N 波护盘；波次越多 = 当日抛压越大（需要反复接）
```
- 用途：与 12.5（质量）、49.5（效力上限）合用——**波次是"抛压强度"的代理变量**，不是护盘力度的指标。

**控跌速 = 情绪管理**（这是"龙哥为什么要守 3800"的答案）：
```text
同样是上证一个月跌 5%：
  两天跌完 5% → 第二个月不一定止得住血
  一天跌一点、反弹一点、再跌一点，慢慢跌一个月 → 第二个月就不见得继续跌
IF 跌多了 THEN 老乡别走、发点镇静剂 → 牛回速归 → 嗨完再降温 → 慢牛走得久
"守 3800"不是守点位（已数次刺破到 3700 多），而是在该位置**提供流动性与信心**
```

**龙哥失手门槛（20261013 直播，本条为看空操作的边界条件）**：
```text
IF 龙哥没失手 THEN 不用过度看空
判定口径：15 年没兜住 → 2026 轮的 12 月 / 3 月 / 7 月三次都兜住了（他自述"至少目前兜的还可以"）
实证（2026-10-13 快照）：内忧外患冲击下大盘高点下来仅 -10%（未达技术性不牛）→ "给龙哥鼓掌"
机制表述（与上节"守 3800"互为表里）：不是点位有支撑，是 3800 以下触发**被动技能**
  = 三板斧流程自动拉一遍（买中字头、买宽基、开会发力）→ 流程见本章开头
失手标准（与本章首条合用）：①-⑤ 流程走完仍护不住 = 失守 = 失手，届时才升级看空
```
- 来源：06-video-extract J 批（2026-10-13 直播）。单源放宽进入（同 43.5 拍板口径）。
- 龙哥也在进步（他原话）：15 年没兜住、这轮想兜住——参照 41 章"市场三状态"的干预者演化观。

**胜率上限（强化 19.3）**：
```text
IF 再有把握 THEN 只能说到九成，永远留一成 = "人算不如天算" → 必须对市场有敬畏之心
开仓节奏：第一天轻仓 → 末日轮等验证点兑现 → 加到正常仓 → 把握 7 成 → 9 成
胜率取决于模式：他开仓少（8月做多、9月做空，两个月看胜率100%）；
  量化一天操作一两千只票，胜率 50% 也赚，靠赔率（亏 3-5 个点、赚 10 多个点）
```

**假期对冲判别** `[单源]`：
```text
IF 长假前海外大概率要跌 THEN 机构会放空单对冲：节后涨→平空单股票赚；节后跌→股票不动空单赚
成败关键 = 资金分配是否匹配（一头收益能否覆盖另一头亏损），覆盖不住 = 对冲失败
```
