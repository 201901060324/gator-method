## 二十二、基本面框架：短期驱动与长期定价 `[核心]`

来源：20260129《基本面的长期和短期》、20260706《预期与现实》、20260524。

### 22.1 顶底先行原则

```text
IF 做多 THEN 心里必须有基本面的顶（不是技术面的顶）
IF 做空 THEN 心里必须有基本面的底（行业盈亏线/亏损顶）
不知道什么价格高估低估 → 不做
```

### 22.2 短期基本面（驱动几天到几周）

1. 默认"**消息是为行情服务的**"：涨时全是好消息跌时全是坏消息，近期基本面最易失真
2. 校验数据可信度：IF 国际定价品种 THEN 期现共振可信；IF 非国际品种 THEN 现货报价可操纵，"期现共振"可能是假信号
3. 看交易所动手没：限仓/提保证金 = 官方认定过热 → 叠加预期过强 = 短空依据
4. 预期矛盾检测（见 21.2）
5. IF 小行情 THEN 小仓位做一段就收，卖飞不可惜

### 22.3 长期基本面（定价值区间）

按产业链自上而下：**上游定亏损底**（行业平均盈亏线，如碳酸锂 2026 ≈8 万/吨，杀到附近跌不动）→ **上游定乐观顶**（调研信息给区间，如 14-16 万；且涨不到历史极值——政策不允许）→ **中游看话语权**（龙头长协价成本固定，涨价利空的是二三线）→ **中游找确定性增量** → **下游看竞争格局**（内卷行业不知道谁活到最后，不好做）。

### 22.4 基本面三种玩法（20260706）[核心]

```text
① 买预期卖现实（做周期）：冬天买甚至深秋，春暖花开卖——大多数时候
② 买现实卖预期（做成长）：现实很强且想象空间不断打开——最难，要判断预期是否已 price-in
③ 买现实卖现实（做红利）：公司没预期稳定分红；股息高时买卖息低时卖
（类可口可乐公司；"若有人跟你讲星辰大户新叙事，那可能就是阶段高点"）
```

### 22.5 调研与深浅

```text
IF 价格出现与逻辑相反的下跌 THEN 不急着翻空，带着仓位去调研，
  直到基本面信息让你扭转逻辑再离场（鸡蛋 09 合约例）
IF 只做行业级中长线 THEN 不必研究报表细节（他自己很少看资产负债表：易造假，
  赚行业 β 不赚公司 α）
IF 做个股五年十年深度投资 THEN 必须研究报表+管理层
IF 自称创新药 AND 研发费用占营收比极低 THEN 定性为蹭概念
IF 物流/用电量等不易美化的数据 vs 官方数据矛盾 THEN 信前者
```

### 22.6 基本面 × 股价的四象限（老登股分类，2026-09-30）`[重要][分类表]`

| | 股价在春天 | 股价在冬天 |
|---|---|---|
| **基本面在春天** | 风电、医药 | 保险、证券 |
| **基本面在冬天** | 养殖（预期先行） | 光伏、基建 |

- 另有一类"**过热夏天**"：染料（太小众易被忽略，成分股已开始走加速）。
- 推论："大团圆也不是一起同时大团圆，**不同行业基本面有错位，股价波动也有错位**。"
  （注意：此"错位"是**基本面 vs 股价**的错位，与四十五章"指数与板块的错位"不是一回事。）

**配套自问（做预期 vs 做现实）**：
```text
"是更喜欢做基本面好的，还是技术面好的？是更喜欢做预期，还是做现实？"
—— 做药 = 做现实，做猪 = 做预期
```

- 与 22.4 三种玩法对应：**做现实 ≈ "买现实"一侧（成长/红利）**；**做预期 ≈ "买预期"一侧（周期）**。
- 养殖 = "基本面冬 + 股价春"被同日两篇独立素材（复盘分类 + 生猪深度数据）印证，非单源。
