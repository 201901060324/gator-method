## 二十七、长线配置与"小马过河" `[核心]`

来源：20260524《投资是小马过河》、20260715、20260831。

### 27.1 小马过河：方法没有对错，只有适配

```text
大象（巴菲特型）：只等月K级以上大跌出手，十年一次 → 普通人做不到，别模仿
松鼠（超短型）：做日K级，听说周K调整明天就清仓 → 这是它的生存方式
小马（绝大多数人）：别信大象说水不深，别怕松鼠说水深——自己踩着石头过河
"看多大级别的周期，就做多大级别的周期"——两套周期不混用
IF 听别人说答案 THEN 没用——"你不理解其中的道理，别人说了你也拿不住"
```

### 27.2 大儿子种庄稼 / 小儿子做生意 / 老太爷

大儿子=传统行业红利防御（饿不死但不受待见，还被要求多存钱）；小儿子=科技AI进攻（来钱快但做死的多）；老太爷=上面的意志，**偏心是有意的**——必须留一个种庄稼的留存粮，真出事时拿存粮救场（=高股息/传统板块的筹码是护盘资源）。"任何一门生意都有周期"，跟小儿子不赚钱的人会回来种庄稼——风格轮动的微观机制。**不能全仓进攻**：一边做生意一边种地。

### 27.3 配置规则

```text
IF 红利持仓 THEN 基本不用卖，至少一半底仓常年不动（吃分红是大头）
IF 熊市里红利像妖股走加速 THEN 可阶段性止盈 1/3 或 1/5
宽基组合参考：沪深300:创业板:恒生:纳指 ≈ 2:2:2:1；纳指不超过港股、不超过A股
IF 做美股 THEN 只在以年为单位的大机会（2000/08/18 级别）配；走合规渠道
"三剑客"组合：红利 + 港股 + 美股
IF 看好但不想承担高风险 THEN 上证50 = 科技含量最低的宽基去处
IF 博科技反弹 THEN 选前期没大涨、被打压、这波反弹幅度小的（避免套牢+获利双压力）
"大团圆结局"三条件：①大金融至少一个走中期补涨 ②科技不拖累指数 ③两三个大体量
低位板块轮动补涨拔估值
⚠️ 前置条件（2026-09-30 补充）：**"要大团圆，仅靠护盘和资金的切换还不够，还得实实在在的基本面改善。"**
   ——"这两年走弱的行业，有资金错杀的成分，也有很多是基本面确实没啥改善，**改善了才容易走真正的修复**。"
IF 结构性不牛市 THEN 长线仍可坚守——"牛市只是放大器，决定盈利高度不决定赚不赚钱"
```

### 27.4 心态规则

```text
"回本就不干了"的心态，越回不了本；把回本当目标是没有出息的
IF 越迷茫艰难 THEN 越要相信人生刚开始，不给负面心理暗示
入市两三年没经历过股灾的，不要说"这就是股市"——"跌一点点几年才叫熊市"
A股最不缺的就是机会，踏空一段就走，随时有舒服的姿势接回
```

### 27.5 网格交易的保有量 `[重要][可计算]`

> 来源：2025-05-29/06-05（"网格交易是最省心的操作……人型量化"）；2026-02-26（"除极少数品种，如宽基，红利，等指数可以采取**无上限保有量**，其他行业指数和个股，都要有金额的上限"）；2026-04-21（"同为无上限保有量的红利ETF和标普ETF"）。27.3 已有"网格/红利"词条，本小节是**网格策略的仓位规划**。

```text
网格原理：找长期向上的品种（红利/标普/黄金/沪深300 等 ETF），划分网格线做区间波段
  ——不看基本面情绪消息，到区间就买卖（"人型量化"省心高效）

保有量 = 持仓品种的仓位占比（金额划分）——三规划：
① 无上限保有量：仅限宽基、红利等指数（"除极少数品种……可以采取无上限保有量"）
② 有上限保有量：行业指数和个股都要有金额上限——"留有余地，恰当的仓位管理，
   是熬过寒冬重要因素"
③ 独立对待持仓、互不干扰（2026-04-21）：同为无上限的红利与标普，一个止盈一个不动
   ——"核心就是……独立对待自己的持仓"
纪律：上限一定是闲钱规划（长期投资，基本面无重大变化时保有量要有下限）
```

### 27.6 海外配置：跨境 ETF 的三种策略

> 来源：黄金 ETF 8 篇（2025-06-12"资金少的选手，逢低配点黄金ETF做对冲"）；纳指 ETF 4 篇（2026-06-25"可以去配一些标普或纳指ETF，能缓解你的不适感"）。**不需要海外账户**，A 股账户即可投资。

```text
逻辑：A股大多数时候没有整体大行情（B 的机会少、a 的机会多），但赚 a 要投入大量时间精力
  → 给时间精力有限、想做长线的人一个"不折腾"的选择：跨境 ETF
品种方向：黄金（对冲）/ 标普 / 纳指等跨境 ETF（按自身配置需求选）
三种策略：
① 定投：发工资买几百几千、不看价格——最省心
② 网格：划分区间做波段（接 27.5 保有量规划）
③ 择时：宏观或技术面因人而异（海外市场更不易被干预，纯技术面胜率往往更高）
情绪对冲用法（2026-06-25 原话）："如果当下市场的割裂，让你感到有种不追科技心里痒痒的
  感觉，可以去配一些标普或纳指ETF，能缓解你的不适感，又能避免上头追高"
```

### 27.7 大小企业之争与配置三原则 `[重要]`

> 来源：大票 180 篇、熊市重质 2 篇（2024-08-22"低估值的权重蓝筹，有预期的东西，就别低位割了。熊市重质，有分量的东西，终究会价值回归"）、高低切换 49 篇。27.3 是配置规则汇总，本小节补**"大 vs 小"的轮动逻辑与均衡原则**。

```text
大企业 = 沪深300 / 上证50；中小企业 = 中证1000 / 中证2000（价值与成长的另一称呼）

历史规律：熊市重质——大企业有行业地位/资金/成本优势、存活率高，机构更愿配；
  复苏期资金先抱大企业、后切中小企业（"资金永远高低切换：把中小估值炒高后，
   资金回流低位大公司"）
反方逻辑（成长先行）：低基数催生高增速——"优等生 60→80 分空间 33%，差生 30→60 分空间
  100%"；弱现实下资金抱团题材（最容易诞生题材妖股的正是中小企业）
他的态度：没什么好慌——即便成长先行，价值蓝筹不是不涨，只是涨得慢、后面爆发

配置三原则（通用）：
① 要均衡：做指数为的是市场平均收益，不走极端（全买超大盘=极端保守；
   全买微小盘=极端激进）
② 要择时要分批：大多数人都只适合左侧（逢低配置、分批进入——间隔因品种弹性而异）
③ 要做安全垫：接 4.5（留一半、不梭哈、成本优势）

自我认知校准："涨的时候想激进，跌的时候又想保守"=不了解自己——
  只有亲身参与后才能下结论（单日大跌或连续下跌就焦急的品种，不适合自己）
```
