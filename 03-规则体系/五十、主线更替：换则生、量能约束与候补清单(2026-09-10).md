## 五十、主线更替：换则生、量能约束与候补清单（2026-09/10）`[核心][可计算]`

> 来源：2026-09-29《股市：错位与共振》、2026-10-08《股市：想红包，砸个包》两篇复盘。

### 50.1 "换则生"：不换主线的可观测后果 `[核心][可计算]`

```text
IF 挖坑后主线不换（仍怼旧主线） THEN 指数重复循环：反弹涨一下 → 大跌 → 再反弹 → 再大跌，
   且成交量越来越少（单调递减，可直接量化）
IF 换出新主线 THEN 才可能走出新行情 —— "换则生"
```

- **可证伪指标**：只要后续每次反弹的量能一波比一波低，就坐实"主线未换、循环未破"。
- 与 43.4 的"新周期两步式"配套：挖坑只是第一步，**板块是否换血**才是成立条件。

**流程的本质定义与「多头不死」（2026-10-12，解释"换"为什么必须等）`[核心]`**：
```text
流程 = 旧主线信仰瓦解（人们逐渐放弃幻想、割肉离场） → 市场孕育出新主线
       → 在新主线带领下指数修复完成填坑
IF 旧主线的多头尚未离场（信仰只松动未崩塌） THEN "多头不死，跌势不止"
```

- 反向因果：**抢反弹资金不是助力，是延迟出清的负担**——给了希望再失望，
  反而让旧主线里的抛压更多（2026-10-12 上午硬拉科技即此例）。
- 与 49.3 的六步流程是同一逻辑的两面：流程 1-2 是"多头离场"，流程 3-4 才是"换血成立"。

### 50.2 科技主线的缩量约束（2026-09-29 + 2026-10-08，非单源）`[核心][可计算]`

```text
量能门槛：要拉科技 / 走单边上涨 → 需要 2.5 万亿 ~ 3 万亿 成交（"随便拉"）
IF 缩量（一万多亿）AND 硬拉科技 THEN 容易陷入恶性循环（缺钱硬拉 → 突然大跌一下）
IF 科技超跌后反弹 THEN "可以涨，但不能抢风头，一抢风头就容易被爆头"
   ——反弹一旦重新成为领涨主线，就会被打回
```

- 与 45 章"增量行情（2~3万亿）干最热的"同源，本条是其**下限侧的否定表述**（缩量时的约束）。
- 实例：2026-10-08 节后首日"硬拉科技 → 砸个大包"；当日复盘即判"换则生"。

**科技的新角色：情绪风向标，不是操作对象（2026-10-19）`[核心]`**：
```text
"当下拉一拉科技反而是好事情，代表市场风偏回升……**操作上不一定做科技，但要看科技的情况**，是情绪的风向标"
IF 想知道风偏是否回升 THEN 看科技能不能被拉起来（敢拉 = 风偏回来）
IF 决定买什么 THEN 不必然买科技（对照 50.5：科技只能当"多强之一"）
```
- 与本节主线的区别：本节管"科技**能不能**涨"（量能门槛），本条管"科技涨了**该怎么读**"（当指标还是当标的）。

**旧主线退位后科技的位置（2026-10-16，第二次出现）**：
```text
"科技死亡后腐烂" → 科技失去主线属性，只剩**捆绑指数的护盘价值**
IF 科技反弹 THEN 按超跌反弹对待，不按主线回归对待（完整定义见 50.6）
```

### 50.3 防御线：高股息的两条纪律（2026-10-08）`[重要]`

**① 龙头新高的"第一反应"元判据**（用第一反应判别自己的思维类型）：
```text
触发：工商银行（宇宙第一行）创历史新高
IF 第一反应 = 去看其他银行 THEN 短线思路
IF 第一反应 = 去看其他高股息行业 THEN 中长线思路
   （理由：股息率也是会波动的——复刻 2023 高股息抱团行情要横向找行业，不是同业跟风）
```
⚠️ 与 841 行"强如高股息，涨多了股息率下降会失去光环"是同一事实的两个用法：那条讲**风险**，这条讲**观察方法**。

**② 高股息的定位**：防御线的核心候选，但需注意见 27.3（红利持仓的卖出纪律）与 841 行的光环衰减风险。

**③ 高股息的双向阈值：涨→离场、跌→扫货（2026-10-13 + 10-14）`[重要]`**：
```text
风险侧（既有，1286 行语境）：再涨 → 股息率下降 → 触发大资金离场
支撑侧（新增，两次出现）：再跌 → 股息率吸引力上升 → 触发大资金扫货
  （实例口径：跌破 6 月低点之后，股息率重新具备吸引力）
IF 判高股息的位置 THEN 两侧阈值都要看，只报一侧会得出相反结论
```
- ⚠️ **方向极度容易被直觉搞反**：高股息是**跌了才更有价值**的品种，与成长股"跌了要跑"相反。
- 两次出现（10-13 / 10-14），已非 `[单源]`；与风险侧构成**成对判据**，并入时不可只留一侧。

### 50.4 候补主线清单（2026-10 语境，带时间戳）`[重要]`

```text
① 能源替代 / 能源安全（他形容"名正言顺"）：
   涉及：油气、燃气、煤炭、风光锂、电力、化工
   逻辑：油价持续高 → 国内增量需求不易有，但海外有潜在需求
   约束：外贸容易被卡——西方一贯说辞"中国的光伏/风电/电池/电车太便宜，要加关税"
② 防御线：高股息（观察 2023 式抱团能否复刻）
③ 扛旗候选人：医药、消费——"宏大叙事上比不上能源和高股息，但体量大、资金也经常炒"
```

- "扛旗候选人"是一档**中间状态分类**：不是主线、也非弃子，而是"体量够、等待轮动"的候补。
- ⚠️ 本条为 2026-10 当日语境，引用时须带时间戳（属 Layer 5 性质的清单，非永久框架）。

**候补清单的筛选方法：双层筛选（2026-10-14）`[重要]`**：
```text
第一层（基础筛）：**有逻辑 + 有业绩** —— 符合的很多，**筛不掉谁**
第二层（区分筛）：**有共振 + 有堆量** —— 才更可能走出右侧行情
IF 只满足第一层 THEN 只能是候补，不能作为交易对象
IF 两层都满足 THEN 才进"可做"名单
```
- 与 45 章"存量行情借偏锋（筹码少、机构少的板块）"分工：45 章讲**为什么点这类板块**，
  本条讲**在能点的板块里再挑哪一个**。

### 50.5 主线席位分配：一超多强里"一超"必须是非科技（2026-10-14）`[核心]`

> 12.5 ④（领涨分散到非科技）与本节的关系：那条是**否定式**（别只护科技），
> 本节是**正向指定席位**（领涨的那个必须是谁）。**更强，且不可互相替代**。

```text
一超多强格局下的席位规则：
  "一超"必须是非科技；科技只能当"多强之一"
  允许：科技跟随上涨、做超跌反弹
  禁止：科技领涨（"不能是一超"）
  正向要求：**领涨的一定得是非科技**
IF 某日科技领涨 THEN 判为**主次不分** → 行情走不远
IF 科技跟随上涨 THEN 正常，不构成"科技回归主线"的证据
```
- **"不靠科技领涨 ≠ 不拉科技"**——两句必须一起说：拉科技可以（甚至有利），但让它当领头羊不行。
- 与 50.2"不能抢风头就容易被爆头"同源：50.2 是**量能约束**下的结论，本节是**席位结构**上的定义。

### 50.6 主线更替的终态：旧主线退位为"普通板块"（2026-10-15）`[重要]`

> 50.1 讲"**不换**主线会怎样"（循环+量能递减），本小节补**换完之后**旧主线的状态定义——
> 此前体系里没有"更替完成"这个终态的判据。

```text
终态定义：旧主线失去主线属性，降级为**普通板块**
  → 涨也只是**超跌反弹**，不再具备"领涨+带动指数"的功能
  判据：① 涨幅靠后的超跌修复，而非放量新高 ② 上涨时不再带动其他板块跟随
IF 旧主线反弹 THEN 按反弹对待（对应仓位、持有周期都按普通板块），不按主线回归对待
IF 旧主线重新放量领涨、且有板块跟随 THEN 才考虑"重新成为主线"（对照 43.4 新周期条件）
```
- 与 50.1 的"多头不死、跌势不止"配套：旧主线的多头**信仰彻底瓦解**，才谈得上退位完成。
- 实例：2026-10 的科技（见 50.2 末段），"死亡后腐烂"的表述即此终态。
