## 五十、主线更替：换则生、量能约束与候补清单（2026-09/10）`[核心][可计算]`

> 来源：2026-09-29《股市：错位与共振》、2026-10-08《股市：想红包，砸个包》两篇复盘。

### 50.1 "换则生"：不换主线的可观测后果 `[核心][可计算]`

```text
IF 挖坑后主线不换（仍怼旧主线） THEN 指数重复循环：反弹涨一下 → 大跌 → 再反弹 → 再大跌，
   且成交量越来越少（单调递减，可直接量化）
IF 换出新主线 THEN 才可能走出新行情 —— "换则生"
```

- **可证伪指标**：只要后续每次反弹的量能一波比一波低，就坐实"主线未换、循环未破"。
- 与 43.4 的"新周期两步式"配套：挖坑只是第一步，**板块是否换血**才是成立条件。

### 50.2 科技主线的缩量约束（2026-09-29 + 2026-10-08，非单源）`[核心][可计算]`

```text
量能门槛：要拉科技 / 走单边上涨 → 需要 2.5 万亿 ~ 3 万亿 成交（"随便拉"）
IF 缩量（一万多亿）AND 硬拉科技 THEN 容易陷入恶性循环（缺钱硬拉 → 突然大跌一下）
IF 科技超跌后反弹 THEN "可以涨，但不能抢风头，一抢风头就容易被爆头"
   ——反弹一旦重新成为领涨主线，就会被打回
```

- 与 45 章"增量行情（2~3万亿）干最热的"同源，本条是其**下限侧的否定表述**（缩量时的约束）。
- 实例：2026-10-08 节后首日"硬拉科技 → 砸个大包"；当日复盘即判"换则生"。

### 50.3 防御线：高股息的两条纪律（2026-10-08）`[重要]`

**① 龙头新高的"第一反应"元判据**（用第一反应判别自己的思维类型）：
```text
触发：工商银行（宇宙第一行）创历史新高
IF 第一反应 = 去看其他银行 THEN 短线思路
IF 第一反应 = 去看其他高股息行业 THEN 中长线思路
   （理由：股息率也是会波动的——复刻 2023 高股息抱团行情要横向找行业，不是同业跟风）
```
⚠️ 与 841 行"强如高股息，涨多了股息率下降会失去光环"是同一事实的两个用法：那条讲**风险**，这条讲**观察方法**。

**② 高股息的定位**：防御线的核心候选，但需注意见 27.3（红利持仓的卖出纪律）与 841 行的光环衰减风险。

### 50.4 候补主线清单（2026-10 语境，带时间戳）`[重要]`

```text
① 能源替代 / 能源安全（他形容"名正言顺"）：
   涉及：油气、燃气、煤炭、风光锂、电力、化工
   逻辑：油价持续高 → 国内增量需求不易有，但海外有潜在需求
   约束：外贸容易被卡——西方一贯说辞"中国的光伏/风电/电池/电车太便宜，要加关税"
② 防御线：高股息（观察 2023 式抱团能否复刻）
③ 扛旗候选人：医药、消费——"宏大叙事上比不上能源和高股息，但体量大、资金也经常炒"
```

- "扛旗候选人"是一档**中间状态分类**：不是主线、也非弃子，而是"体量够、等待轮动"的候补。
- ⚠️ 本条为 2026-10 当日语境，引用时须带时间戳（属 Layer 5 性质的清单，非永久框架）。
