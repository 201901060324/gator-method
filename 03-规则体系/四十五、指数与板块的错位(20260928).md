## 四十五、指数与板块的错位（20260928）`[核心][可观察]`

```text
典型场景：沪深300 跌穿阶段新低，但微盘股、上证50（中字头/三桶油）已止跌反弹 = 错位
IF 短期错位 THEN 中期（周K/月K 拉出来）大多会共振（补跌/补涨，只是先后错开）
IF 长期不共振 THEN 只出现在牛熊转换/风格切换（2021→2022 杀权重：沪深300 哗哗跌、中证2000 震荡，
   因为主导资金从机构交棒给游资）
```

**危险信号**：
```text
IF 只有个别指数独亮、其他全跌（如 2026年6月只有科创/创业板打新高） THEN 极危险
   把兄弟们吸干、踩着兄弟们的尸体上去——"能走多远？"（6月底已验证）
IF 你产生"只有科创最亮、其他都得让路"的想法 THEN 这个想法本身就很危险
```

**操作含义**：
```text
上证50 / 沪深300 / 中字头（三桶油、移动电信）→ 当**信号**看，不要当标的做（不带杠杆弹性太小）
IF 50/300 守住了 THEN 去做有弹性的（中证500 / 1000 / 2000）
IF 50 守住 + 龙哥态度明确 THEN 再去市场里找被挖掘的新板块
```

**错位的核心驱动 = 资金偏好（不是基本面）**：
```text
IF 增量行情（2万亿~3万亿） THEN 干最热的（还是科技）
IF 存量/缩量行情（现在没钱） THEN 只能借着偏锋：找**筹码少、机构少**的板块点火
   （整车、风电跌久跌惨好拉；地产基本面没本质改善只是减缓下跌，照样有人点）
   原因：机构多的板块一点火，机构反手砸给你 = 白点
```

**他的取舍（重申并细化 22.4）**：
```text
基本面决定做不做，技术面决定什么时候做（技术面不只是 K 线，还包括情绪）
IF 很看好但一直跌、且没有高标、没有游资点火 THEN 短线不做
长线两种：右侧（等游资拉涨停/机构拉权重）或左侧（越跌越买）
IF 左侧做板块指数 THEN 必须控仓："不是所有指数都是红利，也不是所有股市都是美股"
   轻仓套 20% 与重仓套 20% 完全不同（心态 + 有无回旋余地：轻仓还能做 T、博段降成本）
IF 做板块指数 THEN 最好等右侧走出来再做（他等港股做双底："宝贵的仓位要花在刀尖上"）
```
