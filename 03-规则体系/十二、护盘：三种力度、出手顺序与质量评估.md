## 十二、护盘：三种力度、出手顺序与质量评估 `[核心]`

### 12.1 三种力度（2026-06-11《护盘的三种力度》）

| 等级 | 目的 | 工具 |
|---|---|---|
| **小维护** | 减缓大盘下跌速度，不出现全面恐慌 | 大金融、巨型中字头 |
| **中护盘** | 给权重股提供流动性，避免流动性危机 | 上证50ETF、沪深300ETF、中证500ETF |
| **大救市** | 赶快止血，避免进一步下跌 | 上述ETF + 中证1000ETF、科创100/50ETF、创业板ETF + 大金融、巨型中字头轮番上阵，伴随开会、出利好 |

> 924 以来**只出现过一次大救市**：2025年4.7关税。之后的阶段底（12月、3月）都只有小维护和中护盘。

他的判断倾向：**小维护、中护盘把阶段底部买出来，效果最好、花钱最少**。
> "如果这个位置都非要拖到大救市，我只会躲得远远的。"（他经历过 2015 年高位大救市没救起来）

【术语别名】"护盘的三种**目的**" = "护盘的三种**力度**"（2026-09-28 表述，内容完全对应，仅用词不同）。

### 12.2 护盘的出手顺序（2025-04-08）

```text
上证50 → 沪深300、中证500 → 中证1000、科创、创业板
（先权重，后小票）
```

**"龙哥"= 大手 = 国家队/干预力量**（术语表补遗）：
> "龙哥继续保持一边给巴掌，一边给糖的降温方式"
> "龙哥三板斧也在抡"
> "5月跟龙作对，去屠龙，然后被龙暴捶亏了40万"（他自嘲自己挨打后变老实）

### 12.3 护盘不改趋势

> "市场底，永远是市场合力所形成。恐慌情绪不消散，筹码没有完成充分交换，靠大手买也无法整体止跌。"

```text
IF 上涨由护盘驱动（而非信号满足） THEN 不判定为止跌，后续仍有震荡反复
```

### 12.4 市场止跌的推进顺序（2026-09-28）`[重要]`

> 与 12.2 的**龙哥购买顺序**并列对照：**Buying order（他买什么）≠ 止跌顺序（市场怎么止跌）**。

```text
市场止跌三阶梯（从先到后）：
1、巨型中字头、大金融、上证50       → 先止跌
2、沪深300、中证500                → 再止跌
3、中证2000、中证1000、微盘股       → 最后止跌
```

**与 12.2 的关键差异**：止跌流程的第三步**必须包含微盘股**——"微盘股不跌透，流程就不算走完"；
12.2 出手顺序止于科创/创业板，是因为**龙哥不买微盘股**，两个名单用途不同，不可混用。

**「插曲」警告**（流程推进中的假启动）：
```text
IF 权重刚止跌反弹了一点、题材次日立马大幅反弹 THEN 视为流程插曲，不判定为止跌完成
（"流程里会出现各种插曲……然后再下跌"——单日反弹 ≠ 流程推进）
```

### 12.5 护盘质量评估五维（2026-10-09）`[核心]`

评估一次护盘**不只看力度，还看结构**——同样是护盘，结构决定反弹质量与副作用：

```text
护盘质量高（副作用小） ⇔ 同时满足：
① 不一味护科技权重（没继续狂怼科技）
② 中证500 / 中证1000 等宽基 ETF 同步放量
③ 有市场自发资金进场（非纯国家队扫货）
④ 领涨分散到非科技板块
⑤ 金融（券商等）有配合
IF 只护科技权重、其余不跟 THEN 副作用大，反弹质量差
```

- 2026-10-09 实例：五条均满足 → 他判"今天这种复盘方式，副作用小"。
- 与 12.1 的关系：12.1 回答"护盘到了什么级别"，本节回答"这次护盘干得漂不漂亮"，评估维度不同，需分别记录。

### 12.6 大盘分时：权重×题材的组合观察 `[核心]`

> 依据公开文章整理。每日复盘的固定视角：**权重搭台、题材唱戏**（2024-02-22《结构良好，不言顶》等多篇），
> 与 12.4（止跌推进顺序）同为盘面结构观察，角度不同：12.4 看止跌流程，本节看**权重×题材的日内组合**。

```text
四类组合（按公开复盘归纳）：
① 权重领涨、题材跟涨 → 赚钱效应在权重蓝筹（机构主导的行情）
② 题材领涨、权重搭台 → 赚钱效应在题材小票（"权重搭台、题材唱戏"，短线最爱）
③ 权重稳、题材弱或退潮 → 老题材退潮信号，撤离高位题材股、谨慎观望
④ 题材强、权重被吸血走弱 → 存量博弈的跷跷板（你强我弱），上涨不可持续
   （"游资小票远远强于机构大票……如果剪刀差不改善，上涨无法持续，小心回落"——复盘固定注记）
```

**公开锚点**：
- "游资止不止盈，看两点：**权重的台子是否稳住，题材高标是否松动**"（2025-01-09《弱势波段怎么做》）
- "做权重的资金出来，如果顺利切到小票里，那短线情绪也不会恶化"（每日复盘）
- "抱团与主线行情是跷跷板，当两个都强的时候，必定有一个要被淘汰出局"（2024-03-12）
- 权重是市场的台子——"权重的台子没搭好，游资则会更倾向于等节后再干活"（2024 复盘）；
  权重持续走弱被吸血时，题材行情也难持续。

```text
用法：分时只是看盘的一个维度，还要结合当下市场高标、领头权重的表现综合分析。
无增量资金时，板块与题材权重之间是存量博弈（跷跷板）；判断分歧程度用剪刀差三档
（>0.5% 存在分歧 / >1% 分歧较重 / >2% 分歧严重，见八章）。
```
