## 十二、护盘：三种力度、出手顺序与质量评估 `[核心]`

### 12.1 三种力度（2026-06-11《护盘的三种力度》）

| 等级 | 目的 | 工具 |
|---|---|---|
| **小维护** | 减缓大盘下跌速度，不出现全面恐慌 | 大金融、巨型中字头 |
| **中护盘** | 给权重股提供流动性，避免流动性危机 | 上证50ETF、沪深300ETF、中证500ETF |
| **大救市** | 赶快止血，避免进一步下跌 | 上述ETF + 中证1000ETF、科创100/50ETF、创业板ETF + 大金融、巨型中字头轮番上阵，伴随开会、出利好 |

> 924 以来**只出现过一次大救市**：2025年4.7关税。之后的阶段底（12月、3月）都只有小维护和中护盘。

他的判断倾向：**小维护、中护盘把阶段底部买出来，效果最好、花钱最少**。
> "如果这个位置都非要拖到大救市，我只会躲得远远的。"（他经历过 2015 年高位大救市没救起来）

【术语别名】"护盘的三种**目的**" = "护盘的三种**力度**"（2026-09-28 表述，内容完全对应，仅用词不同）。
【术语】「**托而不举**」＝托得住、举不起来（2026-10-20）——指护盘力度够维持不跌、但不足以带动市场上行的形态，
  大致落在"小维护 ~ 中护盘"的效果区间（对照上表的力度分级）。用于描述**效果**，不是新的力度等级。

### 12.2 护盘的出手顺序（2025-04-08）

```text
上证50 → 沪深300、中证500 → 中证1000、科创、创业板
（先权重，后小票）
```

**"龙哥"= 大手 = 国家队/干预力量**（术语表补遗）：
> "龙哥继续保持一边给巴掌，一边给糖的降温方式"
> "龙哥三板斧也在抡"
> "5月跟龙作对，去屠龙，然后被龙暴捶亏了40万"（他自嘲自己挨打后变老实）

【术语别名】「**汪汪队**」= 国家队/龙哥的另一称呼，带"抠搜的"（出手吝啬）的语感（2026-10-16）。

**顺序的一次例外（2026-10-20，观察项，不修订顺序）**：
```text
当日实际动作：盘中先扫货科创 ETF（科技）→ 尾盘再补上证 50（非科技）
= 与上表"先权重后小票"相反，属于"从后往前补"
他本人的判据不是顺序，而是**覆盖面**："雨露均沾，大的小的、科技非科技，都照顾到了"（对照 12.5 ④）
IF 出现反向顺序 THEN 暂不判为规则失效，只登记；连续出现 2 次以上再考虑修订本节
```

**【附注】顺序的反用：安全垫＝离护盘资金的距离（2026-10-23）**：
> 上表是"他怎么打"，同一顺序反过来看就是"**我该站哪**"。

```text
IF 本轮看多做多的主要逻辑是护盘 THEN 品种安全垫 = 它在出手顺序里的位置（越靠前越厚）
  安全垫最高 = 上证50：科技最少、低位权重最多、护盘顺序先 50
  想搏弹性 = 中证500/1000，但只能用**指数 ETF**（分批、无杠杆，多急杀几天也扛得住）
  ⚠️ 同一方向用**股指期货**则容错为零：
    "假如今天龙哥不想护盘、想下周再护，那很多人今天就会爆仓、被强平，后续的大涨也会与你无关"
IF 带杠杆 THEN 极端行情下仓位必须更轻（不能一味图弹性，先考虑安全垫）
```
- 与 4.1（分品种风险预算）、4.4（交割/杠杆维度）配套：那两节讲"各品种能下多重"，本附注讲"**护盘逻辑下该选哪个标的**"。
- 与 19.5 拼合才完整：19.5 讲"为什么会被淘汰"（仓位重/成本高/时间长），本附注讲"**用什么工具决定会不会被淘汰**"。

### 12.3 护盘不改趋势

> "市场底，永远是市场合力所形成。恐慌情绪不消散，筹码没有完成充分交换，靠大手买也无法整体止跌。"

```text
IF 上涨由护盘驱动（而非信号满足） THEN 不判定为止跌，后续仍有震荡反复
```

### 12.4 市场止跌的推进顺序（2026-09-28）`[重要]`

> 与 12.2 的**龙哥购买顺序**并列对照：**Buying order（他买什么）≠ 止跌顺序（市场怎么止跌）**。

```text
市场止跌三阶梯（从先到后）：
1、巨型中字头、大金融、上证50       → 先止跌
2、沪深300、中证500                → 再止跌
3、中证2000、中证1000、微盘股       → 最后止跌
```

**与 12.2 的关键差异**：止跌流程的第三步**必须包含微盘股**——"微盘股不跌透，流程就不算走完"；
12.2 出手顺序止于科创/创业板，是因为**龙哥不买微盘股**，两个名单用途不同，不可混用。

**「插曲」警告**（流程推进中的假启动）：
```text
IF 权重刚止跌反弹了一点、题材次日立马大幅反弹 THEN 视为流程插曲，不判定为止跌完成
（"流程里会出现各种插曲……然后再下跌"——单日反弹 ≠ 流程推进）
```

### 12.5 护盘质量评估五维（2026-10-09）`[核心]`

评估一次护盘**不只看力度，还看结构**——同样是护盘，结构决定反弹质量与副作用：

```text
护盘质量高（副作用小） ⇔ 同时满足：
① 不一味护科技权重（没继续狂怼科技）
② 中证500 / 中证1000 等宽基 ETF 同步放量
③ 有市场自发资金进场（非纯国家队扫货）
④ 领涨分散到非科技板块
⑤ 金融（券商等）有配合
IF 只护科技权重、其余不跟 THEN 副作用大，反弹质量差
```

- 2026-10-09 实例：五条均满足 → 他判"今天这种复盘方式，副作用小"。
- 与 12.1 的关系：12.1 回答"护盘到了什么级别"，本节回答"这次护盘干得漂不漂亮"，评估维度不同，需分别记录。

### 12.6 大盘分时：权重×题材的组合观察 `[核心]`

> 依据公开文章整理。每日复盘的固定视角：**权重搭台、题材唱戏**（2024-02-22《结构良好，不言顶》等多篇），
> 与 12.4（止跌推进顺序）同为盘面结构观察，角度不同：12.4 看止跌流程，本节看**权重×题材的日内组合**。

```text
四类组合（按公开复盘归纳）：
① 权重领涨、题材跟涨 → 赚钱效应在权重蓝筹（机构主导的行情）
② 题材领涨、权重搭台 → 赚钱效应在题材小票（"权重搭台、题材唱戏"，短线最爱）
③ 权重稳、题材弱或退潮 → 老题材退潮信号，撤离高位题材股、谨慎观望
④ 题材强、权重被吸血走弱 → 存量博弈的跷跷板（你强我弱），上涨不可持续
   （"游资小票远远强于机构大票……如果剪刀差不改善，上涨无法持续，小心回落"——复盘固定注记）
```

**公开锚点**：
- "游资止不止盈，看两点：**权重的台子是否稳住，题材高标是否松动**"（2025-01-09《弱势波段怎么做》）
- "做权重的资金出来，如果顺利切到小票里，那短线情绪也不会恶化"（每日复盘）
- "抱团与主线行情是跷跷板，当两个都强的时候，必定有一个要被淘汰出局"（2024-03-12）
- 权重是市场的台子——"权重的台子没搭好，游资则会更倾向于等节后再干活"（2024 复盘）；
  权重持续走弱被吸血时，题材行情也难持续。

```text
用法：分时只是看盘的一个维度，还要结合当下市场高标、领头权重的表现综合分析。
无增量资金时，板块与题材权重之间是存量博弈（跷跷板）；判断分歧程度用剪刀差三档
（>0.5% 存在分歧 / >1% 分歧较重 / >2% 分歧严重，见八章）。
```

### 12.7 护盘的动机层：为什么要托（2026-10-16 ~ 10-23，三层）`[核心]`

> 12.1-12.6 回答"怎么护、护得怎样"（力度 / 顺序 / 结构 / 质量），本节回答**为什么必须托**——
> 这是体系里此前缺的一层（38 章的"融资"全部是融资余额语义，与本节的"融资功能"不是一回事，勿混）。

```text
动机 = **融资功能**：市场要承担"给新质生产力融资"的职能，指数表现太难看就交代不过去
判据（可数，不需主观判断）：**核心宽基抹平年内涨幅** = 触及底线
  2026-10-16："科创50 抹平年内涨幅……再跌不好交代，就这样的表现还想融资？"
  2026-10-20："科创指数已经抹平年内所有涨幅，在十五五开局之年、新质生产力发展的融资大年，
             实属不该出现这样的景象"
IF 指数抹平年内涨幅 THEN 护盘动机显著增强（不必等更深的跌幅）
IF 目标是"融资大年" THEN 护盘的隐性下限被抬高——不是技术支撑，是任务约束
```

- **两次出现、措辞不同但同指**（10-16 / 10-20），已非 `[单源]`。第一次的落点是"再跌不好交代"，
  第二次加了**年度语境**（十五五开局、融资大年），说明这是**跨年份都成立的动机**，不是一次性说辞。
  **第三次出现（10-23）**："毕竟爷们儿要脸，出去给人家打招呼拉投资，
  不能给人家说咱们核心资产的优势是便宜吧" —— 同一动机的"面子"表述，三次措辞各异，可当稳定动机用。
- 与 47 章"守 3800 = 提供流动性与信心"互为表里：47 章讲**手法与位置**，本节讲**动机与底线**。
- ⚠️ 不要把"动机强"读成"必然护起来"——动机只说明**有意愿**，效力上限见 12.8 与 49.5。

**第二层 · 当下动机＝补充流动性（2026-10-21）**：
```text
IF 全球科技补跌正在向 A 股传导 THEN 护盘的当下目的 = 补充流动性（对冲传导），不一定是"护指数点位"
与第一层的关系：融资功能是**中期/制度性**动机（任何时候都在），
  补流动性是**当下/事件性**动机（有外部冲击时才凸显）——两者并存，不互相替代
```

**第三层 · 标的层动机＝核心资产定价权（2026-10-22）**：
> 前两层回答"为什么买"，这一层回答"**买什么**"。

```text
观察：移动/腾讯/福耀/格力/宁王等蓝筹白马被爆杀（宁王单日跌十几个点、拖累创业板 41 个点）
他的判读：蓝筹白马 = 中国核心资产的定价权所在
  "这就不难看出为什么近期放量的 ETF 几乎上证50占大头了"
IF 定价权所在的核心资产被集中抛售 THEN 护盘只能在上证50 那一侧接，而不是平均撒到所有宽基
```
- 与 12.2（出手顺序）互为因果：12.2 是**观察到的顺序**，本层是**顺序之所以如此的原因**；
  12.2 附注再把顺序反用为"我的安全垫排序"。三节要一起读。
- 与 17.1 附注（抛售按可变现性）是同一枚硬币的两面：**卖方卖最能卖的，买方买最不能丢的**。

### 12.8 护盘的代价：路径依赖、外部性与周期上限（2026-10-13 ~ 10-22，五条）`[重要]`

> 12.5 评估"这次护得好不好"，本节评估"**长期靠护盘这件事本身的代价**"。三层递进，须成对理解。

```text
① 路径依赖（2026-10-13）：护盘可加速磨底，但"以后每次见底都需要护盘"
   → 一次性收益（底部更快出现）换永久成本（市场自我修复能力被替代）
② 自发磨底优于护盘磨底（2026-10-13）：
   "不吃药自己好" = 免疫力；参照美股少有护盘、跌完自己走回来
   → 同为见底，**自发磨底的底部更扎实**（对应 12.3：护盘驱动不判定为止跌）
③ 周期上限与"留空间"（2026-10-19）：护盘不是无限托底——
   "后面市场好了起来，又会慢慢回落，**为下一次护盘创造空间**"
   → 护盘—上涨—回落的循环是**设计出来的**，不是市场自然波动
   → 操作含义：跌到平台才买、涨上去不追；买点由这个循环反复给出，不是一次性的
④ 弹药回收的时机（2026-10-21）：③讲的是**价格维度**的留空间，本条是**弹药/时点维度**——
   趁情绪尚可时回收弹药，为下一次护盘留余地；不回收则走 V 之后摔得更深
   → 护盘的"退出"与"进场"一样需要择时，不是护完就结束
⑤ 成为量化的免费流动性（2026-10-22）：护盘资金自身的买入构成了程序化资金的对手盘——
   "今天的走法是先买再卖……尾盘最后几分钟，市场没啥成交量的时候直接通吃扫货，又进了几十亿，
    不过最后触发量化给砸下来了""毕竟白给的流动性，量化如鱼得水，我看得确实如鲠在喉"
   → 护盘提供的流动性会被反向收割，**护盘越果断，给量化送的弹药越稳定**
```

- 与 41 章"市场制度体质观"（"越是靠打针活的市场越容易出问题"）同族，但 41 章是**判断**，
  本节是**代价的可操作含义**（买点来源、底部质量、永久成本）。
- ⚠️ ①~④ 都指向"护盘不可永续"，但**不构成做空理由**——失手门槛见 47 章"龙哥失手门槛"。
- ⚠️ **⑤ 与 26.4「缩量异动拉升→砸盘＝收割流动性」方向相反，不要合并**：
  26.4 是**主动收割**（有人借缩量拉升诱多再砸），⑤ 是**被收割**（护盘的钱被量化当对手盘）。
  同一个"尾盘扫货后被砸"的盘面，用哪一条解释取决于**谁是先动手的那一方**。
