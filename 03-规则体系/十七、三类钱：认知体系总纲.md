## 十七、三类钱：认知体系总纲 `[核心]`

来源：认知篇系列 20250213/0216/0222。他的认知地基：金融市场归根结底都是赚别人的钱，分三类。

| 三类钱 | 定义 | 关键认知 | 对应打法 |
|---|---|---|---|
| **增量资金的钱** | 赚后进场的人抬价的差价 | 股市长期(3-5年)是经济晴雨表，**中期(1年)是货币的晴雨表**（实际流入股市的钱） | 盯货币政策/宏观/机构运行；三年不开张开张吃三年 |
| **公司价值的钱** | 机构之间传故事，在故事戳破前退出 | 实体里公司好坏是客观的，金融市场上是主观的；"金融市场是社会学不是科学" | 功夫在盘外：股东研究、研报学逻辑、机构五类买入理由 |
| **市场情绪的钱** | 博弈差价：机构/游资/交易者赢，羊群掏钱 | 情绪是相对的不是绝对的；强者恒强 | 情绪周期定位 + 龙头识别 + 纪律 |

**增量资金传导链**：放水 → 银行/国债 → 第一批=金融机构、企业、杠杆资金 → 大涨后第二批=股民基民跑步进场 → 几股传花 → 机构途中止盈但横盘不掉头 → **增量枯竭 = 牛市结束**（2020-21 例；2022 美元 4% vs 国内 2.75% 外资搬家的利率逻辑）。

**机构六大类**：龙队/公募/私募/险资/外资/其他资管。公募占比最多**最不稳定**——基民集中赎回→基金被动砍仓→越跌越赎的负反馈，此时基本面再好也没用（医药 2020-21 抱团瓦解例）。机构的政策驱动/科技突破两类买入**必须等业绩证伪**，否则只当短期炒作。

### 17.1 市场参与者与"称重机 vs 投票机" `[核心]`

> 来源：2026-03-17《人们在害怕什么》（"股市短期是投票机……妖股就是资金投票的结果。股市长期是个称重机"）；2025-09-19（价值发现/价值认同语境）；2025-10-10（"风来的时候猪都能飞起来……有翅膀的不会掉下来"）。是认知篇的**参与者结构版**。

```text
"短期投票机，长期称重机"（他的用法）：
投票机：涨停/连板妖股是资金投票选出来的——炒作要有东西可炒（事件/业绩/政策）
  妖股的生命周期由资金接力决定；龙头不是算出来/分析出来的，是一步一步走出来的
称重机：长期只看真东西——有业绩/专利/地位的公司跌了能涨回来
  "4月份是A股法定的上称月份"（2026-04-28）——年报期就是称重时刻：
  有分量的重新投票定价，不值分量的资金大幅撤离
参与者光谱（价值发现→价值认同→趋势跟随→盲目跟风）：
  首先发现价值的人把底买出来（2025-09-19 现场语境：煤炭板块被无视时，
  "市场资金，还是有不少认同咱这个价值发现者的观点"）
  盲目跟风者（247 篇语境）在加速上涨见顶时占比最多——情绪驱动、无体系、随大流
选股方向：中长线投资 = 寻找有翅膀的公司（"风来的时候猪都能飞起来，但是风停了之后，
  有翅膀的不会掉下来……没翅膀的哪儿来的回哪去"2025-10-10）
IF 做投资 THEN 买入和持有的理由是基本面；设基本面止损（买入逻辑改变=离场，
  不论浮亏浮盈）
```

**【附注】流动性挤兑下的抛售顺序：按可变现性，不按基本面（2026-10-22 + 10-23，两次出现）**：
> 承接本章开头"机构六大类"里的**基民集中赎回→基金被动砍仓→越跌越赎**。那条讲**负反馈本身**，
> 本附注讲**负反馈砸出来的是什么货**。

```text
被动砍仓/挤兑式卖出的排序依据 = 权重与流动性（好不好卖），不是基本面（该不该卖）
  2026-10-22：砍出来的是蓝筹白马/核心资产（移动/腾讯/福耀/格力/宁王）
  2026-10-23："市场已经没有流动性了，为什么杀白马，因为在成长里面的已经被套完了"
             —— 白马蓝筹成了"血包"：成长里的已套死，白马是唯一还卖得掉的
阶段判读：七月八月是"杀估值"（几百千倍市盈率，跌一跌正常）→ 后期转为"杀白马"
IF 盘面从杀高估值转为杀白马 THEN 说明卖出方已从散户切到机构，且流动性已近枯竭
  （"蓝筹从拖后腿的老登变成血包"＝这一切换的通俗标志）
IF 处于该阶段 THEN 不要用"基本面有没有问题"解释白马下跌——它是被当现金用的
```
- 与 23.1（流动性第一性原理）、12.7 第三层（定价权）配套：**卖方卖最能卖的，买方买最不能丢的**。
- ⚠️ 这不构成"白马跌出价值就买"的充分条件——挤兑末端才谈承接，止跌判据仍走 1.x 与 49 章。


### 17.3 世界观的底座：人性 > 基本面 / 技术面（2026-10-15）`[核心]`

> 这是他认知体系的**最底层陈述**（此前 01/02 章族只零散出现，未立条）。定位：世界观，不是操作判据。

```text
层级：**人性 > 基本面 / 技术面**
驱动变量：人性的驱动变量是**利益**（不是情绪、不是理性、不是数据）
推论 ①：基本面与技术面都是**人性的表达**，所以两者同时失效时，去看利益格局谁在受损/受益
推论 ②：制度、政策、资金行为，最终都要通过"人的利益"这一层才落到价格上
```

- ⚠️ **写作纪律**：本节属**世界观层**，不与操作判据混编——不能从"人性"直接推出买卖动作，
  它只用于**解释**（为什么明显的基本面利好不涨、为什么护盘时有人反手砸）。
- 与 17.1（投票机/称重机）、17.2（钱在谁手里）构成"认知三层"：**谁在投票（17.2）→ 投的是什么（17.1）→ 为什么这样投（17.3）**。

### 17.4 生态位的不对称：制造结果 vs 预测结果（2026-10-23）`[核心]`

> 17.1 讲"投的是什么"、17.2 讲"钱在谁手里"、17.3 讲"为什么这样投"；本小节讲**位置**——你在链条的哪一端。
> 来源全部是公开复盘（2026-10-23），**不引用任何内部数据**。

```text
"你是预测别人的操作，期望拿到别人的结果，但是人家直接就是制造结果的人"
两层博弈：
  制造结果的一方：用自己的成交把价格做出来，他们的动作本身就是价格（大资金/龙哥）
  预测结果的一方：只能从别人留下的成交痕迹里推断（绝大多数参与者），必然滞后
推论 ①：所有"跟着龙哥做"的策略都是**二阶推断**——推断别人的推断，天然滞后且可被反用
推论 ②："真正牛逼的操作是不需要做 T 的，出手就见成效了"
  → 反复做 T 说明买点选错、靠折腾补成本；好操作是一次到位
推论 ③：在流动性/工具都不占优的品种上做日内博弈，是用**劣势位置**去猜别人的结果
IF 想提高胜率 THEN 换位置（去自己占优的时间尺度或品种），而不是在劣势位置上更努力
```

- **结构性矛盾**：流动性贡献最大的一群人，恰恰是定价权最小的一群人——**贡献波动 ≠ 获得收益**。
- 与 17.3 的分工：17.3 是世界观（人性驱动），本小节是**位置感**（我在链条哪一端）。
  17.3 明令"不与操作判据混编"，本小节不受此限——它直接推出操作含义（推论 ②③）。
- 与 41.3（龙哥＝分布式执行体）互为表里：那条讲**他们为什么不可预测**，本条讲**我们为什么只能推断**。
- 与 52.5（用入场方式反推风偏）、52.7（行为三段）配套：生态位决定"该用什么方式"，不决定"该不该参与"。
