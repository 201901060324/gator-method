## 十四、下跌幅度与左侧买入 `[核心]`

来源：2025-11-21《不恐慌，怎么捡便宜》

### 高位抱团的杀跌幅度

```text
第一轮下跌：质量好的公司跌 20%–30%；纯炒作没质量的跌 30%–50%
第二轮下跌：漫漫阴跌，腰斩再腰斩，少数走震荡
（若在新一轮行情中被资金重新选中，则可整体反弹，少数还能新高）
```

**补充：跌幅的归因优先看"前期涨幅"，不是看"单一事件"（2026-10-20）`[单源]`**：
```text
"更惨跌幅已经来到去年八月份的位置……除了易中天带来的大撤退，更多因素还是因为超涨带来的后遗症"
IF 某指数/板块跌幅巨大 THEN 先问它前面涨了多少（超涨 → 回吐是本因），再找触发事件
IF 把跌幅主要归因于某个具体事件 THEN 通常会高估该事件的作用、低估涨幅本身的均值回归压力
```
- 与"高位抱团的杀跌幅度"配套：本节讲**幅度区间**，补充条讲**弹性来源**。

### 长线左侧操作三点

1. **分批、做间隔、做分散，不单押**
2. **轻走势，重质量**
3. **别恐慌，耐心拿**

```text
IF 情绪已杀到冰点 THEN 机会大于风险（但他仍要求"仓位别上太急"）
IF 被错杀、估值杀到地板价的板块 THEN 是长期资金的首选方向
```

**"跌到平台"＝长线买点的技术触发位（2026-10-16）`[重要]`**：
```text
"跌到平台了捡便宜" —— 平台是技术面的触发位，不是估值位
IF 做长线左侧 THEN 等价格回到**前一个平台**再加，不看估值分位触发
（他举例：猪、保险，都是"跌到平台"才动手）
```
- 与本节三点的关系：三点讲**怎么买**（分批、重质量、别恐慌），本条讲**在哪买**（平台位）。
- 与 22.4"基本面决定做不做、技术面决定怎么做"一致：基本面只负责筛选，**下手位置由技术面给**。
