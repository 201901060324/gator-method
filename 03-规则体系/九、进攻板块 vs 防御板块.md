## 九、进攻板块 vs 防御板块 `[核心][分类表]`

来源：复盘底部的板块属性注释（每篇都有）。

- **进攻板块**：半导体、人工智能、食品饮料、汽车、光伏、风电、锂电、金属化工、地产、证券等，与经济发展密切的行业
- **防御板块**：高股息（煤炭、电力、银行）、中字头、农业、养殖、军工
- **属性模糊**：医药（现阶段既非进攻也非防御，领涨无明显指向性）

```text
IF 进攻板块领涨 THEN 资金积极乐观
IF 防御板块领涨 THEN 资金谨慎或消极
```

⚠️ 他说过：攻防划分会随经济发展与行情变化变动，通常一年内不会有大的变化。

**气氛组证券的分级判定**（比"有无涨停"更细）：
```text
板块涨多跌少 + 有涨停  → 及格
涨停数量越多           → 情绪越积极，上涨越有持续性
无涨停但整体上涨       → 不及格（2025-04-02、2025-04-08 均判"无涨停，整体上涨"）
```
