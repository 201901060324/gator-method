### 53.2 算法构成（2026-10-09 首次披露）`[重要]`

```text
结果 = 四层处理：正交化提纯 → 环境自适应动态分配权重因子 → 多周期共振 → 因果校验
```

- 即该模块**不是简单加权打分**，而是带正交去相关 + 自适应权重 + 跨周期 + 因果校验的多层处理。
- ⚠️ 结合 53.4 的实例可推断：**正交化并未完全消除分项共线性**（ETF 资金项仍能单独抬高总分）。

### 53.3 等级体系与判读 `[重要]`

```text
等级含义 = "过去的市场情况 + 当天的市场情况应该做什么"（面向操作的读数）
等级判读看**连续性**，不看单日——"如果连续持续 C 级就是比较悲观的时候了"
等级变动的归因：如 S → C 的跳变要先查"是不是资金表现的结果"（单因子也能导致跳变）
```

**C 级的语义澄清（2026-10-15，首次明确定义）`[核心]`**：
```text
"等级 C 级是说**市场操作难度**是 C 级，**不是 C 级就很差、很多不能做**"
→ 等级衡量的是**操作难度**，不是**市场好坏**：C 级 = 难做，不等于没机会
IF 读到 C 级 THEN 解读为"要求更高的选股与节奏"，不解读为"清仓信号"
```
- ⚠️ 这是自 9-29 引入等级体系以来最容易误读的一处，**必须与"连续性"规则一起用**：
  连续 C = 难做的环境持续；单日 C = 只说明当天不好做。

### 53.4 判读纪律（最重要）`[核心]`

```text
① 等级为准、评分必查分项：
   IF 等级与评分方向不一致 THEN 检查评分是否被单一分项（如 ETF 资金流入）抬高
   ——评分不代表整体环境改善
   实例：2026-10-08 等级 C + 多空 58 分，他自述"拉高分数的主因是 ETF 资金大幅流入"
② 分数两端才是触发点：
   IF 分数逐渐增加 OR 降低到非常低 THEN 可以动手
   IF 分数处于中间区域 THEN 不构成信号（适用"大级别宽幅震荡"环境、面向不爱追涨杀跌者）
③ 与人工规则的接口：多信号交叉提高准确度（见 46 章末补充）、图形≠信号（见 26.4）。
④ **等级跳升 ≠ 趋势反转**（2026-10-14）：
   "虽然还是弱趋势，但是各项指数都在提高" —— 等级（操作面向）与趋势（环境判断）是**两个层**
   IF 等级跳升 THEN 只更新"能不能动手"，不改"牛市/熊市"的环境定性
⑤ **"无新信号"是弱震荡的证据，不是中性**（2026-10-14）：
   "上次空头信号给出以后就一直没有新的信号出现，这也是现在弱势震荡市场的写照"
   IF 信号长期空窗 THEN 判为弱震荡（多空都无力），不判为"环境正常"
⑥ **外围恐慌与内部评分可以背离**（2026-10-15）：
   "市场恐慌度拉满了，但是由于市场结构变化，评分还在逐渐增加"
   → 评分看的是**内部结构**，不看外围情绪；两者背离时以结构为准（但须按 ① 查分项）
```
