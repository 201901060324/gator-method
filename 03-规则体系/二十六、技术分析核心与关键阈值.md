## 二十六、技术分析核心与关键阈值 `[核心][可计算]`

来源：20250519《技术分析的核心》、20240922、20260415。

### 26.1 K 线语言四核心（20250519）

```text
① 前兆信号 vs 确立信号：放量加速=见顶前兆（可分批止盈/持有/博鱼尾）；
   见顶确立=放量大跌 / 非自然回撤 / 三日或长时间横盘不新高 → 确立信号出现，持仓全清
② K线会说谎（突发事件与人为操控）→ 接受不确定性，做大概率的操作
③ 理性比经验重要：IF 历史经验与当下盘面冲突 THEN 以当下盘面为主
   大资金建仓三痕迹：大跌后放量 / 历史低位横盘 / 周K级别箱体突破
④ 分强弱找拐点：大跌后的横盘机会多，大涨后的横盘风险多
   IF 大跌后连阳放量上涨 THEN 弱转强=拐点
```

**【附注】见底侧对偶：加速赶底＝杠杆出清末端，用镜像法读（2026-11-17）`[重要]`**
> 本节 ① 只有**顶部那一半**（放量加速＝见顶前兆）；本附注补齐**底部那一半**。

```text
见顶侧（既有）：放量加速上涨 → 见顶前兆 → 见顶确立＝放量大跌
见底侧（新增）：加速下跌 → 杠杆/清盘筹码集中出清的末端 → "加速了离见底就近了"
方法（镜像）：同一标的的顶底形态互为镜像，把顶部图倒过来看即得底部图
IF 出现加速下跌 THEN 只判方向（离底更近），**不判天数**（他明说"无法判断跌几天"）
```
- ⚠️ 与 17.1（赎回启动后才进入加速下跌段＝筑底最后一程）分工：那是**赎回链**，本条是**杠杆/清盘链**；
  两条链可同向叠加，但驱动不同，不可合并。
- ⚠️ 与 26.4（缩量判读）语境相反：加速赶底一般是**放量下跌**，套用"缩量"结论会读反。


### 26.2 数字阈值汇总 [可计算]

```text
指数单日涨跌 > 2%           = 异常波动，找拐点（多数时候在 2% 以内）
指数技术性牛熊（20261013 直播）：从最近一轮低点涨 ≥20% = 技术性牛；从高点跌 ≥20% = 技术性不牛
                              （下跌波次分界节点；数波次从中枢（区间平台）起算更科学，见 43.5）
上证50 单日跌 ≤1.5%         = 权重稳住，题材可继续炒；>1.5% = 大跌，题材炒作难以为继
创业板大跌后当日收涨 >2%    = 弱转强买入信号；填坑中 >2% = 强者恒强；
                              填坑完成后或大涨后 >2% = 加速见顶卖出信号
沪深300（指数ETF体系，20250308）：
  PE ≤12 定投；≤10 极端低估加仓；≥15 开始止盈；≥17 全部止盈或只留底仓
  IF 经济数据明显改善 THEN 15 倍不算高（抬估值）
恒生AH溢价（5年维度，20250526）：接近 160 = 港股阶段低点；接近 120 = 港股阶段高点
  （⚠️ 他自注：10年维度出现过 <100，此规律会失效，仅 5 年维度总结）
单边上涨需主动性买盘 6%–7%（3% 不支持）；基差接近 0~3 才是"多头推着空头打"
弹性品种须有至少 50 个点空间；突破确认看 3 天；缺口=多空发力的第一目标位
```

### 26.3 缺口与节奏（20240922/20260415）

```text
IF 上方有跳空缺口 AND 市场结构好 THEN 冲高第一目标=补缺口，补完再博弈
IF 市场信号走弱 THEN 空头第一个动作=补缺口
IF 连续上涨 AND 盘中低点碰不到 5 日均线 THEN 要么回踩要么挨巴掌
IF 创业板冲高 AND 上证跟上 THEN 节奏健康；IF 创业板独走 THEN 结构牛走不远
   （"先锋往上冲，大部队慢慢跟上"）
```

**附注：资金周期与观察周期必须匹配——分时的强 ≠ 趋势进场，填坑才是趋势客的减仓点（2026-11-09）`[核心]`**：
```text
原话："短期资金很多昨天进、今天出"→ 分时上蹿下跳；
      "做趋势的投机客多数看日 K，他们要走，也是等坑填了、或者逼近填了才会做考虑"

同一张盘上，不同持仓周期的人在看不同周期的图，卖出触发点完全不同：
  短线资金 → 看分时 → 昨进今出 → 分时的强是**他们快进快出的痕迹**，不是趋势资金进场
  趋势资金 → 看日 K → 减仓观察点＝**缺口填完或接近填完**（即 26.3 主条的"第一目标"）

IF 分时走强 AND 缺口未填 THEN 不构成趋势级买入依据（"看分时走得好而追涨的，会比较难受"）
IF 缺口填完/接近填完 THEN 才是趋势仓考虑减仓的位置，而不是反弹一开始就走
```

- ⚠️ **勿并入 26.4"图形 ≠ 信号"**：26.4 讲图形本身不可靠，本附注讲**周期错配**——同一张盘被两类人读出相反结论；
  一个是"看错"，一个是"看对了但不是你的周期"。
- 与 26.3 主条的关系：主条给**价位**（补缺口是第一目标），本附注给**行为映射**（谁在看这个价位、看到之后做什么）。

### 26.4 缩量判读与"图形 ≠ 信号"（2026-09-29）`[重要]`

**缩量的读法**（否定项 + 因果链）：
```text
IF 大幅缩量 THEN = 大资金无心恋战 → 次日"大涨和大跌都不容易出现"
IF 缩量后却走出大涨 THEN 判为量化把戏、无持续性
（量化砸超跌 → 散户割肉 → 资金抢反弹，是同一个资金闭环）
```

**缩量的第二个分支："主动等待"（2026-10-14）`[重要]`**：
```text
分支 A（上面这条）：缩量 = 没钱 / 救不动 / 无心恋战 → **弱势**
分支 B（本条）：缩量 = 时机未到，不是没钱、也不是救不动 → **主动等待**，条件到了"开仓放粮"
```
- ⚠️ **两个分支必须并列，不能合并**——合并会把相反的结论压成一条，读出来一定是错的。
- **区分口径**：看"有没有护盘能力 / 有没有等着的信号"。
  有护盘能力且信号未到 → 分支 B；护盘也护不动、资金真实撤离 → 分支 A。
- 与 26.3 缺口节奏、24.5 会议日历配合：分支 B 的"时机"往往挂在某个可预期的日期上（会议/数据/事件）。

**缩量的第三个分支："跟风盘"读法（2026-11-05）`[核心]`**：
```text
上面两个分支回答的都是"缩量说明什么"，本分支回答"**缩量之后谁在买、拉升难不难**"——进攻性读法。

IF 缩量 + 低开 + 多数人认为反弹不可持续 THEN 跟风盘少 → 大资金拉升成本低 → **反而涨得更快**
IF 放量 + 冲高 + 多数人认为反弹能持续 THEN 跟风盘多 → 短线大资金趁放量止盈做 T、
   把货出给追高的散户 → **反而容易震荡回落**
核心变量：不是量本身，是**跟风盘的多少**（对手盘的构成，不是水位）
```

| 分支 | 缩量的含义 | 结论方向 |
|---|---|---|
| A（2026-09-29） | 没钱 / 救不动 / 无心恋战 | 弱势 |
| B（2026-10-14） | 时机未到，不是没钱 | 主动等待 |
| C（2026-11-05） | 跟风盘少，拉升便宜 | **偏强（易涨快）** |

- ⚠️ **三个分支必须并列，不能合并**：A 与 C 的字面结论相反（缩量=弱 vs 缩量=易涨），
  合并成一句必然被读反。区分口径：A/B 看**有没有护盘能力与信号**，C 看**对手盘稠不稠**。
- 与 49.7 附注二（护盘缺席仍涨=自发买盘）配合：C 是它的微观机制——跟风盘少，所以少量买盘就能拉动。

**分支 C 的后续路径：放量冲高回落之后是"砸完继续涨"，不是反弹结束（2026-11-12）`[核心]`**：
```text
原话（11-12 冲高回落当日）："今天这种冲高回落，在上周的阳谋里就有提到，散户不买，就涨得快一些。
  散户一窝蜂冲进来，就震荡砸一下。今天放量两千多亿，跟 5 号早上的放量一个逻辑，
  短期获利盘先砸为敬，砸完之后，后面再继续涨"

IF 放量 + 冲高 + 追高盘涌入 THEN 回落归因为**短期获利盘止盈**，不判为反弹结束
IF 回落之后反弹结构未破 THEN 后续仍看续涨（他次日仍称"这波反弹连一半都没走到"）
同类样本锚：11-05 早上的放量（他自己点的"一个逻辑"），不是孤立个案
```

- ⚠️ **前置条件不可省**："砸完继续涨"成立在他"反弹结构未破"的判断之上；剔掉前提会变成
  "放量回落必然续涨"，那是错的。
- ⚠️ **与本节"缩量异动拉升 → 砸盘＝收割流动性"（2026-10-12）方向相反，区别在量**：
  **缩量**下的拉升是收割（砸了更差、抛压更多）；**放量**下的冲高是换手（获利盘走、跟风盘接，砸完还能涨）。
  两条必须各自带量能前提，摘句混用必读反。
- 与 17.4 阳谋附注配合：分支 C 讲"为什么回落"，本附注讲"回落之后怎么走"，阳谋讲"为什么他敢这么判断"。

**图形 ≠ 信号**（否定"看图定胜负"）：
```text
IF 两个标的/两个时点的 K 线形态相近 THEN 不必然得到相同判断
—— "K线差不多，但是信号判断不一样"：判断发生在信号层，图形只是载体
```

**缩量下的"异动拉升 → 砸盘"＝收割流动性（2026-10-12）`[重要]`**：
```text
IF 大幅缩量 AND 出现异动拉升 THEN 不判为转好，判为量化/短线资金收割流动性
IF 拉升后紧跟砸盘 THEN 抛压反而更多（抄底盘给了希望再失望，是延迟出清的负担）
```
- 原话："都缩量成这样了，还靠异动拉升，再砸盘来收割流动……**我们做空的都讲究个不赶尽杀绝**，
  有些资金真的是**杀鸡取卵**，**规矩没立住，把路走窄了**。"
- ⚠️ **交易伦理观**（`[单源]`，2026-10-12 首次出现）：他评价资金行为时带**市场生态可持续性**维度，
  给自己的做空划了"不赶尽杀绝"的边界。此为价值观陈述，不构成可回测规则，**单独登记、不与上面判据混编**。

### 26.5 非自然回撤（趋势股见顶/离场信号） `[核心][可计算]`

> 依据公开文章整理。术语在他公开复盘中直接使用（2024-03-19/03-20、2024-05-22、
> 2024-08-20、2025-02-07、2025-02-20、2025-06-12 共 7 篇），并被列为
> **趋势股的见顶/离场信号之一**。26.1 已将其列入"见顶确立信号"，本节是使用要点。

```text
定义性使用（公开原句）：
- "昨晚专门讲了趋势股的三种见顶信号：三日不行高、放量加速、非自然回撤"（2025-02-07）
- "离场信号就是趋势股的四种止盈方式：放量加速、放量大阴线、非自然回撤、三日不新高"（2024-08-20）
- "下午很多地产冲高回落，甚至走了非自然回撤……鱼尾行情也有肉，吃还是不吃，
  看个人的策略"（2024-05-22）

使用要点（按公开复盘归纳）：
① 出现非自然回撤 ≠ 行情一定结束，属危险信号；配合"三种见顶信号"共同观察
② 适用对象：趋势股与主线领头羊——"当一个主线的领头羊，开始出现较强亏钱效应
   的时候，也意味着炒作接近了尾声"（2025-06-12）
③ 任何主线都有正常回调："只要是正常回调，不是非自然回撤，没到止损的情况下，
   都不必着急离场"（2024 复盘）——注意区分正常回调与非自然回撤
④ 祖师爷纪律（公开多次引用利弗莫尔）："看到危险信号，先离场，如果危机解除，
   随时可以再进场"
```


### 26.7 趋势的能量定义与单边市场的踩踏机制（2026-10-20）`[核心]`

> 26.1-26.6 全部是"怎么度量"（K 线语言 / 阈值 / 缺口 / 缩量 / 回撤 / 强弱 12 条），本节补**定义层**：
> 趋势本身是什么。这是体系里此前没有的一层。

```text
趋势 = 趋（方向） + 势（能量）
  "趋就是方向，势就是能量，**方向是由能量决定的**"
能量的定义：不是"看多的人数"，而是**有定价权的资金**站在哪边
  （"看涨的人多（尤其是具有一定定价权的机构们就涨），看跌的人多就跌"）
推论 ①：散户情绪不构成能量，只能构成噪声——能量要按"谁有定价权"折算
推论 ②：判断方向之前先判断能量归属（机构/游资/龙哥/杠杆），方向是能量的结果，不是原因
```

**单边做多市场的踩踏机制（同一段话的第二层）**：
```text
在市场结构只能做多的前提下：
  多次踩踏 + 多次行情拉扯不清的"混沌行情" → 持仓者把"风险"当第一变量
  → 一有风吹草动就集体踩踏（不是因为利空大，是因为无处对冲）
推论：**A 股的跌幅不能直接与外围对标**，同一利空在单边市场里的杀伤力更大
   （对照 24.6 第 4 问：量级不匹配时，原因在结构不在事件）
```

- **与 26.6 的分工**：26.6 给"多强多弱"的打分表（12 条），本节给"强弱从哪来"的来源解释。
  两者不重复，**不要合并**。
- **与 46 章的分工**：46 章讲"同一信号在不同环境下含义相反"（用法层），本节讲"方向由能量定"（来源层）。
- 操作含义：能量在谁手上 → 决定用趋势打法还是震荡打法（21.5）；能量发生转移 → 才谈主线更替（50 章）。

**【附注】空头侧对偶：反弹初期最大买盘＝空头集中回补（2026-11-19）`[重要]`**
```text
26.7 主体（多头侧）：只能做多 → 风吹草动集体割肉 → 下跌负反馈踩踏
本附注（空头侧）：空平 → 上涨 → 更多空平 → 上涨（**正反馈踩踏**）
"反弹初期最大的多头，就是现在做空的资金"
IF 反弹启动 THEN 第一波大买盘可能来自集中平仓，不是新增看多资金
可观测：放量、跳空修复（前瞻登记，待后续样本验证）
```
- ⚠️ 与本节主体的负反馈**成对**，不要拆开引用：同一个"能量由平仓盘提供"的机制，方向相反。
- 与 19.3（胜率赔率反推）分工：本附注讲反弹买盘的**来源机制**，不构成出手信号本身。
