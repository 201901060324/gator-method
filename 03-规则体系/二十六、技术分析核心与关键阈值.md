## 二十六、技术分析核心与关键阈值 `[核心][可计算]`

来源：20250519《技术分析的核心》、20240922、20260415。

### 26.1 K 线语言四核心（20250519）

```text
① 前兆信号 vs 确立信号：放量加速=见顶前兆（可分批止盈/持有/博鱼尾）；
   见顶确立=放量大跌 / 非自然回撤 / 三日或长时间横盘不新高 → 确立信号出现，持仓全清
② K线会说谎（突发事件与人为操控）→ 接受不确定性，做大概率的操作
③ 理性比经验重要：IF 历史经验与当下盘面冲突 THEN 以当下盘面为主
   大资金建仓三痕迹：大跌后放量 / 历史低位横盘 / 周K级别箱体突破
④ 分强弱找拐点：大跌后的横盘机会多，大涨后的横盘风险多
   IF 大跌后连阳放量上涨 THEN 弱转强=拐点
```

### 26.2 数字阈值汇总 [可计算]

```text
指数单日涨跌 > 2%           = 异常波动，找拐点（多数时候在 2% 以内）
指数技术性牛熊（20261013 直播）：从最近一轮低点涨 ≥20% = 技术性牛；从高点跌 ≥20% = 技术性不牛
                              （下跌波次分界节点；数波次从中枢（区间平台）起算更科学，见 43.5）
上证50 单日跌 ≤1.5%         = 权重稳住，题材可继续炒；>1.5% = 大跌，题材炒作难以为继
创业板大跌后当日收涨 >2%    = 弱转强买入信号；填坑中 >2% = 强者恒强；
                              填坑完成后或大涨后 >2% = 加速见顶卖出信号
沪深300（指数ETF体系，20250308）：
  PE ≤12 定投；≤10 极端低估加仓；≥15 开始止盈；≥17 全部止盈或只留底仓
  IF 经济数据明显改善 THEN 15 倍不算高（抬估值）
恒生AH溢价（5年维度，20250526）：接近 160 = 港股阶段低点；接近 120 = 港股阶段高点
  （⚠️ 他自注：10年维度出现过 <100，此规律会失效，仅 5 年维度总结）
单边上涨需主动性买盘 6%–7%（3% 不支持）；基差接近 0~3 才是"多头推着空头打"
弹性品种须有至少 50 个点空间；突破确认看 3 天；缺口=多空发力的第一目标位
```

### 26.3 缺口与节奏（20240922/20260415）

```text
IF 上方有跳空缺口 AND 市场结构好 THEN 冲高第一目标=补缺口，补完再博弈
IF 市场信号走弱 THEN 空头第一个动作=补缺口
IF 连续上涨 AND 盘中低点碰不到 5 日均线 THEN 要么回踩要么挨巴掌
IF 创业板冲高 AND 上证跟上 THEN 节奏健康；IF 创业板独走 THEN 结构牛走不远
   （"先锋往上冲，大部队慢慢跟上"）
```

### 26.4 缩量判读与"图形 ≠ 信号"（2026-09-29）`[重要]`

**缩量的读法**（否定项 + 因果链）：
```text
IF 大幅缩量 THEN = 大资金无心恋战 → 次日"大涨和大跌都不容易出现"
IF 缩量后却走出大涨 THEN 判为量化把戏、无持续性
（量化砸超跌 → 散户割肉 → 资金抢反弹，是同一个资金闭环）
```

**图形 ≠ 信号**（否定"看图定胜负"）：
```text
IF 两个标的/两个时点的 K 线形态相近 THEN 不必然得到相同判断
—— "K线差不多，但是信号判断不一样"：判断发生在信号层，图形只是载体
```

**缩量下的"异动拉升 → 砸盘"＝收割流动性（2026-10-12）`[重要]`**：
```text
IF 大幅缩量 AND 出现异动拉升 THEN 不判为转好，判为量化/短线资金收割流动性
IF 拉升后紧跟砸盘 THEN 抛压反而更多（抄底盘给了希望再失望，是延迟出清的负担）
```
- 原话："都缩量成这样了，还靠异动拉升，再砸盘来收割流动……**我们做空的都讲究个不赶尽杀绝**，
  有些资金真的是**杀鸡取卵**，**规矩没立住，把路走窄了**。"
- ⚠️ **交易伦理观**（`[单源]`，2026-10-12 首次出现）：他评价资金行为时带**市场生态可持续性**维度，
  给自己的做空划了"不赶尽杀绝"的边界。此为价值观陈述，不构成可回测规则，**单独登记、不与上面判据混编**。

### 26.5 非自然回撤（趋势股见顶/离场信号） `[核心][可计算]`

> 依据公开文章整理。术语在他公开复盘中直接使用（2024-03-19/03-20、2024-05-22、
> 2024-08-20、2025-02-07、2025-02-20、2025-06-12 共 7 篇），并被列为
> **趋势股的见顶/离场信号之一**。26.1 已将其列入"见顶确立信号"，本节是使用要点。

```text
定义性使用（公开原句）：
- "昨晚专门讲了趋势股的三种见顶信号：三日不行高、放量加速、非自然回撤"（2025-02-07）
- "离场信号就是趋势股的四种止盈方式：放量加速、放量大阴线、非自然回撤、三日不新高"（2024-08-20）
- "下午很多地产冲高回落，甚至走了非自然回撤……鱼尾行情也有肉，吃还是不吃，
  看个人的策略"（2024-05-22）

使用要点（按公开复盘归纳）：
① 出现非自然回撤 ≠ 行情一定结束，属危险信号；配合"三种见顶信号"共同观察
② 适用对象：趋势股与主线领头羊——"当一个主线的领头羊，开始出现较强亏钱效应
   的时候，也意味着炒作接近了尾声"（2025-06-12）
③ 任何主线都有正常回调："只要是正常回调，不是非自然回撤，没到止损的情况下，
   都不必着急离场"（2024 复盘）——注意区分正常回调与非自然回撤
④ 祖师爷纪律（公开多次引用利弗莫尔）："看到危险信号，先离场，如果危机解除，
   随时可以再进场"
```
