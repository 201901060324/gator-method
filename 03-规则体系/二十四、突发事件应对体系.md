## 二十四、突发事件应对体系 `[核心]`

来源：20260304《突发事件与市场的反应》。

### 24.1 市场反应第一定律

```text
事件只有两种走向：逐渐发酵 / 逐渐消散（利好利空各二，共四种组合）
无论利好利空，市场在事件刚出现时反应最剧烈；即便发酵，影响也递减；
后市走势由新变量驱动，不再由原事件驱动
从来没有一个大趋势由单一事件驱动，都是多个独立事件的组合
IF 事件消散 AND 无新变量 THEN 市场逐渐修正回吐（利好消散=A 字；利空消散=深 V 修复）
IF 拿旧事件解释新走势 THEN 停——看的是新变量
```

### 24.2 四变量检查（判断趋势是否反转的兜底）

> **流动性 > 宏观经济 > 政策 > 宏大叙事**（他明确把流动性排第一）

- 宏大叙事=火车头行业，不一定是高新技术（稀土=反制牌、电网、黄金=美元信用替代）
- 宏观里**物流数据（港口吞吐量）、用电量**不易美化，比很多数据真实

```text
IF 担心牛转熊 THEN 四变量逐项检查是否"严重恶化"
IF 只有单一负面因素 THEN 不作为减仓/做空的充分依据
```

### 24.3 按交易者类型选应对

```text
超短客：涨啥买啥跌啥卖啥，只吃反应最剧烈那一段——"发现急猛干，啃一口就走"
趋势投机客：
  IF 事件前品种大势与事件同向 THEN 开仓或增仓（锦上添花）
  IF 事件与品种仅情绪关联 THEN 默认沿原趋势开仓——情绪杀不改趋势
  IF 事件与品种强关联且可能伤及基本面 THEN 观望等明朗
长线投资者：只跟踪一件事——核心基本面是否被改变
  IF 未改变 THEN 按原计划；IF 不确定 THEN 按兵不动观察
  IF 仅停留在预期（如油价未实际抬升航空成本） THEN 按兵不动
```

### 24.4 贸易战与市场的关联 `[重要]`

> 来源：贸易术语料 16 篇、301 调查 3 篇（2025-10-14 现场语境）；2024-10-18（"2019-2021年，贸易战结束，虽然中途有疫情这个小插曲"）。24.1-24.3 是"突发事件应对"的通用框架，本小节是**贸易战这一常备事件的判读要点**。

```text
金融视角的分段：贸易战对市场的影响按"预期转变"分段——
  市场预期从过度悲观转向（谈判/缓和信号出现）= 金融意义上的终结点
  （2018-12 G20 元首共识后市场预期开始转变；2019-2021 贸易战结束"中途有疫情插曲"）
贸易战是导火索与关键驱动，但并非完全决定市场（2018 大跌 = 贸易战 + 去杠杆 + 业绩爆雷 +
  流动性枯竭等多因素叠加——单一事件不解释全年走势，见 24.1 第一定律）
反制/关税的具体读法：短期扰动看 24.3 按交易者类型应对（超短啃一口、趋势沿原趋势、
  长线只看核心基本面是否被改变）
次级回调启示：贸易摩擦造成的回调属次级回调——末尾是加仓好时机（十一章 6 步流程对标）
```

### 24.5 A 股开会规律：政策会议时间表与预期炒作 `[核心][可计算]`

> 来源：2025-09-25《解答思考题》（"A股每年的'春躁行情'，发动者就是这类博弈两会的资金，包括季度末的政治局会议，每月的各种例会，还有临时会议"）；2025-06-16（"7月的政治局会议，分量要重一些……后面就得小心预期兑现的回落"）；小作话语料 28 篇。**政策项的季节性日历**。

```text
会议重要性排序与炒作规律：

① 两会（最重要）：每年 3 月上旬
   春躁节奏：大资金提前预期博弈——1 月萌芽、止跌企稳 → 2 月发酵、震荡上涨 →
   3 月高潮、加速见顶 → 会开完没有超预期内容就向下退潮
   （春躁有时提前到春节前启动；预期炒作常伴随"小作文"——10 万亿收储/5 万亿刺激等）
   ⚠️ 大概率"炒过头"：开会前资金充满想象（小作文满天飞）；开会后预期兑现
   基本符合甚至不及预期，大资金止盈撤离，散户沉浸在"大利好"氛围中高位接盘

② 政治局会议：每年 4/7/10/12 月（季度经济形势定调）
   "会议的级别不够"（2025-06-16）——分量轻重看时点；分量重的会议预期炒作更浓，
   "今天没去博弈会议预期的，后面就得小心预期兑现的回落"
③ 每月例会（国常会等）：频次多 → 预期炒作少，往往是结果型炒作
   （开会前反应不大、开会后出东西再炒），短频快、来得快去得快
④ 突发会议：国内外局势变动时的突然安排——尤其需要重视
   （2026-09-03 公开语：现在国内金融机构"名义上是听周天子调遣，其实依然是春秋战国"——
   政策节奏本身就是交易变量）

操作纪律（同春躁）：萌芽/发酵期上仓位，高潮期逐渐离场
  （与 20 章情绪周期配套：会议炒作=一轮"预期→兑现"的情绪周期；
   与 22.7 配套："开会炒预期"是预期-现实转化的标准案例）
```

**与既有章的接口**：
- 与 24.2 四变量（流动性>宏观>政策>宏大叙事）配套：政策项的季节性日历
- 与 15.3（不预测疯牛/慢牛，只跟随）同族：观察会议信号、跟随炒作节奏，不预判点位
- 与 20 章情绪周期配套：会议炒作本身就是一轮"预期→兑现"的情绪周期（"开会炒预期"是
  42.1 中期矛盾"现实 vs 预期"转化的标准案例）
