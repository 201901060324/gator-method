## 四十、行情梯队与下跌分类四型（20251009/1123）`[核心][可计算]`

**行情梯队**（大题材按启动时间和涨幅分三批）：
| 梯队 | 特征 | 参与纪律 |
|---|---|---|
| 第一梯队 | 最早启动、涨幅最大、质量最高 | 出现前只做它，可大胆格局 |
| 第二梯队 | 点火后爆发力强、直接穿上去 | 分一部分资金做弹性 |
| 第三梯队 | 末段补涨扩散、寿命最短 | 只做扩散，绝不格局，"啃一口就走" |
```text
IF 一梯队疲软 AND 二三梯队已现 THEN 一梯队边打边退
IF 二三梯队带动下 一梯队继续新高 THEN 资金反补，行情延续（考验阶段通过）
识别参考股用沪深300/中证500 权重，妖股参考性弱
```

**真突破的四道检验**（技术新高≠真突破，"上台阶"参考摔杯）：
```text
① 普涨（IF 随时两三千家下跌 THEN 共振不存在）② 成交量（上台阶阶段均量 2.5 万亿、峰值 3 万亿）
③ 大金融积极（龙哥不砸）④ 不吸血（IF 板块轮一天就没 THEN 是短差不是切换）
三句顺口溜：权重不强→机构不积极 / 小票不强→游资不积极 / 金融不强→龙哥不积极
IF 三者共振 THEN 才是真上台阶、可大上仓位
```

**下跌分类四型**：
| 类型 | 持续 | 深度 |
|---|---|---|
| 自然回撤 | ≤1 周（5 个交易日） | 浅 |
| 区间震荡 | ≤3 周（约两周回上沿） | 前低附近，突发事件可能刺穿 |
| 次级回调 | >3 周、几周到几个月 | **前段涨幅的 30%–60%** |
| 牛转熊 | — | **跌破区间下沿"拉都不拉回去"=失守** |
```text
IF 刺穿支撑一两天后拉回 THEN 不算失守
IF 判"破位" THEN 支撑必须看区间前低，不能看假突破高点——"4000 是假突破，重心没上移"
IF 下跌初期 THEN 走一步看一步：先博自然回撤→博区间下沿→没博赢才升级次级回调
IF 出现几连阳（十连阳级） THEN 之后行情通常不太好（8 月十连阳是唯一好例外）
IF 每年 12 月-1 月 THEN 机构调仓季，很少有大行情（平仓型 1 月激烈 / 买入型等春节前缩量配便宜货）
IF 夏天 THEN 要么故事（大行情：15/20/25 夏）要么事故（大跌：22/23/24 夏）；催化=半年报+经济数据+天热心躁
IF 指数处于护盘托举中（龙哥未失守） THEN 中期指数仍看震荡；IF 要跌穿周K平台 THEN 需要特别强的驱动（2026-10-08）
```

### 40.1 结构性牛市三阶段与大小票轮动 `[核心][可计算]`

> 来源：结构性牛市 6 篇（2024-03-11"在结构性牛市里，会出现双主线。多主线，那就成全面牛市了"）；拉指数 10 篇；板块轮动 58 篇；大票 180 篇；熊市重质 2 篇。四十章管"下跌分类"，本小节管**大级别上涨的阶段划分与轮动顺序**。

```text
三种趋势：主要趋势（几年）/ 次要趋势（几周-几月）/ 短暂趋势（几天）
做战略部署：先搞清主要趋势方向，留意次要趋势、忽略短期趋势

结构性牛市的三个阶段（配置对应）：
① 拉指数阶段：宽基指数 ETF 表现最佳
② 板块轮动阶段：宽基一般，行业 ETF/个股两级分化（"新老主线的接替上涨"2024-03-11）
③ 全面普涨阶段：绝大多数板块都涨（双主线→多主线=全面牛市）

大小票轮动 + "熊市重质"：
  大票小票大多数时候同涨同跌，部分阶段两级分化（"少数大票一直涨，大多数小票一直跌，
  二八分化明显"2024-02-07）；轮动末期资金高低切换
  "熊市重质，有分量的东西，终究会价值回归"（2024-08-22）

次级回调（最迷惑人）的两大原因（十一章 6 步流程的入口）：
① 过热回调：短期预期打得太满、现实没跟上——多头获利止盈+空头反扑
② 事件插曲：突发事件迅速改变市场预期或现实——通常比过热回调持续时间短
IF 大周期启动前没持仓/持仓少 THEN 机会还有——好买点=大周期启动前的熊市 + 次级回调低点
```
