## 三十七、短线个股操作体系：高标与龙头（20250701/0710/0722）`[核心][可计算]`

**高标三分类（新/旧/老，动态）**：
```text
新 = 短期涨幅 ≥30% 且近一两天仍创新高
旧 = 涨幅 ≥30% 但超 3 天没创新高（人气还在、走震荡）；IF 连续 3 天不打新高 THEN 由新转旧
老 = 前期翻倍→深度回调→资金回头"炒回锅肉"
关注度排序：新 > 旧 > 老；IF 3 天后又创新高 THEN 重新算"新"
```

**龙头三标准（连板数不算数）**：高度（短期涨幅≥30%）+ 参与度（10cm 优于 20cm/30cm，大多数人买得进）+ 赚钱效应（追高的人也赚钱、每隔几天创新高、筹码持续交换）。
```text
IF 涨幅 <30% THEN 属于抢先手阶段；IF ≥30% 且维持强势 THEN 才进入龙头接力思路
IF 做妖股 THEN 至少三板以后才参与；IF 走到 2 进 3 THEN 淘汰关口，胜率差不参与
```

**买点与止损**：
```text
IF 做右侧（分歧转一致） THEN 好买点仅 1–2 天窗口，错过宁可不做——"要么做得早，要么就没得赚"
IF 强势股/妖股 THEN 止损至少 6–8 个点（5 个点一个低开就没了）；打板追进约 10 个点级别
IF 趋势股 THEN 沿 5 日线介入，跌破不回拉即走，止损可 <5 个点
强 = 四种形态之一：天天涨停 / 天天新高 / 不涨停但天天新高收红 / 不破平台
IF 有辨识度的龙头跌 ≥20% AND 出现阳线 THEN 资金会抢反弹（阴线中不接飞刀；做反弹者绝不相信二波）
IF 前排买不进 THEN 看A做B 找后排补涨（前提前排老大不崩；前排集体低开则后排不看）
```

> **版本注记（2026-10-09）**：止损数字存在版本演化——早期口径为妖股止损 -10%~-15%，2026 版收紧为 6–8 个点（37 章），**默认以 2026 版为准**。

**精简复盘三步（约30分钟/天）**：①上证+创业板分时（黄白线=题材/权重），异动归因看板块涨幅榜前后5名与异动时段重合 ②列当天领涨 AND 领跌板块（领跌预示次日情绪）③从"昨日涨停表现"指数翻高标按新/旧/老分类 + 龙虎榜。选股落地：今天强的板块加自选，做后排必看前排脸色。

**投机三要素：情绪—量价—形态 `[核心]`**

> 来源：分歧转一致语料 41 篇；"放量就是分歧"语境（2024-03-08 相关多篇）；裸K 2023-07-22（"老师，您怎么就看个裸K"）；阻力最小 5 篇。37 章"高标与龙头"讲对象，本小节讲**投机的三个观察维度**。

```text
① 情绪（趋势与周期）：工具=炒作周期定位（20 章情绪周期/8 周期公开版）
   参与纪律：发酵阶段参与、高潮阶段开始止盈、分化阶段完全离场
   炒作逻辑三种：政策扶持、事件刺激、业绩预期
② 量价（情绪的客观反映）：
   放量的本质=分歧（有分歧才会有新的一致）：
     长期不放量=市场看法一致（没参与价值）；一旦放量=大量场外资金入场（无论涨跌）
   "对于投机来讲，近期没有放量的个股，都没有参与的意义。投机不是埋伏，而是冲锋"
   放量后先加自选、弄明白"炒的是什么"（题材/业绩/事件/行业复苏）——
     研究不明白 → 删除自选（不做看不懂的投机）
   ⚠️ 成交量并非越大越好：上涨阶段越缩量空间越大；越放量分歧越严重、离见顶不远
   （趋势股放量加速=见顶信号，与 4.6 离场信号同源）
③ 形态（价格确认）：
   最核心=收盘价；最能反映情绪=创新高
   创新高的意义：想走的套牢盘/获利盘已给机会走、留下的都是坚定持筹者
   祖师爷名言："价格，总是沿着阻力最小方向运行"（5 篇语境）——
     "自然界万事万物的运动……都沿着阻力最小的方向前行"（2024-05-17）
```
