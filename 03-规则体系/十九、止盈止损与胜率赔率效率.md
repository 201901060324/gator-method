## 十九、止盈止损与胜率赔率效率 `[核心][可计算]`

来源：20250929《赚翻倍》、20250524《投机的本质》、20260328《胜率赔率效率》、20250425、20260304。

### 19.1 分档目标与三种结局

```text
IF 波段交易 THEN 单笔止盈目标 5%–10%
IF 趋势交易 THEN 单笔止盈目标 20%–30%（基础模型：止盈30%/止损-8%/持有上限2个月）
IF 长线投资 THEN 单笔止盈目标 30%–50%
IF 触及 止盈/止损/持有时间上限 三者之一 THEN 本笔交易结束
IF 出现其他任何结果（含中途小赚离场） THEN 判定执行失败
（"浮盈20%就跑要给自己两巴掌；-8%打止损离场要给自己鼓掌"）
```

```text
IF 做波段/打野 THEN 持有时间上限 25 个交易日，到期不论盈亏都处理
IF 做三五年周期 THEN 不因三个涨停板（30%浮盈）清仓——对不起时间成本
IF 止损放 30% THEN 止盈必须远大于 30%（赔率>1，严格者 2:1）
```

### 19.2 投机四原则（20250524）[核心]

1. 止损可以大，但**不能没有**（金额止损 -5%/-10%；价格止损=前低/均线），触发立即离场
2. 浮盈回吐迹象出现 → 及时止盈，勿让盈利变亏损
3. 把自己当机器人：策略制定后不更改（不加仓、不改止盈止损、不延长时间）
4. IF 策略连续失灵（环境改变） THEN 马上停手或换策略

> 职业投机客平均胜率约 61%，没人超过 75%（他接触的游资与机构操盘手）；靠止损止盈与纪律盈利，不是靠高胜率。他自述花两年半才做到严格止损。投机者对筹码"毫无感情"——买入持有唯一理由是"短期它还能涨"。

### 19.3 胜率赔率效率的不可能三角（20260328）[核心]

三者最多取其二。利弗莫尔路线=高赔率(≥3:1)高效率低胜率（浮盈加仓重仓猛干，伴生大起大落）。
**他的改良版：高胜率 + 高效率 + 低赔率（>1 且通常 <2）**——通过放大止损降低赔率、增加容错、提高胜率；**不浮盈加仓**，初期分批买足。

实战样本（开仓前先计算）：中证1000 股指多单 8 手（保证金近 200 万，止损 50 万/止盈 60-100 万）→ 实际 +85 万/14 个交易日；PVC 空单 100 手（止损 15 万/止盈 20-30 万）→ +30 万。

```text
IF 胜率小 THEN 轻仓；IF 胜率大 THEN 仓位可适当大；不重仓不单押
IF 做短线商品 THEN 盯国内品种不盯国际品种（国内有龙头/跟风/卡位的炒作规律）
```

**方向层面的胜率赔率分离（2026-10-12，猪周期实例）`[核心]`**：
```text
胜率赔率不只用于定止盈止损比，还用于**决定是否出手**
IF 方向判断胜率高 AND 赔率不支持 THEN 可以判断对方向却**不做**这笔
```
- 实例（2026-10-12）：国庆后需求走弱、现货跌是大概率（**胜率高**），按技术面逢高空远期合约"没毛病"；
  但他判"**我知道节后要跌，但不去做空，等着止跌后做多**"——赔率不支持，遂放弃空单、反向等做多。
- 与 4.1"能做 ≠ 做好"同族：**看得准 ≠ 该做**，两件事分开判断。

### 19.4 止盈执行的补充（2026-09）`[次要]`

**① 止盈双条件（金额 AND 盘面）**——2026-09-28 平空实例：
```text
IF 持仓到达预设止盈金额 AND 盘面情况同步达标 THEN 平仓
（单一条件满足不必然平仓——中秋前的空单因"没跌到位"，一手没平）
```

**② 卖出按"区间"管理，不是"点"**——卖出信号是**区间**，进入区间即进入卖出管理，
不必等一个精确点位（此用词出自 AI 模块的信号命名，与他人工的"止盈双条件"同向：都是**非单点**判定）。

### 19.5 看对只是一半：被淘汰三原因（2026-10-12）`[核心]`

> "**看对，只是对了一半，不被淘汰是另一半。**"
> （924 熊转牛抄底成功后有人评论"我当时也知道是底，但没拿住，割了"——看对了，但在事实验证前被淘汰出局）

```text
被淘汰通常三种原因：仓位重了 / 成本高了 / 时间久了
三者各自对应可控手段：
  IF 仓位重 THEN 分批建仓 + 分品种风险预算（4.1）
  IF 成本高 THEN 选入场方式、增加安全垫（52.5）
  IF 时间久 THEN 设持有时间上限（19.1）、别盲目抄底
```

- 这是体系里少见的**失败原因论**（其余章节多为"怎么取胜"）。三变量都与"方向判断对不对"无关——
  即**正确判断也会被出局**，故须单独设防。
- 通用收句："机会来临时也不是无脑上，要把**进场时机和价位**都规划好，**增加安全垫**，才能保证不被淘汰出局。"

### 19.6 评价基准纪律：不美化没走过的路（2026-10-22）`[核心]`

> 19.5 讲**为什么会被淘汰（失败侧）**，本小节讲**用什么标准评价一笔交易（基准侧）**。
> 两者常常同时被违反：既被淘汰、又拿事后最优路径骂自己。

```text
"如果我空单拿到现在，能多赚 500 多万。但是，算这些没有意义，
 **不要去美化自己没有走过的路**，把自己**交易体系内的利润**赚到，就足够了"
→ 评价基准 = **体系内可实现的利润**，不是事后回溯的最优点

第二层：他人赚到 ≠ 方法可复制
  反例式追问："有人说，3700 点做空的就赶尽杀绝，人家现在也大赚了一笔。
   按照这个逻辑，之前中际 1300 块梭哈的人也能大赚一笔，所以你想复刻他们的操作吗？"
  他的答案："普通人是很难做好这种极限情绪的加速的，职业圈 100 个人里可能都只有一两个，
   我身边是一个都没有"
  → 用**方法的可复制性/稀缺度**筛方法，不用**别人赚没赚到**筛方法

IF 想评估自己这一笔 THEN 只问"体系内该赚的赚到了吗"，不问"最优路径能赚多少"
IF 看到别人暴赚 THEN 先问"这套打法在人群里的成功率有多高"，再决定要不要学
```

- 与项目回测方法论红线**同源**：事后倒推、精选样本、拿结果反推方法，都会高估能力。
- 与 19.5 的配合：19.5 说"看对只是对了一半"，本小节说"**看对之后还赚到了体系内的钱，才算数**"。
- 他主动交代"没吃满、少赚 500 多万"，是这条纪律的**自证**——不是在凡尔赛，是在演示"不事后加杠杆式复盘"。
