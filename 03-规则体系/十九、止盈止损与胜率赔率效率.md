## 十九、止盈止损与胜率赔率效率 `[核心][可计算]`

来源：20250929《赚翻倍》、20250524《投机的本质》、20260328《胜率赔率效率》、20250425、20260304。

### 19.1 分档目标与三种结局

```text
IF 波段交易 THEN 单笔止盈目标 5%–10%
IF 趋势交易 THEN 单笔止盈目标 20%–30%（基础模型：止盈30%/止损-8%/持有上限2个月）
IF 长线投资 THEN 单笔止盈目标 30%–50%
IF 触及 止盈/止损/持有时间上限 三者之一 THEN 本笔交易结束
IF 出现其他任何结果（含中途小赚离场） THEN 判定执行失败
（"浮盈20%就跑要给自己两巴掌；-8%打止损离场要给自己鼓掌"）
```

```text
IF 做波段/打野 THEN 持有时间上限 25 个交易日，到期不论盈亏都处理
IF 做三五年周期 THEN 不因三个涨停板（30%浮盈）清仓——对不起时间成本
IF 止损放 30% THEN 止盈必须远大于 30%（赔率>1，严格者 2:1）
```

### 19.2 投机四原则（20250524）[核心]

1. 止损可以大，但**不能没有**（金额止损 -5%/-10%；价格止损=前低/均线），触发立即离场
2. 浮盈回吐迹象出现 → 及时止盈，勿让盈利变亏损
3. 把自己当机器人：策略制定后不更改（不加仓、不改止盈止损、不延长时间）
4. IF 策略连续失灵（环境改变） THEN 马上停手或换策略

> 职业投机客平均胜率约 61%，没人超过 75%（他接触的游资与机构操盘手）；靠止损止盈与纪律盈利，不是靠高胜率。他自述花两年半才做到严格止损。投机者对筹码"毫无感情"——买入持有唯一理由是"短期它还能涨"。

### 19.3 胜率赔率效率的不可能三角（20260328）[核心]

三者最多取其二。利弗莫尔路线=高赔率(≥3:1)高效率低胜率（浮盈加仓重仓猛干，伴生大起大落）。
**他的改良版：高胜率 + 高效率 + 低赔率（>1 且通常 <2）**——通过放大止损降低赔率、增加容错、提高胜率；**不浮盈加仓**，初期分批买足。

实战样本（开仓前先计算）：中证1000 股指多单 8 手（保证金近 200 万，止损 50 万/止盈 60-100 万）→ 实际 +85 万/14 个交易日；PVC 空单 100 手（止损 15 万/止盈 20-30 万）→ +30 万。

```text
IF 胜率小 THEN 轻仓；IF 胜率大 THEN 仓位可适当大；不重仓不单押
IF 做短线商品 THEN 盯国内品种不盯国际品种（国内有龙头/跟风/卡位的炒作规律）
```

### 19.4 止盈执行的补充（2026-09）`[次要]`

**① 止盈双条件（金额 AND 盘面）**——2026-09-28 平空实例：
```text
IF 持仓到达预设止盈金额 AND 盘面情况同步达标 THEN 平仓
（单一条件满足不必然平仓——中秋前的空单因"没跌到位"，一手没平）
```

**② 卖出按"区间"管理，不是"点"**——卖出信号是**区间**，进入区间即进入卖出管理，
不必等一个精确点位（此用词出自 AI 模块的信号命名，与他人工的"止盈双条件"同向：都是**非单点**判定）。
