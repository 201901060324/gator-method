## 二十、情绪周期与题材炒作 `[核心]`

来源：20250222《赚市场情绪的钱》、20250603《炒作分类》。

### 20.1 情绪周期六阶段与相对阈值

```text
冰点 → 企稳 → 回暖 → 火热 → 过热 → 退潮（月满则亏）
⚠️ 不是每轮都走满：偶尔企稳直接过热再急跌（极端行情，多数人不适合参与）
情绪是相对的 [可计算]：
IF 过去一个月日均涨停 100 家 AND 连续几天降到 80+ THEN 退潮迹象
IF 熊市日均涨停 60 以下 AND 几天飙到 80+ THEN 过热迹象
```

### 20.2 两类人气龙头

① **中军趋势龙头**（机构打造）：市值大、通常不涨停、大涨→调几天→再涨。
② **妖股龙头**（游资打造）：对情绪影响更大。三特点：有辨识度（连板高/涨幅近倍）、有参与度（放量换手板，不能全是秒板）、赚钱效应好（可不满涨停但天天创新高）。

```text
IF 龙头还在往上顶 THEN 主线炒作没终结
IF 主线龙头被炒成独立抱团（老大涨小弟不涨） THEN 失去号召力
IF 普涨日 THEN 看不出资金流向，不压主线；IF 分化日 THEN 看资金流向压主线
IF 游资已拉出妖股领头羊 AND 机构中军未确立 THEN 仍在赛马期，难成持续主线
（板块走主线需"两只羊"：妖股领头羊 + 机构中军；中军确立后涨幅至少 30 个点起）
```

### 20.3 题材炒作三分法（20250603）

```text
结果型（尘埃落定）：游资点火第二天基本就走 = 博傻 → 不参与
预期型（未发生可预知）：核心=预期差=实际结果−市场预期；三个节点：
  现货没动期（价格成本低时间成本高）→ 现货开始涨期（双低，新人首选）→
  预期差趋零期（博弈加速，老手首选）
发展型（已发生未结束）：持续性=技术形态+外界驱动
IF 新题材出现 THEN 先答四问：①预期兑现了吗 ②还剩多少预期差 ③事件还会发展吗 ④盘面反应强不强
⚠️ 绝不能因为还有预期就忽略盘面——砸出大阴线、套牢盘增加 = 炒作提前终结
```

### 20.4 赛道行情与宏大叙事（20250611）[核心]

```text
宏大叙事四要素：故事大到人人皆知 + 政策扶持 + 有业绩或技术优势 + 板块容量够
IF 公募私募建仓 AND 游资拉升 AND 三方认知一致 THEN 主升浪来临
IF 主升浪结束 THEN 成长股衰变为周期股（"所有成长股最终都会变成周期股，只隔一个主升浪"）
季节法：春观察 → 夏买入 → 秋卖出 → 冬观望
IF 人人都看好 THEN 开始卖出
```
