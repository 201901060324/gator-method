## 二十、情绪周期与题材炒作 `[核心]`

来源：20250222《赚市场情绪的钱》、20250603《炒作分类》。

### 20.1 情绪周期六阶段与相对阈值

```text
冰点 → 企稳 → 回暖 → 火热 → 过热 → 退潮（月满则亏）
⚠️ 不是每轮都走满：偶尔企稳直接过热再急跌（极端行情，多数人不适合参与）
情绪是相对的 [可计算]：
IF 过去一个月日均涨停 100 家 AND 连续几天降到 80+ THEN 退潮迹象
IF 熊市日均涨停 60 以下 AND 几天飙到 80+ THEN 过热迹象
```

### 20.2 两类人气龙头

① **中军趋势龙头**（机构打造）：市值大、通常不涨停、大涨→调几天→再涨。
② **妖股龙头**（游资打造）：对情绪影响更大。三特点：有辨识度（连板高/涨幅近倍）、有参与度（放量换手板，不能全是秒板）、赚钱效应好（可不满涨停但天天创新高）。

```text
IF 龙头还在往上顶 THEN 主线炒作没终结
IF 主线龙头被炒成独立抱团（老大涨小弟不涨） THEN 失去号召力
IF 普涨日 THEN 看不出资金流向，不压主线；IF 分化日 THEN 看资金流向压主线
IF 游资已拉出妖股领头羊 AND 机构中军未确立 THEN 仍在赛马期，难成持续主线
（板块走主线需"两只羊"：妖股领头羊 + 机构中军；中军确立后涨幅至少 30 个点起）
```

### 20.3 题材炒作三分法（20250603）

```text
结果型（尘埃落定）：游资点火第二天基本就走 = 博傻 → 不参与
预期型（未发生可预知）：核心=预期差=实际结果−市场预期；三个节点：
  现货没动期（价格成本低时间成本高）→ 现货开始涨期（双低，新人首选）→
  预期差趋零期（博弈加速，老手首选）
发展型（已发生未结束）：持续性=技术形态+外界驱动
IF 新题材出现 THEN 先答四问：①预期兑现了吗 ②还剩多少预期差 ③事件还会发展吗 ④盘面反应强不强
⚠️ 绝不能因为还有预期就忽略盘面——砸出大阴线、套牢盘增加 = 炒作提前终结
```

### 20.4 赛道行情与宏大叙事（20250611）[核心]

```text
宏大叙事四要素：故事大到人人皆知 + 政策扶持 + 有业绩或技术优势 + 板块容量够
IF 公募私募建仓 AND 游资拉升 AND 三方认知一致 THEN 主主升浪来临
IF 主升浪结束 THEN 成长股衰变为周期股（"所有成长股最终都会变成周期股，只隔一个主升浪"）
季节法：春观察 → 夏买入 → 秋卖出 → 冬观望
IF 人人都看好 THEN 开始卖出
```

### 20.5 主线题材的判定条件（公开复盘版） `[核心]`

> 依据公开文章整理。与二/三章（买点视角）互补，是**主线本身的资格判定**。

```text
主线判定四要素（按公开复盘归纳）：
① 有号召力的龙头带队——"要有多个具有号召力的龙头带队"（复盘）；
   "放量与缩量交替，是成为龙头的必经之路"
② 有中军权重——"中军权重的空间，通常是30%-50%，主线妖股龙头的空间，
   通常是翻倍起步"（2024-06-11《红包，还是"红包"》）
③ 板块要大、能容纳资金——"主线板块一定得大，维生素可以当个先锋，
   把整个医药的情绪给带起来，但是今天的医药，权重并不是很强"（同上）
④ 会扩散——"一个主线板块，判断持续性的信号，就是领头羊的持续新高……
   再看板块之间的共振，也就是扩散"（2024-03-08《百花齐放才是春》）

判定纪律（公开原句）：
- "底部反转的主线板块，翻倍只是起步"（2024-02-06《苦尽甘来》）
- 主线由赛马产生："今天靠前的马儿：医药、酒、地产、半导体。短线可以围绕这些
  板块做轮动低吸，也可以等赛马出结果了再动手"（2024 复盘）
- 扩散与轮动的另一面：领涨分散到补涨板块时，往往接近尾声
  （"上周是小游戏补涨，今天是大游戏补涨……板块分化严重"2025-06-12）

操作：等赛马出结果再动手；主线押注"富则火力覆盖，穷则精准打击"
（2024-11-07、2025-02-05、2025-06-27、2026-01-07、2026-03-11 5 篇）；
不想选个股就看板块 ETF。
```

### 20.6 交易拥挤度：题材顶峰的判别线 `[核心]`

> 来源：2025-02-24《先别骂，大跌…》（"交易拥挤度。简单理解，就是短期增量资金达到极值"）；2025-10-22《游资猎杀时刻》（"黄金短期交易拥挤度到达极限，哑铃策略趋同后，出现急跌是必然结果"）。与 20.1 情绪量化表互补——情绪表看全市场温度，本节看**单一板块/品种的拥挤程度**。

```text
定义：交易拥挤度 = 短期增量资金（或共识度）达到极值的状态
  "当一波炒作，交易拥挤度达到顶峰时，是继续涨一天，还是两天，我也不知道，
   我只知道，凛冬将至，提前做好应对策略"（2025-02-24）

基础认知：A股 90% 以上时间是存量博弈（吸血语料 54 篇——一个板块涨得好，
  资金就舍弃其他板块往里灌）
板块拥挤见顶的读法（对内版整理，公开判读句）：
  妖股龙头疲软（不涨停/不新高/失去号召力）；板块出现涨停潮（情绪极致）；
  炒作预期兑现没有新预期；成交量阶段峰值
避险侧拥挤度（跷跷板）：求稳资金也变得不耐心、从避险资产涌向热门板块时，
  热门板块的拥挤度接近顶峰（2025-10-22 哑铃策略语境："极致的防御+极致的进攻"趋同）

调整质量判别：
良性调整 = 高低切换（49 篇语境："资金在做良性的高低切换，没有只卖不买"2024-03-08）
  ——热门降温、冷门被买止跌、短线资金流入筑底板块开启新炒作
  （"市场的见底和突破，普涨是必要条件"——见一章共振）
恶性调整 = 极致吸血、不调整：资金猛干一波，一波之后结束
  （"权重的血都被抽去……台子塌了，题材这个戏，也就唱到了尾声"）
拥挤瓦解后的判读：看之前被吸血的板块何时止跌——增量不来捡便宜，
  存量博弈的多杀多、缩量阴跌就会持续
纪律："避免去赚最后一个铜板"（2024-12-19"市场的第一个铜板与最后一个铜板，代价是昂贵的"）
IF 出现严重吸血+交易拥挤 THEN 情绪瓦解又快又猛（哑铃趋同=急跌必然）
```

### 20.7 主线行情三分类 `[核心]`

> 来源：2025-02-06《第二场庆功宴》（原文完整公布："在咱们鳄鱼派，主线行情分为三类：1、一超多强的普涨主线行情 2、一超吸血的主线行情 3、畸形的主线行情……希望大家不要跟那些小白一样，看着一个板块大涨了两天，就喊主线，就要梭哈"）；一超多强 13 篇（2024-03-25"一轮炒作周期，通常是一超多强的格局"）。

| 类型 | 特征 | 指数形态与持续 | 策略适配 |
|---|---|---|---|
| **一超多强·普涨主线** | 一个主线带领多个支线板块一起上涨（机构游资共振、有驱动力、板块扩散、气氛组也涨） | 单边上涨大行情，持续一个月以上 | 容错高——没做到主线做其他板块/宽基也有收获 |
| **一超吸血·结构性** | 板块强但号召力弱（不带动兄弟板块、气氛组不涨） | 指数横盘震荡或小幅上涨，板块强一个月以上 | 存量博弈资金抱团——没做对主线不仅没收获往往还亏 |
| **畸形主线** | 不共振（只有机构或只有游资）/乱扩散（配角热度超过主角）/无强驱动力/吃独食严重 | 指数横盘或小涨，持续一个月以内 | 操作难度大、快进快出，波段比趋势更合适 |

```text
判据：形态先对号入座——一超多强=吃一个月+的大行情；吸血=只做精准打击；
  畸形=波段快进快出
IF 探讨主线 THEN 按三分类细分看（不要"看着一个板块大涨两天就喊主线梭哈"）
IF 形态演化 THEN 动态跟踪：畸形／吸血主线可能"跑着跑着"升级或降级
"主线行情是走出来的，不是猜出来的"——按当下信号调整策略
```
