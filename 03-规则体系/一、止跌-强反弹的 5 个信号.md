## 一、止跌 / 强反弹的 5 个信号 `[核心]`

来源：2024-11-18《止跌的5个信号》，另有 2025-09-19《止跌的三个信号》等多个版本。

| # | 信号 | 他的判定标准 |
|---|---|---|
| 1 | **指数共振** | 上证与创业板、沪深300与中证2000、A股与港股之间差距要收敛 |
| 2 | **出现火车头板块** | 有领涨板块还不够，**必须有带动作用**；"没有带动作用的火车头，就不合格" |
| 3 | **气氛组证券走强** | 衡量标准：券商**有没有涨停板**；"没有，没有就是不及格" |
| 4 | **短线增量资金进场** | 看成交量和外资/游资动向 |
| 5 | **股指基差缩小** | 衡量标准：**上涨途中有没有缩小**（下跌途中缩小不算） |

### 执行阈值（明确的数字！）

> "止跌的市场信号，并非全部满足才能看止跌，**激进的选手满足三个就会出手，保守的选手满足4个或者全满足**，就可以出手。"

```text
IF 满足信号数 >= 3  THEN 激进选手可出手
IF 满足信号数 >= 4  THEN 保守选手可出手
IF 满足信号数 <  3  THEN 继续观望
```

### 短期情绪冰点阈值 `[核心]`

来源：2026-09-24《跌多少才会止跌？》

```text
IF 微盘股跌 >= 3%  AND 跌停家数 > 30  AND 上证跌 > 2%
THEN 视为短期情绪冰点
```

（他对当日行情的判断是"今天来看，还不算情绪的冰点"）


### 信号 4 的细化：增量资金 vs 国家队的分时判别 `[核心][可计算]`

来源：20240919 / 20240922 直播回放（924 行情启动前夜的现场教材）。

| 特征 | 增量资金进场 | 国家队进场 |
|---|---|---|
| 主体 | 很多机构 | 一两个机构 |
| 分时形态 | 循序渐进、温和放大 | 脉冲式，分时"七拐八拐"、量忽高忽低 |
| 含义 | 有质量的上涨，当天/隔天可做配置 | 只是底部区间信号 |

```text
IF 分时温和放量、成交量循序渐进放大 THEN 增量资金进场（有质量的上涨）
IF 脉冲式异常放量 THEN 国家队进场，别误判为增量资金
IF 国家队"扫货式抄底"（无抵抗急跌后 沪深300ETF 某分钟量≈半小时/1小时量，全年仅数次）
THEN 只是底部区间信号，不是见底信号 —— "底部和底是有区别的"
```

实测样本：9/18=国家队打卡；9/19=增量资金进场标志日；9/20=国家队扫货；两天后 924 行情爆发。
