## 一、新增规则（IF…THEN）

### A. 量能与流动性

1. **[核心] 成交量下限决定短线可做性**（来源：20250701，前半段；20250710 再次强调"1.5万亿不愁没得做"）
```text
IF 成交量 ≥ 1.5万亿（哪怕港股休市外资缺席） THEN 短线题材可做，不愁没题材
IF 成交量缩回 1.2–1.3万亿 THEN 回到类似 5 月的轮动行情，短线难做
IF 放量下跌但仍有 1.5–1.6万亿 THEN 短线仍有得做，不因放量下跌撤退
【阈值未公开】跌破 1.5 万亿后的精确观察期
```

2. **[单源] 股市"逼空"是终结前兆**（来源：20250722，股指期货段）
```text
IF 商品期货出现空头被迫减仓、逼空上涨 THEN 是好事，行情可延续
IF 股市出现逼空式上涨 THEN 往往接近阶段结束——"股市这边逼空可能就要结束了"
```

### B. 基差 / 股指期货（强化已有第一、八、二十六章）

3. **[核心] 基差看尾盘、分场景定阈值**（来源：20250722；20250904 细化）
```text
IF 只看盘中基差 THEN 会被盘中冲高误导，必须看尾盘/两点半后
IF IF（沪深300期指）基差尾盘仍收敛到负数 THEN 切换单边上涨思路，上仓位
IF 牛市急涨阶段基差维持 150 左右（IM） THEN 属于强势正常范围，不算异常
IF 基差急速拉大（现货涨、期货压价） THEN 期货空头在加仓，是背离警示（0904：IM 曾标到 248）
【阈值未公开】基差 248/150/负数 三档之间未给出完整分级表
```

4. **[单源] 双方增仓次日行情激烈**（来源：20250904）
```text
IF 股指期货多空双方同时增仓 THEN 次日通常走得刺激（空头减仓=直线拉升；多头平仓=冲高回落）
```

### C. 龙头 / 高标玩法（强化已有第二十、二十六章，大部分为新增）

5. **[核心] 高标三分类：新 / 旧 / 老**（来源：20250701，短线专题核心）
```text
新 = 短期涨幅 ≥30% 且近一两天仍创新高
旧 = 涨幅 ≥30% 但超过 3 天没创新高（人气还在、走震荡）
老 = 前期翻倍→深度回调→资金回头"炒回锅肉"
IF 连续 3 天不打新高 THEN 多数资金转入观望（由新转旧）
IF 3 天后又创新高 THEN 重新算"新"（分类是动态的，跟随资金博弈程度）
市场关注度排序：新 > 旧 > 老
```

6. **[核心] 龙头三标准，连板数不算数**（来源：20250701）
```text
龙头 = 高度（短期涨幅≥30%）+ 参与度（10cm 优于 20cm/30cm，大多数人买得进）+ 赚钱效应好（追高的人也能赚钱、每隔几天创新高、筹码持续交换）
IF 只有连板数量 THEN 算不上龙头
IF 高换手率 THEN 不必然死——"情绪到了换手高也不一定死"
```

7. **[核心] 30 个点是"抢手"与"做龙头"的分界**（来源：20250701）
```text
IF 涨幅 <30% THEN 属于抢手/抢先手阶段（先信资本卖后信资本）
IF 涨幅 ≥30% 且仍维持强势不跌 THEN 板块成绩很足，才进入龙头接力思路
IF 做妖股 THEN 至少三板以后才参与，一板二板不参与（火力覆盖者除外）
```

8. **[核心] 右侧好买点窗口只有一两天**（来源：20250701，反复强调）
```text
IF 做右侧（分歧转一致） THEN 好买点仅出现在 1–2 天内（确定之后立刻出手）
IF 错过这 1–2 天 THEN 宁可不做，"要么做得早，要么没得赚"
```

9. **[核心] 龙头/强势股的止损与成本设置**（来源：20250701；对已有第 25.1 章"技术杀放宽"的细化）
```text
IF 做强势股/妖股 THEN 止损不能小：至少 6–7–8 个点（5 个点一个低开就没了）
IF 打板追进去 THEN 止损约 10 个点级别，且成本离均线远
IF 做趋势股 THEN 沿 5 日线附近介入，跌破 5 日线不回拉即走，止损可 <5 个点
IF 做一致（突破打新高） THEN 止损最难设——新手优先做日 K 级别分歧买点
```

10. **[核心] 强的四种形态（不只涨停算强）**（来源：20250701）
```text
强 = ①天天涨停 ②天天新高 ③不涨停但每天新高+收盘收红 ④不新高不收红但不跌破平台
IF 在"弱中观察到任一种强" THEN 可博弈分歧转一致
反例：阴跌中天天创新低不算强（如转写举例的"草坪"，标的存疑）
```

11. **[核心] 龙头抢反弹阈值：跌 20%+ 阳线出现**（来源：20250701）
```text
IF 有辨识度的龙头跌 ≥20%（人气没死透、获利盘部分释放） THEN 通常会有资金抢反弹
IF 做抢反弹 THEN 必须看到阳线再动手，不在大阴线中接飞刀
IF 每一波反弹 THEN 高度越来越弱（释放前级套牢盘），赚"相信二波的人"的钱
IF 自己做反弹 THEN 绝不能相信二波——"即便最终走二波了也跟你没关系"（做反弹与做突破不可混淆）
```

12. **[单源] 趋势股"涨二歇一"节奏判别**（来源：20250710）
```text
IF 趋势股连续两天下跌且跌破 5 日线收盘收不回 THEN 出来观望（正常节奏是涨两天歇一天）
IF 之后分歧转一致重新走好 THEN 再进去没有问题
IF 卖掉后拉黑不再看 THEN 是坏习惯——有些票可以反复做
```

13. **[单源] 二进三是坎**（来源：20250722）
```text
IF 连板股走到 2 进 3 THEN 是淘汰关口，胜率差且风险回报比不划算
IF 看好某板块前排 THEN 前排买不进就"看 A 做B"——找后排补涨（前提：前排老大不崩）
IF 前排集体低开大跌 THEN 后排连看都不用看
```

14. **[单源] 做T参考线**（来源：20250710）
```text
日内做T = 当日黄色均价线以下买、以上卖；向下接近前低再加一次
更小级别 = 5/15/30 分钟 K 线 + MACD 拐点
IF 踢出来是懵的 THEN 干脆不踢；网格=把间隔画出来
```

### D. 融资盘 / 杠杆牛（强化已有 23.2 章，新增选股法）

15. **[核心] 融资占比选股法（鱼头/鱼身）**（来源：20250710，本场重点）
```text
融资余额/流通市值 > 3% = 融资客扎堆（衡量"股性"/杠杆资金喜爱程度）
吃鱼身：IF 短期涨幅 15–30% AND 融资余额/流通市值 >3% THEN 参与（涨幅>30% 杠杆资金已赚 60 个点，进入鱼尾）
吃鱼头：IF 当日融资净买入占成交 5–15% AND 短期涨幅 <15% THEN 埋伏（融资数据次日早更新，看的是昨日数据）
IF 融资买入占比过高（如 26%） THEN 危险——全是杠杆资金没有韭菜，"狼多了，明天稍微丢点肉狼就跑了"
IF 融资客抢反弹的票（大跌次日融资买入暴增） THEN 不做——不顺势
前提：融资余额持续增长（杠杆牛在延续）；环境变了此法失效——"策略一定要跟行情相结合，千万别刻舟求剑"
```

16. **[核心] 融资余额盯盘纪律**（来源：20250710；与 23.2 章"连续3–4天减少"略有差异，此处他口播为 2–3 天）
```text
IF 融资余额偶尔减少一天 THEN 没关系
IF 连续 2–3 天减少 THEN 杠杆资金在撤离，警惕（每天早 8:50 更新，必盯）
IF 两融单日增长 100–150 亿级别 THEN 杠杆疯狂，但顶无法预测——"牛顿都计算不出人性的疯狂"
```

17. **[单源] 杠杆牛的扩散传播机制**（来源：20250710）
```text
传播链：张三（有50万，券商1:1融资）做妖股赚钱 → 李四不敢做妖股，融资买趋势股 → 王五只有10万，被介绍到场外配资/银行信贷
不带R标识（不可两融）的票 = 场外配资/信贷杠杆聚集地，最易被做庄（配资多为虚拟盘对赌，钱根本不进股市）
IF 看到无R小票无缘无故暴涨 THEN 警惕是被配资资金"做庄"
```

18. **[单源] 板块内高低切的融资信号**（来源：20250710）
```text
大银行融资余额持续下降（工行 4 月约 20 亿 → 7 月 16 亿）+ 小银行融资占比升高（贵阳银行）= 融资客在卖大买小
IF 同板块内出现这种迁移 THEN 资金高低切正在进行；"资金永远是高低切，杠杆资金也不例外"
```

19. **[单源] 银行的真实逻辑是工具银+抱团，不是估值**（来源：20250710）
```text
IF 有人用 PE 低（如工行 7 倍）劝你买银行 THEN 远离——PE 必须与自身历史纵向比较（22-23 年估值合理时才是买点）
IF 现在买银行 THEN 冲的是工具银属性+资产荒抱团，与估值无关
IF 银行抱团走到后期 THEN 会有不小的回撤（参考 2024 抱团顶：工行跌 15%，小银行跌 30%）
```

### E. 板块节奏 / 联动

20. **[核心] 板块联动"看 A 做B"**（来源：20250701）
```text
操作法：熟悉每个板块分类 + 每个板块与大盘情绪的关系；看到 1 要想到 2345
已知联动对：银行↔电力↔医药（同防御类，银行开盘强→看电力医药）；风光锂三兄弟（同涨同跌，锂电炒过轮到风和光）；港口↔石油；多元金融↔证券↔数字货币
IF 某板块前排涨停 THEN 立刻在联动板块找异动响应
IF 只靠猜/算命 THEN 无意义——必须看到信号再按规律找响应
```

21. **[单源] 普涨即兑现**（来源：20250701）
```text
IF 连"狗不理"板块（地产、白酒等被嫌弃的）都开始轮动上涨、全面普涨 THEN 普涨很难持续，短线兑现（配合微盘股 6 连阳→物极必反，技术性调整）
```

22. **[单源] 军工判死刑条件**（来源：20250701）
```text
军工以往"渣"的原因：票太多、啥都能扯上军工、小弟换得勤（老大强但小弟强两天就换）
IF 干仗预期消退 AND 龙头不再强 THEN 才能判死刑
IF 情绪强+龙头强+有新故事（如阅兵预期） THEN 即使事件在两个月后也不能提前判死——"盒子没打开之前最有想象力"
```

23. **[单源] 消费必须拆开看**（来源：20250701）
```text
零售/白酒/食品/新消费/旅游分开炒
IF 某方向没有"让资金喊口号的想象空间"（如稳定币、自主可控都有口号，消费没有） THEN 短线难炒，只剩长线埋伏
```

24. **[单源] 会议行情尿性**（来源：20250710）
```text
IF 临近政治局会议 THEN 地产等政策预期板块可以提前蹲一枪（埋伏=横着趴着狗不理时进，大涨去做叫突破不叫埋伏）
IF 会后 THEN 熄火回落是常态（逢会必提地产、会后不出劲爆政策）
下一次博弈窗口 = 十月政治局会议
```

### F. 复盘方法论（强化已有 02 流程）

25. **[核心] 精简版短线复盘三步**（来源：20250701，职业级可计算流程）
```text
① 看上证+创业板分时（黄线白线=题材/权重谁强）；盘中异动找归因：板块涨幅榜前后各 5 名，看哪个板块与异动时段走势重合
② 列当天异动板块：领涨的 AND 领跌的都要列（领跌的预示次日情绪）

耗时约 30 分钟/天；一板二板不必统计（上班族版）
选股落地：今天强的板块加自选；喜欢前排加前排、喜欢后排加后排；做后排必看前排老大脸色（看A做B）
```

### G. 抱团瓦解框架（20250904，本场最重要的新框架）

26. **[核心] 抱团瓦解后的三种结局**（来源：20250904，重点）
```text
情形1【最好】疯牛2.0（2014末-15初模式）：单边上涨→抱团瓦解暴跌（当年券商指数单日跌停）→宽幅震荡1–2个月→换挡加速开启疯牛2.0
  条件：成交量维持 2 万亿以上 + 融资持续 + 源源不断的基民（完成筹码充分交换）
情形2【中性】牛市结束（2021模式）：从一个抱团轮到另一个抱团（医药→酒→煤→风光锂→猪→酱油轮番）→基本面修复不及预期+美联储加息终结
  指数层面每一轮抱团间仍有几百点空间 → "珍惜牛市里的大跌"
情形3【最差】黑天鹅（2018模式）：抱团瓦解 + 突发黑天鹅（当年关税）= 雪上加霜，开启一年熊市
  当前（2025-09-04）判断：无黑天鹅迹象，概率最低
今年（2025）与历史的关键改进 = "工具银"：银行+保险+证券都成了管控工具——疯的迹象砸一下、跌狠了拉一下（以前只拉银行，吴村长之后证券也入列，如 0904 太平洋涨停给游资信心）
```

27. **[核心] 宽幅震荡的时限**（来源：20250904）
```text
IF 成交量 2 万亿级别 THEN 宽幅震荡不宜超过 1–2 个月（机构圈认为 2–3 个月，他不赞成）
IF 迟迟震荡不突破 THEN "震得越久越不好"，往下的概率增大
IF 抱团瓦解后资金轮动普涨其他板块（科技可以不大跌但不能大涨） THEN 情形 1 概率上升
IF 科技两天后又涨回去 THEN 情形 1 概率下降
```

28. **[核心] 权重票瓦解给体面离场**（来源：20250904）
```text
IF 大票/机构票抱团瓦解 THEN 会做双顶甚至三顶，给体面离场机会（茅台、2021 各"茅"例）
IF 妖股/小票 THEN 直接 A 杀，没有体面
IF 你不珍惜体面离场 THEN "你可能等不到它体面"
```

29. **[单源] 仓位/资产管理的庄稼比喻**（来源：20250904）
```text
结出果实要收割：短期涨幅超设计止盈就卖，不猜最高点（"你不卖，有的是人卖"）
无结果的庄稼要耐心：定期检查是否"生虫烂根"，确定无药可救再放弃（买电信/水电类垄断资产被套时的自检：当初买入逻辑变了吗？行业还有对手吗？）
IF 连红利低波/自由现金流（日跌 1.7%）都拿不住 THEN 属于新手村，别碰高波动品种（新手村→低波权重→高弹性，一关一关过）
IF 全仓单一资产 THEN 无论多看好都是给自己添堵——"东边不亮西方亮"
```

## 二、行情现场判断复盘（重点）

### 2025-07-01（137 分钟，短线专题）

- **行情阶段判断**：牛市中的题材活跃期。成交量 1.5 万亿（港股休市还能维持）= 流动性很好，"这段行情已经很好做了"；涨了六天刚出现第一天像样分歧，"已经很温柔"，没必要太悲观。
- **看到的信号**：银行开盘领涨（防御）；电池、多元金融/软件开发领跌；下午药+工业金属把指数拉起来（V 型）；微盘股六连阳；昨天连地产白酒都普涨；军工龙头（长城军工）主动封板、小弟换着跟。
- **推理链**：银行/电力/医药同起 = 风偏下降，但游资（永动机）只是转进防御的兄弟板块休息，不是离场；电池炒太久已鱼尾，与创新药比获利盘更大（"一路上涨调都不调的获利盘最大"）；微盘六连阳+狗不理普涨 = 物极必反的技术性调整需求。
- **结论**：短线——成交量守住 1.5 万亿之前积极做，跌破 1.5 万亿转观望；右侧好买点只在分歧转一致的那一两天；军工不能判死刑、可做主线候选；不好方向演化 = 数字货币/无人驾驶/电池继续跌→走负反馈，若军工在普跌中扛起大旗则主线概率大增。长线不受影响。
- **风险提示**（认错意识）：两融每天百亿级增长，"这些玩意儿最终一定会爆，但别去猜什么时候爆"；不猜顶、跟着热情做、给自己提个醒。

### 2025-07-10（129 分钟，杠杆牛专题）

- **行情阶段判断**：杠杆牛初期。"十年没见过这么优美的融资余额曲线"；6.25 摔杯后仅 7 月 4 日减少一天；对标 1415 年"小牛才露尖尖角"——两融规模接近但远没到全民炒股氛围。
- **看到的信号**：融资余额一路增；成交量 1.5 万亿；涨停数量上不去（大市值票不涨停涨不停 + ST 横住）；沪深300 创新高数量飙升、中证2000 下降；IF 偏多、IM 偏空；今天证券有涨停板。
- **推理链**：风格从纯小票切向中大市值趋势票（融资客偏好 R 标识、走趋势的票，"投机者先享受，投资者后享受"）；涨停数量下降≠赚钱效应差，是风格切换；大银行融资余额下降+小银行上升=板块内高低切，有人在卖大银行。
- **结论**：短线——只要融资余额不连续 2-3 天减少、上面不打压，短线都有得赚；选股用融资占比法（鱼头/鱼身）；防守点在"杠杆流何时断"。判断银行抱团后期会有不小回撤、现在买银行冲的是工具银+抱团不是估值。
- **海外**：美股新高后有 1-2 周安全期，回调=倒车接人；建议全球配置（5 月下旬已提示过）；港股被虹吸（资金去了美股+A股，且港股科技在"内卷"）。

### 2025-07-22（114 分钟，股期联动/顶层设计专题）

- **行情阶段判断**：杠杆牛加速段。今晨融资余额单日 +153 亿（6.25 以来最大，上次 150 亿+ 要翻到 5 月初）；指数已破 3 月高点、成交量 1.9 万亿——"这还不好做就没好做的行情了"。上有估值压制（3674 冲不上去的原因），下有两只金测（托底资金）。
- **看到的信号**：机差（基差）收敛中但仍为正 15；证券今天冲高但没封住涨停板（"要封就封彻底"）；银行被砸两个点后拉回（推断为龙哥看到 153 亿主动降温）；恒生AH溢价指数 124 创年内新低；水电站概念连板、海螺水泥涨停带动水泥。
- **推理链**：本波上涨=杠杆资金杠出来的；牛市再冲需要"东风"=券商带头大哥出涨停板（6.25 摔杯成功就是券商带的头），今天"万事俱备只差东风"；估值压制的根源=传统行业利润被压制，所以商品的牛决定 A 股的牛的成色；反内卷（供给侧2.0）+水电站（创造需求）+城市更新=一石三鸟。
- **结论**：短线——方向圈定反内卷+水电站，买点只有两类（日K级别震荡分歧 / 盘中异动打一枪）；长线——博弈三季度政治局会议预期，埋伏"远低于3300+形态低+好公司"（如柳工连 30% 都没涨不卖）；基差收敛到负数之前仍按震荡思路应对、单边思路不打满。**两手准备**：正反馈走成=权重牛；走不成=2021 式结构牛收场，所以牛市要配防御、赚了钱提部分出来、越涨越卖。
- **港股**：AH 溢价 124 按五年规律显示港股有阶段性见顶压力（触 120 附近 A 股都曾大回撤），但"还不能说就要见顶"；短线 A 股性价比更高、长线港股便宜。

### 2025-09-04（88 分钟，抱团瓦解日）

- **行情阶段判断**：牛市中的急跌分歧日，抱团瓦解但"瓦解=新的开始"。短期判断：宽幅震荡、up and down 加强版、过山车刚开始；"没有更多坏信号之前不用慌，我逢低做多不逢高做空"。
- **看到的信号**：创业板最多跌 5 个点（牛市流动性放大了瓦解的冲击）；CPO 抱团（新易盛等）跌得最狠；北证50 尾盘有承接（疯批资金还扎在场子里）；IM 基差周一标到 248 后两天收敛、IF 收敛到 160+（改善信号）；银行（农行拉 5 个点）、保险、证券（太平洋涨停）联手护盘。
- **推理链**：基差背离（现货涨期货压价）早已预警，"我不带大家看大家就忽略了"；抱团=交易拥挤度见顶（"你觉得随便买都赚钱的时候，最好的时光就过去了"）；8 月大家不看基本面（寒武纪 450 倍 PE 被喊价值洼地），跟踪基本面的人心里有杆秤；大金融三件套齐动=龙哥表态"还在场、还想继续玩这个牛"（宽基ETF今天尚未发力，属小维护级别）。
- **结论**：短线/波段——抱团瓦解后三种情形中当前介于情形 1 与情形 2 之间，1–2 个月内分胜负；权重票等体面离场（双顶三顶）；科技短期越大涨越不好，看震荡。长线——牛市任务未完成、不会就此结束；配防御+资产分散+按庄稼纪律止盈；港股科技是降息后流动性外溢首选、"不拥挤可以慢慢播种"。
- **认错/自我表露样本**："周一我减仓创业板，我也不知道减完周一又要跌，就是短期涨多了、到设计的止盈了我就卖""我经常卖飞""7 月底就喊保守的先卖一些，8 月又冲一个月，确实保守，但也有坏处——赚的少"。

## 四、世界观补充（Layer 1）

- [核心] 商品走牛，股市的牛才扎实；股市独自走牛而商品不走，泡沫更大。（0722）
- [核心] 资本市场永远预期先行：股市先起来→民间资本有信心→扩产→基本面改善→股市再走牛（"先有鸡还是先有蛋"式的顶层设计推演）。（0722）
- [核心] 本轮牛市上面控盘意识远强于 15 年：不等完全疯了再管，"疯的迹象就砸、跌狠了就拉"——银行/保险/证券都是工具。（0904，强化第十二章）
- [核心] 买的时候敲锣打鼓（汇金增持每季度可见），卖的时候不公布（21 年减持上万亿 23 年才披露）——巨大体量资金出货需要震荡。（0904）
- [核心] 没有救世主：等靠要思维（等国家队/游资/大V来救）是悲剧根源；荐股、"带你发家致富"多与杀猪盘同构。（0904）
- [核心] 任何资产都不能一直猛涨，"要对资产去魅"——涨到最后都是一地鸡毛/一地基茅。（0904）
- [核心] A 股科技看美股脸色：英伟达不涨我们科技不敢动；港股科技才是"真科技"但吃国际流动性。（0710/0722/0904）
- [核心] 牛市急涨阶段基本面会被彻底忽视（"8 月谁谈基本面就是拖出去斩了"），但跟踪基本面的人心里有杆秤。（0904）
- [单源] 美国市场"比较单纯"：经济差炒降息、经济好炒利润增长，死活都能炒；A 股能炒的少（微盘股、银行）。（0710）
- [单源] 港股=干儿子，看干妈（美股）脸色；AH 溢价五年规律（120 附近加仓/创新高减仓）自用多年。（0722）
- [单源] 杠杆资金是波动放大器：上涨和下跌都被放大，急涨急跌是杠杆牛常态；有杠杆才有"活水"击鼓传花。（0710）
- [单源] 股票比期货容易逃顶：期货跌起来快到爆仓，股票见底温柔（双顶、震荡）。（0722）
- [单源] 好的选股方式都是市场帮你选出来的（融资扎堆、涨停表现、人气排名皆是）。（0710）
- [单源] "牛市里赚啥都会被吐槽"，别被外部评价干扰操作。（0722）
- [单源] 顶尖操盘不是低买高卖，而是"不花钱让自己的东西涨上去"（国资工具化）。（0722）
