## 一、三类钱的完整体系（20250213/16/22 重点）

### 1.1 赚增量资金的钱（20250213，认知总纲第一课）

- **定义**：赚"后进场的人给我抬价"的钱。归根结底"都是赚别人的钱"，第一类赚新进场资金的差价。
- **核心认知**：股市长期（3–5年）看是经济的晴雨表；**中期（1年左右）看是货币的晴雨表**——注意是"实际流入股市的钱"，不只是货币政策。
- **增量资金传导链（2020–2021案例）**：放水 → 钱发给银行/国债/专项债 → 第一批增量 = 金融机构、企业、去银行借钱的杠杆资金 → 大涨后第二批 = 跑步进场的股民与基民 → 几股传花（越涨关注的人越多，增量持续流入）→ 抄底机构途中止盈但股市不立刻掉头（横盘）→ **增量枯竭 = 牛市结束**（2022年初）。
- **外资流向**：美元贬值人民币升值 → 外资持有人民币资产；反之美元加息升值 → 外资回流美国（2022 美元存款利率 0.25%→4%+ vs 国内三年期 2.75%，资本逐利必然搬家）。
- **他自己的案例**：2024-09-18 老美首次降息，A股 2717 点时他喊抄底——"增量资金在路上，不要怕"。这是鳄鱼派"成名之战"（B站起兵）的决策依据。
- **对应打法**：三年不开张，开张吃三年；时刻关注国内外货币政策、宏观经济、机构运行情况。

### 1.2 赚公司价值的钱（20250216）

- **定义**：机构之间相互讲故事、机构传花，在故事被戳破之前全身而退，留下追高的股民。
- **核心认知**：**实体经济里公司好坏是客观的，金融市场上是主观的**。"金融市场不是一加一等于二的科学，而是社会学。" 引索罗斯：任何金融市场都是幻象；投机的故事短暂，投资的故事持久。
- **好故事的标准（高股息红利为例）**：A股机构讲了十多年还在讲的故事；熊市里是"矮子里的高个"（资本总要干活），牛市里又有顺周期属性 → 形成机构共识的防御方向。他做私募时给企业闲钱（一两千万）配置红利做底仓，年均十来个点。
- **机构六大类**：龙队、公募、私募、险资、外资、其他资管。外资占比最少最坚定；**公募占比最多最不稳定**——机民集中赎回 → 基金被动砍仓 → 越跌越赎的负反馈，此时基本面再好也没用。
- **机构的五类买入理由**：宏观经济复苏、行业周期底部回暖、公司竞争力（垄断/卷死同行）、政策驱动、科技突破。**后两类必须证伪**：没有业绩支撑的政策与科技，机构只当短期炒作，出业绩后才当长线投资。
- **信息获取**：股东研究（F10）看机构增减仓；看研报学数据与逻辑（不是抄代码）；认识高管/基金经理（不打听内幕——消息能否掀起风浪取决于能否形成市场共识与合力）。
- **教训引用**：医药 2020–21 机构抱团瓦解，抄"估值低"的人半身腰——忽略了机构运行情况。

### 1.3 赚市场情绪的钱（20250222）

- **定义**：赚博弈差价。参与者四类：机构、游资、交易者、羊群——"三家赢一家，掏钱的都是羊群"。
- **指数人物化比喻（新增表述）**：上证50=刘备（主心骨，稳重无战斗力）；创业板=赵子龙（先锋军，关键时刻先动，机构进场的先行指标）；沪深300=关二爷（最均衡，**衡量机构行为最重要的指数**）；中证2000=张飞（游资题材股）。
- **三组共振**（强化已有第八章）：沪深300 vs 中证2000 = 机构 vs 游资（当天谁上班积极）；上证 vs 创业板 = 传统 vs 新兴；上证 vs 恒生科技 = 内资 vs 外资。共振涨=情绪好短线胜率高；共振跌=该休息。
- **剪刀差**：差值 1% = 分歧较重，2% = 分歧严重（与已有第八章一致）；**双方涨幅或跌幅都超过 2% 时不看剪刀差**（单边行情分歧无意义）。
- **情绪周期 6 阶段**：冰点 → 企稳 → 回暖 → 火热 → 过热 → 退潮。月满则亏。**但不是每轮行情都走满 6 阶段**，偶尔企稳直接过热再急跌（极端行情，多数人不适合参与）。
- **情绪是相对的不是绝对的**【阈值可计算】：过去一个月日均涨停 100 家，连续几天 80+ = 退潮迹象；熊市日均涨停 60 以下，几天飙到 80+ = 过热迹象。牛熊转换阶段不能单看量化表。
- **仓位原则**：大行情大仓位，小行情小仓位，没行情没仓位。大多数股民搞反：回暖初期没看到，火热时犹豫，过热才进场，被套后又在退潮期重仓猛干。
- **船长隐喻**：每一块钱都是船员；风浪大就靠岸，"风浪越大鱼越贵"的赌徒大多活不过三年。风险越大回报越大是新人误区。
- **主线识别四个字：强者恒强**——他大涨别人小涨，他小跌别人大跌，都大跌时他先反弹。
- **两种人气龙头**：① 机构打造的中军趋势龙头（市值大、通常不涨停、大涨→调几天→再涨）；② 游资打造的妖股龙头（散户市场里更得人心，对情绪影响更大）。妖股龙头三特点：有辨识度（连板高度高/涨幅至少接近一倍）、有参与度（要有放量换手板，不能全是秒板）、赚钱效应好（可不天天涨停但至少天天创新高）。
- **龙头结构**：一超多强型 / 前仆后继型 / 齐头并进型。只要还有龙头往上顶，主线炒作就没终结；少数情况下主线龙头被炒成独立抱团（老大自己涨，小弟不涨）= 失去号召力。

## 二、交易体系总纲（20250228 / 20250923 重点）

### 2.1 体系三部分与入门路径（20250228）

- **交易体系 = 认知 + 规律 + 技术**三部分（整个系列的骨架）。
- **9 个字**：买什么、怎么买、怎么卖。
- **目标决定体系（三档）**：
  | 追求 | 体系 | 赚哪种钱 |
  |---|---|---|
  | 年 10 来个点，牛市二三十 | 指数 ETF | 增量资金 |
  | 年 20 个点，牛市四五十 | 个股投资 | 公司价值（功夫在盘外） |
  | 职业以交易为生 | 个股投机 | 市场情绪（每天盘外 4 小时学习思考） |
- **新手两大纪律**：
  1. 别一上来就双开（投资+投机体系冲突，如安卓 iOS 装一部手机）。他做十年也要分主次：大资金投资做根基，小资金投机追求卓越。实在要双开：**七成资金投资 + 三成投机，放两个账户**。
  2. 先当学徒后赚钱：学徒阶段投入的资金即使全亏也不影响生活；稳定盈利后再加本金。
- **技术是工具**：任何策略要有核心变量（技术流看量价/均线/形态）；消息与基本面是次要甚至不看（对纯技术流而言）。策略持续失效 → 暂停、休息观望、或换策略。"兵无常势，水无常形"。
- **学法**：先厚后薄，博览群书 → 化为己用；技术分析必须结合市场环境（同一策略牛市大赚、熊市亏损累累）。

### 2.2 体系里的变与不变（20250923，十年自述）

- **巴菲特案例讲"变与不变"**：不变 = 以基本面分析为核心；变 = 捡烟蒂 →（伯克希尔纺织厂踩坑）→ 合理价格买伟大公司 → 雪球复利 → 体量所迫演化为保险打底、能源交通护航的多元帝国。买日本五大商社 = 借日元（0.5% 利息）收 5% 股息，净赚 6 倍利差。
- **他自己的十年演化（自述时间线，重要人格素材）**：
  - 2015 入市：纯投机客，利弗莫尔趋势策略，尝到甜头也摔跟头；股灾让他明白"强如祖师爷都多次破产，从市场带走的利润才是真正的利润"。
  - 2016–17：进入金融行业接触价值投资，"功夫在盘外"。
  - 2018 初：基本面恶化但市场反常抱团上涨 → 嗅到危险离场，躲过一劫。
  - 2018-10：重仓抄底（价值体系说跌无可跌），煎熬三个月，鬼故事满天飞。
  - 2019：反转，第一桶金——**入市到第一桶金花了 5 年，交易天赋几乎是零**。
  - 2020–21 结构牛：价值体系成熟，白酒/医药/风光锂/科技泡沫破灭时全部躲过；"赚一定的泡沫利润但不迷恋泡沫"。
  - 2022 初：第二个转折点——同门四种操作（重仓等突破 / 止盈留底仓 / 清仓观望 / 做空），他选做空，收获丰厚后收手。
  - 2022–23：机构退场游资天下，趋势投机作辅助，投资仓位极低只打底仓。
  - 2024：第三个转折点——熊市末尾重仓抄底，体量迅速扩大；此后不再个股投机，**价值投资为主、股指期货投机为辅**，商品有大行情偶尔趋势投机。
- **不变的**：投资为主投机为辅；价值投资是安身立命根本；稳定第一，追求卓越第二；**重仓都发生在熊市末尾**；牛市每上一个大台阶做减仓。
- **变的**：做期货、海外市场、做空、对冲。
- **原则句**：一开始坚持一招鲜，做到稳定盈利赚第一桶金；之后与时俱进调整改进甚至推翻自己，但保持本心——"如果你是鳄鱼，改进的方向是更有耐心、更果断、更有洞察力，而不是强迫自己天天去追兔子。" 他明确说自己永远成不了龙虎榜游资，擅长的是宏观基本面与整体大势。
- **天道观**（呼应行业周期篇）："天道规律决定最终结果，人为干预只会改变其中的过程。"

## 三、新增规则（IF…THEN）

> 与已有 03-rules.md 重复的不列。标 [单源] = 仅本系列一处来源。

### 3.1 目标与执行

```text
IF 波段交易 THEN 单笔目标止盈 5%–10%
IF 趋势交易 THEN 单笔目标止盈 20%–30%
IF 长线投资 THEN 单笔目标止盈 30%–50%
（来源：20250929）[单源]

IF 趋势单 THEN 止盈 30% / 止损 -8% / 持有时间上限 2 个月
（来源：20250929，他的"基础模型"）[单源]

IF 达到目标止盈/止损/持有时间上限三者之一 THEN 本笔交易完结束局
IF 出现其他任何结果（包括中途小赚离场） THEN 判定本笔交易失败（执行失败）
（来源：20250929）[单源] —— 他要求"浮盈 20% 就止盈了要给自己两巴掌；-8% 打止损离场要给自己鼓掌"

IF 稳定盈利之前 THEN 投机资金 ≤ 总资金 30%
IF 稳定盈利之后 THEN 投机资金 ≤ 60%
（来源：20250524）[单源]

IF 双开（投资+投机） THEN 资金比 7:3，分两个账户
（来源：20250228）[单源]（注意与已有第四章"7:2 底仓/波段"是两回事）
```

### 3.2 止损止盈（投机四原则，20250524）[核心]

```text
原则1 IF 触及止损（金额止损：浮亏 -5%/-10%；或价格止损：跌破前低/均线） THEN 立即离场，止损可以大但不能没有
原则2 IF 浮盈已现回吐迹象 THEN 及时止盈，勿让盈利变亏损（金额止盈：+5%/+10%；价格止盈：前高/均线）
原则3 把自己当机器人：策略制定后不更改——不额外加仓、不改止盈止损、不延长持有时间（20260328 强化）
原则4 IF 策略连续失灵（环境改变） THEN 马上停手或换策略
```

### 3.4 指数共振四规律（20250630）——强化已有第八章

```text
规律1 权重大票先于小票见阶段顶：先下跌、先止跌、先反弹（时间差可长可短）
规律2 IF 流动性越好 THEN 小票热情越高（可无视权重下跌继续冲），见顶后跌得也越快
规律3 [可计算] IF 上证50 单日跌幅 ≤1.5%（"权重稳住"） THEN 题材小票可以继续炒，不判恐慌
          IF 上证50 跌幅 >1.5% THEN 视为"大跌"，题材炒作难以为继
规律4 IF 市场诞生主线炒作 THEN 更容易走出流畅的指数共振行情（如 2025 年 1–3 月 AI+机器人双主线，量能 2 万亿）
```

### 3.5 融资余额（杠杆资金，20250710）[单源]

```text
IF 融资余额持续增加 THEN 融资客情绪偏买方，强势市场
IF 市场回调 AND 融资余额同步持续减少 THEN 往往有不小的下跌
IF 融资余额持续 3–4 天减少 THEN 提高警惕：大资金可能在撤离（偶尔一两天减少正常，融资客也要止盈）
背景规律：杠杆助涨助跌；融资余额对顶底有滞后性（市场见底后融资客才进场，见顶后融资客仍在买）
券商融资门槛：开户满 6 个月 + 本金 50 万 + 征信良好；杠杆 1:1，利率 5%–8%
场外配资：杠杆 5–20 倍，利率 15%–30%+，属非法证券业务
```

### 3.6 题材炒作三分法（20250603）[核心]

```text
分类：
- 结果型：尘埃落定（安倍遇刺/夺冠/谐音梗/节日）。游资点火第二天基本就走 = 博傻，持续性差 → 大多数选手不参与
- 预期型：未发生但可预知（夏炒电、节前炒旅游）。核心 = 预期差 = 实际结果 − 市场预期
- 发展型：已发生未结束（哪吒2/光线传媒、ChatGPT 行情）。持续性看市场情绪 = 技术形态 + 外界驱动

预期型参与三节点（化工原料 Q2 旺季案例）：
- 节点1（3月，现货没动）：价格成本低、时间成本高，走势大涨一天回落一周
- 节点2（4–5月，现货开始涨）：趋势流畅，双低 → 新人首选
- 节点3（6月，现货大涨预期差趋零）：博弈加速，价格成本高、时间成本低 → 老手首选

参与前四问：
IF 新题材出现 THEN 先答：①预期兑现了吗？②还剩多少预期差？③事件还会发展吗？④盘面反应是否强势？
（发展型警告：绝不能因为还有预期、还有利好就忽略盘面反应——砸出大阴线、套牢盘增加 = 炒作提前终结）
```

### 3.7 赛道行情（20250611）[核心]

```text
宏大叙事四要素：故事大到人人皆知 + 政策扶持 + 有业绩支撑或技术优势 + 板块公司足够多（容量够）
（反例：旅游板块容量不够；可控核聚变/室温超导听不懂）

IF 公募私募建仓（初步挖掘+前期锁仓） AND 游资拉升造势 AND 三方认知达成一致 THEN 主升浪来临
IF 主升浪结束 THEN 成长股开始衰变为周期股（"所有成长股最终都会变成周期股"，中间只隔一个主升浪）
季节法：春天潜心观察 → 夏天果断买入 → 秋天逐步卖出 → 冬天默默观望
IF 人人都看好 THEN 开始卖出
```

### 3.8 行业周期（20250416）[核心]

```text
三拐点择时：
- 盈利拐点：先行指标 = 营收增速与扣非净利润增速。IF 连续增长后增速明显放缓（如 20%/30%/25% → 10%） THEN 保持警惕，查财报找原因
- 供给拐点：看扩产能/去产能。IF 出现跨界扩产或为抢份额盲目扩产（恶性） THEN 行业上行周期加速结束
- 需求拐点：看宏观经济 + 技术革新。技术突破必须"商用、有普及苗头"才算数，实验室突破不算

周期长度参考（他给的数字）：房地产 20–30 年 / 金融 8–10 年 / 白酒 7–10 年 / 医药 5–8 年 / 汽车 4–6 年 / 消费电子 3–5 年 / 养殖 3–4 年

合格线：职业选手单笔周期投资翻倍才及格；业余选手盈利至少 50%
天道观：人为干预改变过程不改变结果（干预只能缩短萧条时间、减小萧条伤害）
去产能 = 行业走出寒冬的必经之路；跨界者最先被淘汰（无技术优势），无规模无现金流的小公司次之
```

### 3.9 技术分析四核心（20250519）[核心]

```text
核心1 K线语言分前兆信号与确立信号：
- 放量加速 = 见顶前兆信号（可分批止盈/持有等确立/清仓博鱼尾）
- 见顶确立信号三种：放量大跌 / 非自然回撤 / 三日或长时间横盘震荡不新高
- IF 出现确立信号 THEN 持仓者全部清仓，持币者去看其他

核心2 K线语言会说谎：突发事件与人为操控会造出小概率行情 → 接受不确定性，做大概率的操作

核心3 理性比经验更重要：
- 技术分析两大假设：历史会重演（行为金融学）；价格包含所有信息（含未公开）
- 大资金建仓的三种 K 线痕迹：大跌后放量 / 历史低位横盘震荡 / 周K级别箱体突破
- 看图习惯：先看最近两年日K，再看上市以来周K
- IF 历史经验与当下盘面冲突 THEN 以当下盘面为决策主要依据（既不喊"这次不一样"也不被经验主义束缚）

核心4 分强弱，找拐点 [可计算]：
- 大跌后的横盘机会多；大涨后的横盘风险多
- IF 大跌后连阳放量上涨 THEN 弱转强信号 = 拐点
- [阈值] IF 指数单日涨跌超过 2% THEN 异常波动（多数时候指数波动在 2% 以内）
- [阈值] 创业板大跌后当日收盘涨幅 >2% = 弱转强买入信号；填坑过程中涨幅 >2% = 强者恒强；填坑完成后或大涨后涨幅 >2% = 加速见顶卖出信号
- 单根日K只代表当天，必须结合至少最近一个月走势
```

### 3.10 胜率赔率效率（20260328）[核心]

```text
不可能三角：胜率、赔率、效率最多取其二（存款=高胜率低赔率低效率；彩票=高赔率高效率低胜率）
- 快枪手型：高效率高胜率低赔率（快进快出小赚小亏偶尔大赚大亏）
- 趋势型（利弗莫尔）：高赔率（≥3:1）高效率低胜率（10 笔可能 7 止损 3 大赚）；清仓试探→止损亏小钱→做对浮盈加仓至重仓；伴生大起大落甚至破产

他的改良版体系：高胜率 + 高效率 + 低赔率
- 赔率 >1 通常 <2（例：止损 50 万、止盈 60–100 万）
- 通过放大止损降低赔率、增加容错率，从而提高胜率
- 不浮盈加仓，初期就把仓位分批买足，不重仓猛干留有余地

开仓前计算（他的三笔实战）：
- 中证1000股指多单 8 手，保证金近 200 万，止损 50 万，止盈 60–100 万 → 实际 +85 万，14 个交易日
- 燃料油空单 10 手：波段仓位 20–30 万，妖气品种只配 10 万
- PVC 空单 100 手：保证金 30 万，止损 15 万，止盈 20–30 万 → 实际 +30 万

IF 胜率小 THEN 轻仓；IF 胜率大 THEN 仓位可适当大；不重仓、不单押
基本面是开仓第一要素，技术面只是辅助
体系缺点自认：赔率小 → 必须维持高胜率 → 必须持续跟踪宏观与行业基本面 → 容易过早买卖 → 遇极端行情照样打止损 → 所以必须分仓
短线盯国内品种不盯国际品种（国内有自己的炒作规律：龙头、跟风、卡位，与 A 股题材炒作如出一辙）
```

### 3.11 指数 ETF 体系（20250308）[核心][可计算]

```text
心法两条：①耐心持有、知足常乐、不攀比（比买卖技巧更重要）；②大周期为主、小周期为辅

流动性周期底部特征（左侧分批买入信号）：
成交量极度缩量（最低 5000 亿以下）+ 机构被动砍仓 + 权重蓝筹三级跳 + 融资客被强平 + 千股跌停

经济周期修正：IF 经济数据明显改善 THEN 15 倍不算高（抬估值），仓位可适中
截至 2025-03：沪深300 PE 11 倍

执行数据（他接触上万个业余交易者的反馈）：90% 能赚钱但嫌慢放弃；60% 熊市拿不住；50% 断续做；最终 <10% 坚持把大资金放指数上
```

### 3.15 博弈思维与资金规划（20250704）[核心]

```text
抛硬币模型：规则完全公平，资金小的一方输光概率也更大（100 元 vs 1 万元）→ 小散户天然劣势
```

### 3.16 快与慢（20250616）[单源]


### 3.18 等风来 vs 随风起（20250623）[核心]

```text
长线只有两种买进策略：
- 左侧埋伏（等风来）：基本面为主技术面为辅。价格成本优势，时间成本高（短则一季长则几年）
- 右侧顺势（随风起）：技术面为主基本面为辅。节约时间成本，价格成本可高可低，需接受频繁止损

左侧买进后三种情况及应对（都要求提前写好）：
①风还在路上：不动等风 / 逢低加仓冲高减仓滚动 / 按间隔分批加仓一股不卖 / 设最长期限（3 个月–半年）风没来就走人
②风来了：+30% 减半仓 +50% 清仓 / 基本面拐头再全止盈 / 滚动持仓抵仓拿趋势
③基本面触底后再下探（碳酸锂案例：行业共识 20 万是底→10 万是底（成本线）→现 6 万）：
  两个原因：低估国内企业内卷能力（明面减产暗地降成本）+ 企业期货空单套保压制
  对应：止损离场 / 躺平熬 / 滚动降成本 / 越跌越买死磕（他不推荐，但列出）

阈值：左侧单笔 <30%–50% 利润 = 不划算；长线也要止损 20%–30%（可大到 50%，配翻倍预期则风险回报比合理）
右侧阈值：止损不超过 20%，不浮亏加仓，回调超两周离场等再突破
关键区分：IF 波动来自大盘 THEN 忽略；IF 波动来自行业与公司基本面 THEN 重视
（2025-06 时点判断：煤炭基本面还在探底、资金在做高股息抱团；猪周期风几年没来，适合左侧不适合右侧）
```

### 3.20 赚翻倍（20250929）[核心]

```text
三条件：①心里先有翻倍（目标定下来）②严格执行排第一盈亏排第二③保留主观思考
```

### 3.21 独立对待每笔交易（20260309）[核心]

```text
每笔交易是独立事件：长期胜率 60% ≠ 每 5 笔必中 3 笔；可能连错 5–10 次，样本量越大容错率越大
IF 交易模型在理想状态下都推演不通 THEN 现实中一败涂地（先做理想模型推演）
调仓两大坑（张三案例）：
- 趋弱加强（把弱势止损、全仓加到强势 A）：容错空间进一步降低，满仓单行业
- 去强加弱（止盈赚钱的、加仓亏损的摊成本）：源于损失厌恶，往往最后重仓割肉——赚时小赚亏时大亏
IF 未稳定盈利 THEN 仓位相互独立互不流通：10 万分 5 个行业 ETF 各 2 万，各行业独立分批建仓；止盈后可新开 F 行业，但不得把资金加进已满仓的其他行业
IF 已稳定盈利、胜率赔率更高 THEN 可尝试仓位流通的调仓方式
```

### 3.22 交易与围棋（20250425）[单源]

```text
认知一：多想几步——下单前五问：为什么买？符合策略吗？止盈设了吗？止损设了吗？明天可能怎么走、应对方案是什么？（"先买再思考，被套了到处问"是股民坏习惯）
```

### 3.23 学习第一步：书单（20260212）[单源]
