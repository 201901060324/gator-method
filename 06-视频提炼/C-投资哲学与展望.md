## 一、新增规则（IF…THEN）

### 1. 指标可信度类

- **R1** IF 大资金通过 ETF 二级市场集中卖出（成交量可见放量）THEN 这是"敲锣打鼓地卖"，往往**不是**见顶/结束信号；IF ETF 份额悄悄减少（一级市场赎回成一篮子股票、分散到个股卖出，成交量看不出）THEN 反而要小心。【单源】（20260524 开头）
  - 强化已有第十二章（龙哥行为）与第十五章反例规则：新增"悄悄卖比敲锣打鼓卖更危险"这个反向判据。
- **R2** IF 任一单指标（如 ETF 份额）出现与行情矛盾的表现 THEN 不得作为唯一决策依据。案例：科创50 份额 2025.6-2026.5 持续减少（减少 55 亿份，仅次于中证500），却是宽基里涨得最好的——"不要低估了家人们（散户申购）的力量"。【单源】（20260524 前段）
- **R3** IF 判断 ETF 份额变动的主体 THEN 记住：一般公募不会主动赎回（赚管理规模和管理费）；大规模主动赎回来自私募、资管计划、"上面"。用于归因，不要一概说成"机构跑路"。【单源】（20260524 前段）
- **R4** IF 做多 THEN 心里必须有**基本面的顶**（不是技术面的顶）；IF 做空 THEN 心里必须有**基本面的底**（行业盈亏线）。不知道什么价格高估/低估，就不做。【单源】（20260129 中段）

### 2. 数据失真类（商品/基本面）

- **R5** IF 解读消息面 THEN 默认"消息是为行情服务的"：持续上涨时全是好消息，一下跌全是坏消息；近期基本面最易失真，存在夸张和作假。【单源】（20260129 前段）
- **R6** IF 品种是国际定价（金、银、油）THEN 产业资本不易控制，现货/期货共振信号可信度较高；IF 非国际品种 THEN 现货报价操作空间很大（报价≠实际成交），"期现共振上涨"可能是假信号。【单源】（20260129 前段）
- **R7** IF 资金少、经验少 THEN 不碰庄性明显的商品品种（他点名：纯碱最明显、多晶硅、碳酸锂），尤其农产品——流动性小，他估计有的农产品里 80% 资金是产业资本。【单源】（20260129 后段）
- **R8** IF 上游资源品价格暴涨 THEN 政府不会放任无限上涨（地方要保就业，关矿关线流失就业），上涨有政策约束顶。【单源】（20260129 中段）

### 3. 仓位与执行类

- **R9** 大行情大仓位，小行情小仓位，没行情没仓位。【单源】（20260129 开头）—— 强化已有第四章仓位管理：补充"行情级别 → 仓位级别"的映射。
- **R10** IF 做期货 THEN 必须轻仓（他当下风险度 <50%），且**千万不要追加保证金**——被反向波动要求追加保证金是期货大忌。【单源】（20260129 开头）
- **R11** IF 行情级别判断为小行情（空间不大）THEN 仓位就小一点，做一段就收，"你的策略是什么，你就执行什么"，卖飞了也不可惜（"过段时间你都会庆幸"）。【单源】（20260129 开头）
- **R12** IF 突发事件冲击导致大跌 THEN 事件"来得快去得也快"，不因突发事件清仓离场——三月份看着突发事件走掉的人，错过后面整波上涨。【单源】（20260524 前段）
- **R13** IF 短线/情绪股持仓 THEN 无法用基本面判断离场点，离场信号由市场给出："情绪好的时候完全看不出不持有的理由，突然有一天市场告诉你你要走了，你就会走"——信号出现即执行，不等解释。【单源】（20260524 开头）
- **R14** IF 短线投机做得特别好 THEN 可以加大仓位做；IF 做得不好 THEN 回归长线、指数、价值投资，"过程折磨一点，结果很美好"。【单源】（20260129 结尾）

### 4. 机构持仓视角类

- **R15** IF 做短中期（一个季度、一两个月维度）THEN 跟机构加仓方向做（看基金季报前十大持仓、ETF 份额变动，找高度重合个股）。【单源】（20260524 中段）
- **R16** IF 某行业机构持仓占比已减到历史 10%–20% 的位置 THEN 再跌基本不是机构砍仓（无人可砸），反而会吸引长期配置资金进来打底 → 长线"物极必反"配置方向。【单源，带数字】（20260524 后段）
- **R17** IF 全仓押注单一风格（"全跟小儿子做生意"）THEN 牛市里无异于赌博；正确姿势是一边做生意一边种地（进攻+防御都配）。【单源】（20260524 后段）—— 强化已有第七章攻防并重。
- **R18** IF 回顾 2023-2024 THEN 当时机构全在红利/高股息/国债，科技"狗都不看"——现在反过来说明：**机构共识本身就是反向指标**，要往共识的反面找下一段机会（他称之为逆向思维）。【单源】（20260524 后段）

### 5. 宏观监测类（2026-05 时点，Layer 5 性质强）

- **R19** IF 盯海外利率风险 THEN 主盯**日债**不盯美债：日债预警线 2.0，当时已到 2.72 属高位；美债 4.5% 不构成预警。日债飙升的机制是输入性通胀 → 部分套利资金回流日本（卖美债美股）。下一个观察点：日本利率决议（他给的日期：6 月 16）。【单源，2026-05 时点】（20260524 中段）
- **R20** IF 判断市场情绪位置 THEN 看市场在交易什么剧本：三月份交易"最坏情况"（核战争）→ 砸出坑是机会；当下交易"最好情况"（不加息、通胀回落、航线打通、AI 继续涨）→ 超买信号，"能想到的好东西都交易进去了，你还能怎么好"。汇率端验证：当时汇率只反应好消息、不反应坏消息，就是险情信号。【单源】（20260524 中段）
- **R21** IF 提交易假设 THEN 最小单位是**周K 级别**；日K 以下级别的假设没有参考意义（"跟掷骰子差不多"）。【单源】（20260524 中段）
- **R22** 交易决策流程（他再次完整口述）：大胆假设 → 小心求证：收集信息 → 处理并提出假设 → 根据假设制定交易策略 → 一步步看市场有没有按假设的事态发展 → 不符合就修正假设。【单源】（20260524 中段）—— 强化已有 15.3"只跟随不预测"：补充了"跟随"的具体操作件——跟随 = 持有假设 + 持续验证 + 及时修正。
- **R23** IF 担心大型 IPO 抽血 THEN 不必过度盯：原始股成本极低（有不到一元的），机构不可能精准卖在最高点，"150 腰斩出货都赚钱"。【单源】（20260524 中段）
- **R24** IF 龙哥拉动核心资产出现"整齐划一"的上涨（茅台、神华、电信、移动、长江电力这类高股息权重同日齐涨）THEN 判定是社保、险资、汇金受指挥进场 → 指数会好看，但小票短线情绪炒作环境差（"明知山有虎"不做）。【单源】（20260129 后段）
- **R25** IF 会议（重要会议）临近 THEN 政策受益板块会"动一动"（博政策），开完会就不好说了——会前炒预期是规律。【单源】（20260129 后段）
- **R26** IF 长线左侧捡便宜 THEN 只围绕三点筛选：**政策、宏大叙事、估值**。宏大叙事=科技/AI；估值=被宏大叙事冷落、PE 低、业绩不错的传统行业。【单源】（20260129 后段）—— 强化已有第十四章左侧操作三点，给出具体的筛选三轴。
- **R27** IF 行业全行业困难（内卷）THEN 找"熬死同行"的龙头：同行卷死，市场份额归它，业绩反而好，是下一个周期最亮的（他举例：光伏、电池已有验证；地产公司若减少 90%，剩下的 10 家就是香饽饽）。【单源】（20260129 后段）
- **R28** IF 制造业、业绩不错、PE(TTM) 仅十几二十倍、被宏大叙事资金冷落 THEN 是拔估值修复候选（金属化工是已验证的一波；后面还会有别的行业轮动）。【单源，具体倍数见存疑】（20260129 后段）
- **R29** IF 判断牛市是否还在 THEN 看资金面而非点位：融资余额没有明显下降 + 成交量仍在两万多亿 → 牛还在，不用恐慌。【单源，2026-01-29 时点】（20260129 结尾）
- **R30** IF 做海外/美股 THEN 走合规渠道（QDII、境内 ETF、50 万门槛的正规开户）；最大障碍不是"买不了"，是"拿不住"和"跌的时候不敢买"——每次一跌全是崩溃论鬼故事。【单源】（20260524 后段）

## 二、投资哲学总纲（20260524"小马过河"重点）

这是他罕见的完整自我表达：借寓言把"方法没有对错、只有适配"讲透。规则化如下：

### 2.1 核心命题：风险因人而异，别人的答案不可照抄

1. **三种动物 = 三种生存方式**（对应资金生态位的自我版本）：
   - **大象**（巴菲特型）：说"水不深"。只等月K 级别以上、指数级别的大跌才出手，十年可能只有 2020 年那一次开仓机会，开进去就不动。普通人做不到——"你做得到吗？做不到"。
   - **松鼠**（超短型）：说"水很深"。做日K 级别交易，听说周K 调整可能明天就清仓，跌稳了再回来。这是它的生存方式。
   - **小马**（绝大多数人）：大象说水不深，你别轻易下河去模仿；松鼠说水很深，你也别怕——**自己踩着石头过河去实践**。
2. **规则：你是什么动物，就按什么方式做。看多大级别的周期，就做多大级别的周期。**不要用别人的周期长度要求自己，也不要把自己的周期强加给别人。
3. **不要把自己自动代入别人的收益叙事。**"大家只会看到自己想看到的"——幸存者偏差批判：老粉传说"创业板 1500 精准抄底、翻倍走人"，实际是 2020 年 1700 多就开始分批买，越跌越买（1600/1500/1400），2 月双底回落、6-7 月抄底遇黑天鹅砍过短线、8 月底满足信号再干、又横一个月、918 降息才启动。
4. **推论：别人告诉你答案也没用**——"你自己不理解其中的道理，别人跟你说了你也拿不住。"理解深度决定持有定力。
5. **评价任何人（包括他）的观点，看完整周期，不看一两天**：他举例某讲龙头的博主周一看好、周四喊风险、周五真跌了，粉丝反而骂"你不是说一直涨吗"——听众只截取对自己有利的片段。

### 2.2 大儿子 / 小儿子 / 老太爷（20260524 中后段，比"资金生态位"更宏观的产业-政策叙事）

- **大儿子 = 种庄稼的** = 传统行业、红利、防御板块：能养活人、饿不死，但年轻人看不上、日子拮据；老太爷不准他做生意，还让他**多存钱**（存的钱放在老太爷那儿）。
- **小儿子 = 做生意的** = 科技、AI、进攻板块：来钱快（"一年两年生意抵种五年六年庄稼"），但整天应酬身不由己，做死的多；老太爷也会敲打他（降温）。
- **老太爷 = 上面的意志**：偏心是有意的——怕两个儿子都下海家里破产，必须留一个种庄稼的、留存粮。**真出事时，老太爷会拿大儿子存的钱资助他，把家撑起来**（= 高股息/传统板块里存的资金和筹码是护盘资源）。
- 引申规则：
  1. **任何一门生意/收益都有周期**（互联网、智能机、新能源都是周期，只是长短）；跟着小儿子做生意不赚钱的人，会回来种庄稼——风格轮动的微观机制。
  2. **种庄稼（防御）饿不死，做生意（进攻）会做死**——所以不能全仓进攻（呼应 R17）。
  3. 选择比自己想象的广："我们不像他们没得选"，可以一边做生意一边种地。

### 2.3 心态哲学

1. **越是迷茫、艰难的时候，越要相信你的人生刚开始。**不给负面心理暗示："你越给自己负面的心理暗示，你越不行。"
2. **"回本就不干了"的心态，越回不了本。**
3. **经历量级自省**：入市两三年、一轮牛市进来的，连股灾都没经历过，不要说"这就是人生、这就是股市"。什么叫熊市——"跌一点点几年，这才叫熊市"；三月份那种、去年 4.7 跌一两天就回来的，都不算。
4. **A股最不缺的就是机会**，踏空一段仓位就走，随时有舒服的姿势接回（针对"卖飞焦虑"）。
5. **做空单/做不熟的东西之前，先问自己懂不懂**——不懂就轻仓娱乐（他自己最近商品就是"小行情小做"）。

## 三、基本面：长期与短期（20260129 重点）

他的基本面框架以碳酸锂为教具展开，结构如下：

### 3.1 短期基本面（驱动几天到几周的行情）

1. **先给近期基本面定性**：它影响短期行情，但**最容易失真**——存在夸张和作假（R5/R6）。
2. **校验数据可信度**：这个品种是不是国际定价？现货报价是"实际成交"还是"口头报价"？非国际品种的期现共振要打折扣。
3. **看交易所有没有动手**：限仓、提高保证金 = 官方认定过热；叠加"预期过强、基本面没跟上"，就是短空依据（他本次做碳酸锂回撤的逻辑）。
4. **检测预期与全行业现实的矛盾**（关键一步）：2026 年每家车企销量目标 20%–30%、甚至 40%–50%，但全行业（国内+海外）总增长可能不到 10%——"每个车企都觉得自己能卷死对手"。**个别预期加总远大于行业总盘 → 过于乐观 → 做回归。**
5. **小行情按 R11 执行**：空间不大 → 仓位小 → 做一段就收。

### 3.2 长期基本面（定价值区间：顶和底）

按产业链自上而下：

1. **上游（资源端）定"亏损底"**：找行业平均盈亏线——碳酸锂 2026 年约 **8 万/吨**（工艺好的企业能更低），这是企业利润线，价格杀到这附近跌不动（做空心里有底）。同时是反内卷去产能政策的底线约束。
2. **上游定"乐观顶"**：靠自己收集的产业链/调研信息给区间——他给碳酸锂 2026 乐观区间 **14–16 万/吨**；且回不到当年 50 万（上游涨价会传导杀死中下游，政策也不允许，见 R8）。
3. **中游看话语权**：龙头电池厂是**长协价**，成本相对固定，碳酸锂涨价冲击的是二三线小厂——所以"碳酸锂涨价利空电池"对龙头不成立。
4. **中游找确定性增量**：2026 年电池的确定性增量是**储能**。选股三条件：有溢价权 + 业绩能打 + 储能业务占比可以。
5. **下游看竞争格局**：整车内卷（"谁卷死对手谁活下来"），你不知道谁能活到最后 → 不好做；亮点只在出口，但出口又牵扯国际矛盾（欧洲反复）→ 也不稳。
6. **综合定价**：把供给（成本线+去产能进度）和需求（储能增量 vs 整车内卷）两端叠起来，得出"心里有顶有底"的区间，区间外才是错杀或泡沫。

### 3.3 商品 vs 股票的基本面差异（他的提醒）

- 股票和商品走势**有出入**，不互为信号（"股票那边走完了"不等于商品走完了）。
- 商品市场产业资本极多，"不仅能影响价格，更能控制基本面"（R7）。
- 所以他给普通人的建议：多炒股，少碰庄性明显的商品。

## 四、2026 展望点评（20260124）

## 五、世界观补充（Layer 1）

- **[核心]** A股是"政治经济学"市场：上面（老太爷/龙哥）的意志通过产业布局直接塑造风格——不准谁做生意、让谁多存钱都是安排。20260524 的"大儿子/小儿子"寓言是他这层世界观最完整的口述版。
- **[核心]** 市场永远在两个极端之间摆动：交易最坏情况 ↔ 交易最好情况，很少停在中间。极端本身就是超买/超卖信号（R20）。（20260524）
- **[核心]** 消息为行情服务：行情决定消息的解读方向，不是消息决定行情。（20260129，R5）
- **[核心]** 任何一门生意/收益都有周期；收益的来源会轮动（种庄稼↔做生意），机构共识的方向本身就是下一段机会的反面。（20260524，R18）
- **[核心]** 商品市场被产业资本深度控制，普通人在商品上的信息劣势远大于股票。（20260129，R6/R7）
- **[次要]** AI 发展太快对当下经济"帮助有限"（措辞他很谨慎）：不利于就业、不利于他想要的温和通胀，预期会有文件限制 AI 大幅替代岗位；美日想用 AI 提升生产力降通胀，但控制不了能源价格。（20260524，单源、时点性强）
- **[次要]** 外卖、网约车、快递"三大件"不能无限承接就业。（20260524）
- **[次要]** 市场资金有惯性：参与者是人，人有记忆，会重复做同样的事（年年讲"明年是 AI 应用爆发之年"，年年年初 AI 应用动一动）。（20260129）
- **[次要]** 全球化配置值得做（东方不亮西方亮），但只走合规渠道、用 ETF 起步。（20260524，R30）
- **[次要]** 股票和商品的基本面有出入，互为参考但不同步。（20260129）
- **[单源]** 大型 IPO 抽血担忧被高估：原始股成本极低，出货是长期的、不择价位的。（20260524，R23）
