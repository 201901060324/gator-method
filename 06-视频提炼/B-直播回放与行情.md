### 1.9 板块的"两只羊"结构（20240919，强化已有第三章赛马判定）`[单源]`

> "一个板块想走主线出来，需要两只羊：一个是妖股领头羊，这是游资打造的任务；一个是机构打造的中军权重。"

### 1.21 大趋势的四个核心变量与排序（20260304）`[核心]`

> **流动性 > 宏观经济 > 政策 > 宏大叙事**（他明确把流动性排第一）

- **流动性**：决定任何金融市场的下限（"玩的人越多赌场越有意思"）。海外主要盯美日（日本低利率曾提供全球流动性，2024 年 7 月首次喊加息时全球剧烈反应）；国内已定调"积极宽松"。传导链：干仗→能源价格→美国通胀→美联储决策→流动性→全球。
- **宏观经济**：只在极端萧条（如口罩）或极端繁荣时才成为主导；平时看 PPI、GDP、消费者数据；**物流数据（港口吞吐量）不易美化**，比很多数据真实；用电量稳增。
- **政策**：国内必须看，"**开会大于干仗**"；海外在老特之前基本不用考虑（小政府传统）。
- **宏大叙事**：=火车头行业，**不一定是高新技术**——稀土（反制牌）、电网整合、黄金（美元信用替代、央行购金）都是宏大叙事。

```text
IF 担心牛转熊 THEN 把四个变量逐一检查是否"严重恶化"
IF 只有单一负面因素（如"中石油涨停后牛转熊"之类统计） THEN 不严谨，不作为决策依据——牛从来不是被单一因素结束的
```

### 1.22 突发事件的四种组合与市场反应（20260304，详见第三节）`[核心]`

核心结论先行：
- 事件只有两种发展路径：**逐渐发酵 / 逐渐消散**（利好利空各两种，共四种组合）。
- **市场对任何事件（无论好坏）的反应都是刚出现时最剧烈**；即便事件持续发酵，对市场的影响也递减；后市走势取决于**新变量**，不再取决于原事件。
- "从来没有一个大趋势是由单独的事件驱动的，都是多个独立事件组合起来的。"（例：924 的起点是两个新工具，但推到 4000 点靠的是后面一个接一个的新变量。）
- IF 利好消散（打开盒子是芝麻）AND 无新变量 THEN 市场逐渐修正、回吐涨幅（A 字）；IF 利空消散（如 4.7 关税、降杠杆） THEN 市场脱敏修复收上去。

## 三、突发事件应对体系（20260304 重点）

> 背景：当周突发地缘冲突（封锁海峡、油价飙升、隔壁熔断），他把圈内旧文系统性展开。

### 第一步：判断事件的发展路径（二选一）

```text
事件只有两种走向：
A. 逐渐发酵——利好越来越多/利空越来越坏
B. 逐渐消散——刚出来以为装的是西瓜，打开一层层盒子最后是芝麻
```

### 第二步：套用"市场反应第一定律"

```text
无论利好利空，市场在事件刚出现时反应最剧烈；
即便事件持续发酵，影响也递减；后市由新变量驱动，不再由原事件驱动。
```
四种组合与历史案例：

| 组合 | 市场走势 | 案例 |
|---|---|---|
| 利好+发酵 | 先暴动，后递减，由新变量接力上行 | 924 两个新工具 → 后面靠新变量推上 4000 |
| 利空+发酵 | 先暴跌（最剧烈），之后 L 型钝化，由新变量决定 | 口罩（2020/2/3 干跌停后，越发酵越脱敏）；地产恶化最初一两年反应最剧烈，之后 L 型 |
| 利好+消散 | A 字：冲上去后回吐修正，回到事件前 | 各类一次性利好、业绩报脉冲 |
| 利空+消散 | 深 V 修复 | 2025-04-07 关税；2022 俄乌；某次盘中降杠杆新规（4200 点一根直线后修复） |

```text
IF 事件消散 AND 无新变量 THEN 市场逐渐修正回吐
IF 事件发酵 AND 后市走弱/走强 THEN 看的是新变量，不是旧事件——别拿旧事件解释新走势
```

### 第三步：判断当下处于哪种、盯什么新变量（以 20260304 为例）

- 国内新变量：两会（"开会大于干仗"）——"把市场从粪坑里捞出来的往上拉力"。
- 海外新变量：油价 + 对油的措施（护航、航线恢复）；油价 → 美国通胀 → 美联储决策 → 流动性。
- 判断结果：倾向"利空消散后收上去"（V），而非走 L。

### 第四步：按自己的交易者类型选应对（核心分类）

**类型 1 · 超短客（快枪手）**
```text
涨啥买啥、跌啥卖啥，只吃市场反应最剧烈的那一段："发现急猛干，啃一口就走"
IF 后面发酵了还有空间 THEN 与你无关——超短不该吃那段
风险：半路上车被回落套住
```

**类型 2 · 趋势投机客（分两小类）**
```text
2a. 事件前品种大势与事件方向相同 → 锦上添花：做开仓或增仓（追求爆发+高确定性开仓点）
    例：原油/燃油开战前已走小趋势，开战第一天加仓
2b. 事件前大势与事件方向相反：
    IF 事件与品种仅情绪/流动性关联（如可乐、麦当劳） THEN 默认沿原趋势开仓——情绪杀不改趋势
    IF 事件与品种强关联且可能伤及基本面（如高油价 vs 航空公司） THEN 暂时观望，等基本面明朗
底层逻辑：趋势一旦形成不会轻易改变；牛转熊需要多重因素+反复过程（顶会反复、有时间反应），别因单一突发事件做剧烈反应
```

**类型 3 · 长线投资者**
```text
忽略事件本身，只跟踪一件事：核心基本面是否被改变
IF 未改变 THEN 按原计划做
IF 不确定（预期改变但未证实） THEN 按兵不动，观察事件发展是否产生实质影响
IF 正向影响（如油企三连板） THEN 长线不清仓（做三五年周期的，三个涨停板就倒袋"对不起自己"）；一年内波段可走
IF 负面但仅停留在预期（如航空股：油价未实际抬升成本，公司有库存/长协/期货对冲） THEN 按兵不动——"不要把公司经营者想得那么蠢，他比你还担心原材料波动"
IF 中性（如消费品对战争） THEN 直接忽略
```

### 第五步：用四变量检查是否趋势反转（兜底动作）

```text
流动性 / 宏观经济 / 政策 / 宏大叙事 → 逐项检查有无"严重恶化"
IF 只有单一负面信号 THEN 不作为减仓/做空的充分依据
```
（他当时结论："看不到充足的理由让我大幅多转空"，后续油价回落后市场如期修复。）

## 四、其他主题规则（20260415 等）

### 4.1 "要么八千点要么永远三千点"的变革框架（20260415）

- 弹总（但斌）"A 股严格意义上只是反弹"的说法他**不反驳**：国际标准牛市=不断创历史新高；A 股 30 年没过 6124/5178。官方文件里从没出现过"牛市"二字，只说了"稳"。
- **变革成功的四个信号**：
  1. 创业板创历史新高（唯一可能的大学生的"出息"）→ 国际资本才会信；
  2. 资金结构平滑化、摆脱"杠杆牛"（两融增速、台阶式上涨）；
  3. 分红与回购制度（连续分红公司占比太低；回购不注销=上市公司自己炒股；呼吁不分红罚款/退市；银行等最赚钱公司股价才几块钱、不回购还增发——"买不完根本买不完"）；
  4. 金融开放程度（半封闭市场与俄股同类，双向约束，"不一定放了就是好"）。
- 存款搬家死循环："股市想的是你不搬家我怎么走长牛，居民想的是你不走长牛我为什么搬"——总要有人先迈一步，且制度要让居民"信"（信 = 不断新高）。
- 判断口诀：**IF 未来几个月看不到让老乡相信变革成功的动作 THEN 做好历史重演（区间震荡/回落）的准备**。

### 4.2 指数层面的操作含义

- 拉指数很简单：一只大金融 + 一个国家战略板块（一级市场造势逻辑：二级不活则一级无退出动力）。
- 3800 = 机构成本线/护盘位（去年 12 月、今年多次在此拿起）。
- IF 做指数（ETF/股指） THEN 心中有了区间锚点即可做波段；IF 做板块 THEN 轮动市里板块不好做。

### 4.3 基本面的深浅（20260415）

- 他自己**很少看详细财报/资产负债表**（不太懂 + 易造假），赚行业的 β 不赚公司的 α；宁德时代当年只是恰好选中的行业钱。
- IF 只做行业级中长线 THEN 不必研究报表细节；IF 做个股深度投资（五年十年） THEN 必须研究报表+管理层。
- 简易筛选示例：IF 自称创新药 AND 研发费用占营收比极低 THEN 定性为蹭概念。

### 4.4 中线/长线的"名分"规则（20240922）

- 买入前先想清楚"你蹲进去做的是什么"：季度业绩预期（车，1-3 个月）/ 产能出清（猪、锂电，半年起）/ 政策预期埋伏（地产，10-20 天）——名分决定持有周期和卖出条件，不能中途混淆。
- 左右之争："要左就左要右就右"，来回切换两头挨打。
