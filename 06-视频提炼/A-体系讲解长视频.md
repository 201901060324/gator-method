## 一、新增规则（IF…THEN）

### A. 交易决策流程（20260517，全篇核心）

- IF 开始分析任何市场/品种 THEN 第一步永远是收集信息（技术面、基本面、消息面都算），并做筛选——小作文、道听途说直接 pass。[核心]（20260517 中段讲决策流程）
- IF 信息无法确认真实性 AND/OR 前后矛盾、一天一变（如碳酸锂矿复产传闻传了800遍）THEN 放弃基本面假设，多也不做空也不做，直接观望；或干脆只看技术面，默认价格反映所有信息（公开的与未公开的）。[核心]（20260517 前中段讲碳酸锂调研；20260623 结尾重申"看不懂基本面就找技术面好看的做，纯粹一点胜率反而高"）
- 决策流程六步（见第三节详述）：收集信息 → 处理 → 提出假设 → 制定交易策略 → 执行 → 验证（事态发展 + 行情走向是否符合预期）；符合→继续执行，不符合→回到收集信息重新走循环。原话依据："大胆假设小心求证"。[核心]（20260517 中段；20260715、20260831、20260623 三场开头都重演此流程，属他每场直播的固定开场）
- IF 提出假设 THEN 必须同时明确验证时间点/验证事件（例：假设新联储主席推缩表→验证点=6月18利率决议；假设市场急跌后反弹→验证点=周K出十字星或小阳线）。[核心]（20260517 中后段）
- IF 事态发展符合预期假设 THEN 只做一件事：继续执行策略，不要因"涨太多怕跌/跌太多怕崩"而动作（"新高符合假设就拿着，再新高再拿着"）。[核心]（20260517 后段）
- IF 出现不符合预期（如"订单很好但股价涨不动"）THEN 暂时出来观望，重新走流程。[核心]（20260517 结尾）

### B. 信息收集准则（20260517）

- 收集信息两个准入标准：①真实性 ②持续性（不朝令夕改）。IF 某行业打开信息一看真假混杂、方向矛盾 THEN 该行业多也不做空也不做。[核心]（20260517 前中段）
- IF 基本面没有渠道确认真假 THEN 直接切换技术面派，"把自己当成纯技术派，有时候反而好做一些"。[核心]（20260517 结尾）

### C. 行情结构规律（20260517）

- IF 一轮周K连阳级别的趋势行情 THEN 没有一根周K翻绿就熄火的先例——趋势结束前必有反弹修复，摸前高做双顶（或双底）再下去，"市场有惯性，不是一泼凉水就A杀下来"。[核心]（20260517 中段）
- IF 指数急跌 THEN 提出假设"至少做个双底/反弹一波"，指数级别表现为周K十字星或小阳线修复后才谈方向。[核心]（20260517 中段）
- 任何时候最大的利空都是涨多了。[核心]（20260517 中段，原话："最大的利空都是涨多了"）
- IF 融资余额连续多日百亿级买入 THEN 短线获利盘巨大，即使无外部利空也会有利润回吐（"牛市多急跌"），原因是短期资金承接有限、"冲一段就要歇一下让更多人进来把情绪续上"。【阈值未公开：几日算连续】[核心]（20260517 中段）
- IF 成交量仍大（几万亿级）THEN 不必恐慌深度下跌——"市场的下限是由量决定的，不怕跌就怕没人玩，没人玩的市场才没下限"。[核心]（20260517 中段；20260715、20260623 均重申量的意义）

### D. 成长股三种参与姿势的操作规则（20260517，见第二节）

- IF 做 0→1 成长股（AI应用、商业航天、低空经济、医疗生物等） THEN 把自己当风险投资人：不跨一个量级不走——一两百亿市值看四五百亿、四五百亿看千亿、千亿看几千亿；回报目标"没赚个三五倍绝不走"。[核心]（20260517 后段）
- IF 入手 0→1 标的 THEN 至少有一个吸引你的点：管理团队（看人）、技术、或赛道（政策扶持/技术爆发/资金炒作可能），三选一。[核心]（20260517 后段）
- IF 风险投资失败 THEN "悄悄地干，输了就当没干过"——接受十笔亏七八笔的赔率结构，靠一笔成千上万倍（一级）或三五倍（二级）覆盖。[核心]（20260517 后段）
- 区分炒作与成长投资，验资清单：①公司团队 ②实际业务产出（AI相关业务占比可列出）③研发费用/资本开支是否跟上（"连资本开支都没有，未来哪来爆款产品"）④产品情况 ⑤营收环比增减 ⑥研发经费增减。[核心]（20260517 后段）
- IF 做高股息 THEN 唯一认输出局条件=连续几年不分红/分红力度不及以往；偶尔一年不分红属正常，不算出局。[核心]（20260517 结尾）
- IF 做短线强制线（如跌破12日线） THEN 触线就走；之后又新高则再干回去——"把均线看成一个强制线，很单纯的，很多量化就是这样"。[单源]（20260517 结尾）
- 动量策略（他转述量化做法）：列出过去6个月涨幅最大+市值300亿以上的公司，谁新高保留谁、不新高就走；A股因板块轮动快，把周期缩短到1-3个月不断换仓。[单源]（20260517 结尾）

### E. 市场情绪与预期管理（20260517）

- IF 官方大会/会面"不及预期" THEN 属正常预期管理——"大事情都是小会定的，大会都是走流程"；真谈崩了对面根本不会来。判定关系改善看官方定调措辞（友好合作>战略合作>战略竞争对手>战略性稳定）。[单源]（20260517 中后段讲中美关系四阶段）
- IF 旧变量（如中东局势）已被市场脱敏（股市对油价脱敏） THEN 不再作为交易依据——"市场交易的往往都是新变量"。[核心]（20260517 中后段）
- 事件冲击反应规律：刚开始反应最剧烈，之后慢慢钝化（中东干仗油价例子）。[核心]（20260517 中后段）

### F. 宏观：美联储与流动性（20260517 / 20260623 / 20260831）

- 利率与扩表/缩表的分工：利率决定资金价格（短期资产价格），扩表/缩表决定市场上钱的数量（中长期）。缩表利空需要长期大额贷款的成长类/高科技企业。[核心]（20260517 中后段）
- 新联储主席（转写"卧石"，推断为沃什）三主张：①掐头去尾看通胀（不看平均值，"去掉一个最高分去掉一个最低分"，按此算法通胀2.4%而非3.5%）②2%目标改为区间1.7–2.3 ③缩表恢复美联储独立性、反对市场路径依赖与道德风险、不做预期管理。[单源]（20260517 中段）
- 路径依赖/道德风险类比：救助烂企业会让所有企业摆烂等兜底（地产不强力收储同理）；08年QE是"没办法"，一救救了近20年。[单源]（20260517 中段）
- IF 新主席表态要缩表 THEN 倾向判定为"反应过度"，假设其短期搞不成（利益集团角逐、阻力大），验证点=下次利率决议；预期过度→有修复过程。[单源]（20260517 中后段）
- 美债问题五条解决路径及代价排序（20260831 核心）：
  1. 靠吓唬（让市场自我调节）——代价最小、最难，现任主席正在用；
  2. 吓唬AI叙事（AI企业发债挤占长期资金，吓一吓让资金回流国债）——同属"吓唬"；
  3. 协商/让金融机构买国债——短期无代价，长期增加系统性风险概率（参考08年）；
  4. 加息——最直接，代价=股市走弱、经济短痛（"长痛不如短痛"，他本人倾向这条）；
  5. 降息——股市嗨，代价=通胀加重、未来更大危机（参考口罩期QE→22年起难受四五年）。"任何事情都能解决，只是代价不同。"
  [核心]（20260831 中段；IF 靠降息解决美债 THEN "可能未来几年都没有太多好日子"）
- IF GDP增长 THEN 不一定就业增长（近年怪象：靠提效不靠雇人，资本空心化）；但大衰退时两者同步向下。[单源]（20260831 中段）
- AI泡沫的两个破产信号 [核心]（20260623 中段；20260831 结尾重申"债权违约是AI泡沫的重要衡量标准"）：
  - 信号1：企业债务违约——头部巨头目前无违约（"有借有还在借不难"，信用稳定）；中小科技高收益债违约率约4.5%且环比上行，需留意。债务是历次危机的引爆点（08地产、2000互联网、大萧条）。
  - 信号2：流动性承受不了估值——标普TTM PE 27.8（近10年96%分位，50年均值18.5）；动态PE口径88%分位；纳指PE 35–36（近10年82%）；罗素2000 17倍PE（42%分位）=美股的价值洼地。高于08和21年、低于2000年互联网泡沫。
- IF 美股全面大跌 THEN 未触发——估值未到2000年极值+存在低洼行业+流动性仍支撑，市场会自动切换（科技→消费/医疗/金融/能源良性轮动）。[单源]（20260623 中段）
- IF 担忧全球性危机 THEN 看两条：①货币端——大量资金对美元失去信任、质疑美联储独立性引发大规模流动；②AI债券违约。08年式危机需2–3年疯狂孕育，"今年只是第一波全球共振加速"，目前看不到。[核心]（20260831 结尾）
- IF 七八月份 THEN 全球流动性季节性枯萎（欧美金融从业者集中休约20天年假，欧洲尤甚），历史上易出极端行情（2020年8月日股单日跌10%+）；叠加今年高波动，"对周K级别的调整要有准备，不管会不会出现"。[核心]（20260715 结尾）

### G. 产业链与基本面（20260715 / 20260831 / 20260623）

- 长鞭效应（核心机制，见第四节）：真实需求+10% → 零售+库存约20% → 批发+30~50% → 上游扩产100%；需求回落时反向同样成立——各环节库存出清后，需求一点点好转就"帮"地供不应求、价格暴涨（AI链、药盒涨价例子）。[核心]（20260715 前中段）
- IF 工业品被宣称"供不应求将持续到20XX年" THEN 留个心眼——工业品厂房一开机器一转就能生产（12小时两班倒三班倒），只有农产品/养殖才有刚性生长周期；历史上白酒、光伏、锂电、风电都演过"计算器按到未来几十年"的戏码。[核心]（20260715 中段）
- IF 关键数据（如库存、排产）因商业机密拿不到真实值 THEN 不做该品种——"收集不到/无法判断真假就不做"（碳酸锂15–16万仅平衡区间案例；冻库库存是最难打听的数据）。[核心]（20260715 中段；20260517 前段碳酸锂）
- 逻辑漏洞检测法：IF 各车企销量目标集体+20%~+50% AND 行业整体增幅预期仅+10% THEN 必有车企高估自己=提前交易周期下行的做空依据。[单源]（20260715 中段讲年初空碳酸锂依据）
- 矛盾与统一（产业链视角，见第四节）：IF 供需两旺 AND 上中下游利润分配均衡 THEN 行情走得长久（20–21年新能源全链齐涨）；IF 蛋糕做不大 AND 一家独大（中游电池吃掉利润） THEN 行情不长久，传导路径=最先吃压力的先跌（整车先跌→上游原材料跌→中游电池跌）。[核心]（20260715 中后段）
- IF 下游还没赚钱（B2B，如当前AI：下游光花钱不赚钱） THEN 该行业"从来没有统一过"，把上游零部件未来五六年需求都算进去是不合理的。[核心]（20260715 中后段）
- 屁股决定脑袋：产业链各环节都说自己环节最重要（三星说存储/GPU闲置20%时间、老黄说算力就是GPU、电力大国说算力的尽头是电）——投资者很难听到实话，研报要按说话人立场折价。[核心]（20260715 中段）
- 眼前的事实≠真实情况：基本面投资要实事求是，但要结合产业链特性与周期，把短期、中期、长期分开思考；"越长的周期越好把握，越短的周期越不好把握"。[核心]（20260715 中段）
- IF 做短线（持仓几天到几周） THEN 根本不需要看基本面——几周内行业基本面不会变，看形态、融资余额、成交量、OBV、均线即可，最多确认"这个行业没雷"。[核心]（20260715 后段）
- 股票会跑在现货/期货前面：碳酸锂股价在现货见顶前提前见顶；证券股在业绩公布前1–2周提前见底——期货有到期日、股票可以拿，所以股票定价更超前。[核心]（20260715 中段）
- 证券行业判定（服务业模型）：一切看成交量——"只要成交量维持两三万亿、两融火热，这行业就真赚钱（成本固定，多开一个户不增加边际成本）"。[单源]（20260715 中段）

### H. 资金行为（20260715 / 20260623）

- 杠杆资金行为模型：杠杆哥不做时间的朋友，找"短期涨10%的品种×10倍杠杆"；IF 波动率下降/单边波动收窄 THEN 杠杆资金自然撤离（波动大才值得上杠杆）。[核心]（20260715 后段）
- 融资余额跟踪法：IF 高位品种融资余额持续下降 AND 股价还在涨 THEN 玩的是无杠杆资金（基民/机构），注意持续性；IF 低位品种融资余额缓慢上升 THEN 杠杆哥在迁移（"互掏腰包"）。[核心]（20260715 后段）
- 题材炒作的撤退路径（市场版长鞭效应）：机构先撤（风控越涨越卖）→ 杠杆哥 → 股民 → 基民接最后一棒。[核心]（20260715 后段）
- 去杠杆两波结构（参照2015标准答案）：第一波急跌强平→空头回补+救市反弹→第二波下跌打掉80–90%人的幻想（"不新高了，我等解套吧"）→之后波动越来越小、杠杆资金彻底离场、转入阴跌。[单源]（20260715 后段，以白银走势图为例）
- 流动性底层逻辑（20260623 后段，见第四节）：持续上涨需要源源不断的增量资金且价格越高需要的钱越多；下跌不需要增量资金，只需原来的人不玩。[核心]
- 流动性枯竭型下跌：极端例子——冷门股500亿市值，10手卖单从9.99改价9块成交，9000元成交额=股价跌10%=市值蒸发50亿；砸盘者不是大股东（大股东一减就是几万股），是家人们扛不住割肉、基民赎回、机构被动砍仓。[核心]（20260623 后段）
- IF 高位放量滞涨（如成交近4万亿却涨不动） THEN 卖出者=大股东在源源不断出货。[核心]（20260623 后段）
- 急涨慢跌是制度性特征：无完善做空机制→上涨定价快、下跌靠"人走茶凉"缓慢出清（新能源、白酒、医药都如此；涨50%一周，跌回原点要数周甚至半年一年）。[核心]（20260623 后段）
- 港股=流动性荒漠：无本土资金（只有内资南下+外资"过路和尚"），几十亿就能砸出大跌（腾讯曾砸到10倍PE以下）；反过来一旦启动，涨10%也只需小钱——流动性荒漠是双刃剑。[核心]（20260623 后段；20260715 讲港股沽空占比高、需连续大涨逼空才见好）
- A股难以全面牛的结构原因：股票数量从07年1000+只→14-15年2000多只→现在5000+只；短暂全面牛仅出现在去年7–8月（一周）、今年1月（至1.14，被盘中降杠杆打断，"最可惜"）。[核心]（20260623 后段）

### I. 交易防御：三种杀（20260831，见第四节）

- 技术杀应对：多看两天（破位多看两天、突破确认看三天——"三天重合新高才是真突破"，看周K更稳）；代价=止损可能从5个点拖到10个点，所以弹性大的个股止损放宽到7–8个点（找"度"）。[核心]（20260831 中后段）

## 二、三种投资人分类（20260517 重点）

**性质澄清**：他讲的"三种投资人"不是按资金量/人群分类，而是**做成长股的三种参与姿势**，按介入阶段划分（0→1 / 1→100 / 100之后）。转写原文语境："特别是说成长股，第一种就是做风险投资人……"

### 1. 风险投资人（做 0→1）

- **对象**：未跑通的商业化新技术——AI应用、商业航天、低空经济、飞行汽车、医疗生物科技等"很多公司根本还没赚钱"的领域。
- **心态设定**：把自己当一级市场风投——"你投的是一家没上市的公司，能不能上市还不一定"；很多年不温不火是常态。
- **盈利结构**：十笔亏七八笔，一笔成了就是成千上万倍（一级）；二级市场不指望万倍，"两三倍三五倍是很可以做到的"。
- **持有纪律**：**不跨一个量级绝不走**——一两百亿市值看到四五百亿、四五百亿看到千亿、千亿看到几千亿；"不干到上市绝不走"的心态。"大家做翻倍股最难的不是没选到翻倍股，是做进去了拿不到。"
- **选股三看**（一级市场思路）：看创业团队/管理层（人给不靠谱的感觉公司多半干不成——举宇树、泡泡玛特创始人为例）、看技术、看赛道（政策扶持+技术爆发可能+资金炒作可能）。三选一，必须有一个吸引你的点。
- **反例提问**（他用来敲打追高者）："你为什么没在小米股价8块的时候被雷军的人格魅力吸引，非要在四五十、六十的时候被吸引？"
- **失败处理**："悄悄地干，如果输了就当没干过。"

### 2. 成长投资人（做 1→100）

- **对象**：已跑出阶段成果、正在长大的公司（宇树即将上市属此类；比亚迪、宁德早年属此类）。
- **介入时机（他列的三种思路）**：
  1. 等概念最火那一波过去，经历调整/熊市/基本面恶化/情绪退潮的洗礼后再投（"基本面的分歧转一致"）；
  2. 等新的爆款出现再投——**判定一家公司还是不是成长股，就看它有没有新爆款**（泡泡玛特例：没看到新爆款就默认它吃老本、不当成长股投）；
  3. 他本人投宇树的条件：**商业化应用场景更全面**——出货量领先全球也嫌利润差意思，"哪怕它做出高达我也不投，高达只能卖给军队，应用场景太窄"。
- **另一种划分**：渗透率视角——IF 你认为渗透率还能从60%打到80–90% THEN 车企仍是1→100的成长股；IF 认为已到天花板 THEN 转价值股做（涨多了卖跌多了买）。
- **阿里/腾讯之辨（20260831 补充，同属成长投资判断）**：腾讯=AI赋能、主业稳健、竞赛输了根基还在（稳健之选）；阿里=AI第二主业、破釜沉舟无后路、全栈一条龙、刚增发（进取之选）。管理层原话"投三年"才有基本面回报拐点，但股市拐点会提前于基本面拐点反应。

### 3. 价值股投资人（100之后）

- **对象**：行业到天花板的成熟资产——水电（长江电力）、可口可乐、银行、高股息煤炭、移动电信等。
- **估值特征**：PE 常年不动（长电、可口可乐估值十年没大波动），股价上涨全靠盈利推。
- **操作**：吃股息为主，"股息率跌到多少（阈值未公开）可以买进做一把"；默认其没有成长空间，做"参天大树"的逻辑。
- **例外**：若你认为它要卖新东西（如运营商卖Token/AI产品） THEN 可转回成长股逻辑。
- **市值天花板警告**：真要找爆发力强的成长股，市值不能太大——"已经万亿的再翻几倍到几万亿，全球有几个英伟达？"

## 三、交易决策流程（20260517 重点）

他明确说这个流程"未来一直用，不管市场怎么变"，且每场直播开头都走一遍。完整还原：

1. **收集信息**：技术面、基本面、消息面皆可（"你喜欢看啥看啥，收集一切能收集的"）。两条准入标准：真实性、持续性。
   - 常见跳过条件1：IF 基本面无法验证真假/矛盾多变 THEN 跳过基本面，直接技术面（默认价格反映一切信息）。
   - 纯技术派的信息=K线+量价，屏蔽杂音。
2. **处理信息**：去伪存真、交叉验证。警惕长鞭效应造成的"每个环节都没说谎但合起来是错的"。
3. **提出假设**："大胆假设，小心求证"。假设必须可验证，且**同时定下验证时间点/验证事件**（如6月18利率决议、周K十字星、订单公布）。
4. **制定交易策略**：依据假设给出买/卖/观望与仓位。
5. **执行**：符合预期就机械执行，"不要今天跌5个点就走、明天涨5个点又加仓——那是短线不短线、长线不长线，没有决策流程"。短线也要有执行标准（如跌破12日线强制走，新高再干回去）。
6. **验证与循环**：两个验证维度——①事态发展是否符合预期假设（如干仗没失控）②行情走向是否符合预期（如3800后跌不下去）。符合→继续执行→再新高再拿着；不符合→回到第1步重新收集。
   - 他举的两个实例：3月干仗（假设"打不到失控程度+牛市没结束"→发3800可播种→事态缓和验证）；联储新主席（假设"缩表短期搞不成、市场反应过度会修复"→验证点6.18决议）。

## 四、三种杀 / 长鞭效应 / 矛盾与统一 / 流动性底层逻辑

### 4.1 交易里的三种杀（20260831）

定义：不管你做得多对，市场有三种方式把你"杀"出局。

1. **技术杀**（最常遇到）：假破位——"设60日线止损，刚破位止损，第三天啪涨停"；假突破——"刚破前高进去做趋势，啪跌下来是个双顶"。
   - 应对：**多看两天**（他总结成三个字"多看看"）；突破确认看3天（"3天重合新高才是真突破，其实不会有太大损失，反而增加确定性"）；或看周K；代价是止损点数要放宽（弹性大的票5个点不够，放7–8个点），这个"度"因票而异。
2. **规则杀**（最无赖）：利用市场规则不对称赚钱。案例：①鸡蛋——现货8月真涨（基本面跟踪完全正确）、期货偏压到交割月才涨，散户7月底必须平仓，"看对了也没你的份"；②T+1+不能双向——机构先拉涨停吸引你、再砸跌停，双向都能赚，你明知要跌停还卖不出去；③股市版——证券业绩很好估值很低就是不涨。
3. **信息差杀（基本面杀）**："低端的控盘控制价格，高端的控盘控制基本面。"案例：一条推特改变基本面；纯碱"说缺就缺、涨完又不缺"；碳酸锂一个矿复产/关矿的传闻讲一年；獐子岛扇贝跑了又回。核心句："**你研究基本面，人家研究你**"（上游联合套保空单猎杀做基本面的多头大户，爆仓后散户跟风下杀，产业资本再低价提货）。

### 4.2 长鞭效应（20260715）

- 定义：终端真实需求的微小变化，沿"消费者→零售商→批发商→零部件→工厂→原材料"逐级放大，像鞭子——手柄轻轻一甩，鞭尾打人很疼。
- **正向放大**（需求上行）：真实需求+10% → 零售多备库存+20% → 批发+30~50% → 原厂"行情来了"扩产100%。举例：终端多卖1000件→零售备1200→批发备1560。面馆例子：平时卖10斤面备12斤，连卖几天售罄就进14斤。
- **正向后果**：全产业链过度乐观→产能过剩→"增产一两年，还债三五年"（白酒囤茅台：2600买茅台的人不傻，只是身在局中；猪产能还债还到26年）。
- **反向放大**（需求下行后补库存）：各环节库存出清→需求稍好转→瞬间供不应求、价格暴涨（AI链缺货、"药盒"涨价、零售商囤内存条——"5年前囤茅台，5年后囤内存条，历史是个圈"）。
- **为什么研报会错**：券商调研只问上游订单（确实爆发了），没看中端和零售；"可能人家也没说谎，但事实和公布出来的东西不一样"。
- **为什么摸不到真实数据**：信息错配+商业机密（他去猪场调研，母猪存栏好打听，冻库库存是商业机密谁都说"摇头"）；且每个环节"屁股决定脑袋"只说自己好。
- **推论规则**：IF 宣称缺货的是工业品 THEN 缺货持续到20XX年的说法高度存疑（工业品扩产快，只有农产品/养殖有刚性周期）；IF 关键环节数据是商业机密 THEN 该品种放弃。

### 4.3 矛盾与统一（20260715）

- **产业链层面**：
  - 统一=供需两旺+上中下游利润分配均衡→行情长久（20–21年新能源：上游碳酸锂涨、中游电池涨、下游整车也涨，和和睦睦）。
  - 矛盾=蛋糕做不大后一家独大→不长久。新能源后期利润被中游电池吃掉（"你要么别用我的电池"），下游活不下去→需求下滑→全链难办。
  - 下跌传导路径：谁最先吃压力谁先跌——整车先跌→上游原材料跌→中游电池跌。
  - 应用到AI：AI下游（应用层）目前光花钱不赚钱、B2B闭环未走通→"这个行业从来没有统一过"→把上游未来五六年需求按计算器是不合理的。
- **盘面层面**：
  - 统一=股民、基民、公司、机构、"龙"都想继续嗨；矛盾=**钱从哪来**。
  - 案例推演：外资连续净卖出+内资杠杆"杠上开花"→杠无可杠→暴涨后必还债（参照2015标准答案，去杠杆两波）。
  - 解法=流动性重构：钱从高位热门品种流向低位品种"互掏腰包"，不需要3万亿成交，2万多亿就能普涨（1块涨到2块和100涨到200所需的钱天差地别）。
- **方法论**："任何一个品种任何时候都可以看多或看空，但必须把短期、中期、长期分开"——同一段白银行情，1月前看空对、做空难受（杠杆累积期没做出头）；"26年最确立的做空品种是白银"，但要等做头（杀下来→弹→再杀下去）之后第一波杀杠杆结束再空。

### 4.4 流动性的底层逻辑（20260623）

1. **上涨需要增量资金，且价格越高需要的钱越多**；持续上涨=源源不断的增量资金，断了就"游戏暂停或结束"。
2. **下跌不需要增量资金**——只需原来的人不玩：多杀多→流动性枯竭型下跌，"一点点成交量就能砸出大坑"（9000元砸出10%跌幅/50亿市值蒸发的极端盘口演示）。
3. **市值与流动性**：市值大≠不会流动性枯竭型下跌（前几天保险证券的大坑；港股几十亿砸腾讯大跌）；热门股也不等于涨得动（1万手×1000万成交只推高0.1%——因为上有大股东源源不断的货）。
4. **流动性决定市场下限**；枯竭型下跌的砸盘者=家人们割肉、基民赎回、机构被动砍仓（不是大股东）；高位放量滞涨时卖出的=大股东。
5. **"穿裤子"比喻**：以前科技一个人穿10条裤子、十几个行业轮流穿1条；流动性重构=裤子重新分配。
6. **全面牛的稀缺**：07年1000多只股、14-15年2000多只→现在5000+只，钱不够全面普涨；21年结构牛是"大吸小"（沪深300吸中证2000的血），这轮是"科技吸一切"（连大金融、消费、高股息都当血包）。
7. **急涨慢跌**：无做空机制→定价不对称，涨得快跌得慢（涨50%一周，跌回去数周至一年）；全球通用，我们尤甚。
8. **推论规则**：
   - IF 寻找流动性重构的受益方向 THEN 找"类似证券"的行业——估值低+业绩有增长确定性（证券是名牌所以去年被杀；金属也算一个）。
   - IF 做投机 THEN A股+港股是全球最好的市场（能把垃圾炒很高、把价值压很低）；IF 做投资 THEN 美股全球最好（"不接受反驳"，良性轮动教科书级别）。
   - IF 做海外市场 THEN 最大阻力不是波动，是信息茧房——"跌的时候铺天盖地，涨的时候不报道"（日股、巴菲特买日股"懂得都懂"）。
   - 护盘频率反推市场体质：美股极少护盘（4.7关税川普发推特就涨回来了=推特护盘），"越是自发完成切换修复的市场越强；动不动要打针才能活的市场，体质好不了"。
