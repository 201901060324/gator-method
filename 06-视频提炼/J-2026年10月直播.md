## 一、本场知识点：为什么下跌只有两波

### 1.1 下跌两波的行为学解释 `[核心]`

对偶于上期"上涨为什么是三波"（43.2：少部分人信 → 部分人慢慢信 → 最后信的人进场 → 行情结束）。

```text
为什么下跌只有 A、C 两个主跌浪（涨却有三波）：
  A 浪 = 上涨刚结束时，大家把它当成普通回调（以为和 4 浪一样还会涨回来）
  B 浪 = 诱多反弹（希望燃起）——"多头的残存力量博反弹，俗称诱多"
  C 浪 = 绝望的一浪（反弹搏进去的人走了，大家大梦初醒：原来已经结束了）
涨 = 慢慢相信的堆量过程（参考黄金：成交量慢慢堆上去，之后加速）
跌 = 蜂拥出逃的挤兑过程（参考白银：蹦一下掉下来，比黄金更快——白银连稀缺性都没有）
类比："帝国大厦——跑上去要两钟头，跳下来只需要几秒钟"
```

```text
IF 数主跌浪 THEN 只有 A 和 C 两下（二浪/四浪回调属于主升浪内部的子浪，不算主跌浪）
IF C 浪走完 THEN 杀伤的力度和持续性比 A 浪多得多
IF 经历 C 浪 THEN 最杀人诛心的不是跌幅，是时间太长
   实例：22 年——第一波刷下来 20 个点（技术性不牛）→ 反弹 → C 浪从反弹高点算才 20%、
   从低点算没多少跌幅，但走了两年（22 下半年 + 23 整年 + 24 年）
```

### 1.2 20% 技术性牛熊标准与中枢画法 `[核心][可计算]`

```text
技术性牛 = 从最近一轮低点上涨 ≥ 20%（国际管理惯例，非他自创）
技术性不牛 = 从最近一轮高点下跌 ≥ 20%
"20% 是恒定标准"——把它作为下跌波次的分界节点
```

15 年熊市三种画法的对照（他给的教学案例）：

```text
从下跌起始点画：三波（每波都 > 20%：1.0 = 32%、2.0 = 26%、3.0 = 熔断 14%~20% 口径不一）
从中枢（区间震荡平台）画：只有两波（第三波从中枢算 14% 不够 20%，不算独立一波）
他的取舍：**一般做交易，更多从中枢来画**——更科学、更符合做交易的判断
   理由：从中枢之上抄底/买入的人在那段时间是有利润的（五六个月的行情），
   不是"一刀砍下来接着砍"（1.0/2.0 衔接那种），所以从反弹平台起算才算"新的下跌"
另一个判据：若某段走势走了约五个月（半年）、反弹幅度大时间长，则不应再画为上一波的延续，是新问题引起的新下跌
```

⚠️ **熔断的年份纠正（他在直播里主动纠正）**：常说的"15 年熔断"其实不在 15 年，熔断是 16 年年初的事——15 年的后半段熊市只有两波，16 年熔断已是新的一波（3.0）。

## 二、本场主题：下跌 1.0 / 2.0 的判别（当下应用）

### 2.1 判别框架：时间 + 空间 `[核心][可计算]`

```text
IF 高点下来第一波大跌（1.0）后反弹构筑平台 THEN 后续跌破平台 ≠ 2.0 开始
   （只是刷新了区间的低点，"他目前还是在区间震荡，只是把区间的低点给刷新了"）
IF 中枢以下跌幅 < 20%（本轮实证：科创中枢以下只下去了 8 个点） THEN 判 1.0 的延续，不判 2.0
IF 要确认 2.0 THEN 需要时间与空间双条件：
   ① 在平台位置震荡一到两个月（时间）
   ② 跌幅区间继续扩大（空间）
IF 真要走 2.0 THEN 之前一定会先构筑一个区间平台（平台往往就是前一波上升浪之前的中枢）
IF 1.0 和 2.0 衔接 THEN 两者跌的造型和幅度基本一样，不能靠"跌幅像不像"区分
```

### 2.2 2.0 vs 1.0 的盘面指纹 `[核心][可观察]`

```text
1.0 的特征：有量、中途有反弹（创业板反弹五六个点"偷偷地给了机会"）、有拉扯、有抵抗
  （当时"旧的也猛"，跌下来还有资金接，还有反弹的拉扯）
2.0 的特征：没量、大跌唰唰唰、想卖卖不出去（每天开盘 30/31 个点直接跌停板）、
  比 1.0 更猛、毫无抵抗、是真正绝望的一波
IF 判断当下是哪一段 THEN 看指纹：跌得没那么猛（明星股没像 7 月那样 10 厘米/20 厘米连续砸）
  → 还是 1.0 的延续，不是 2.0（本轮实证：易中天及存储系明星股没有像 7 月那么跌）
```

### 2.3 历史案例载体

- **21 年的"林子"**（转写怪词）：1.0 第一波跌 20 多 → 反弹平台后延续 → 构筑新平台（一两个月）→ 才到 2.0 → 又构筑新平台。1.0 和 2.0 之间有完整的中枢结构。他预判："未来有很多科技股都会走得跟 20/21 年的林子一毛一样"。
- **21 年的"毛子"（俄罗斯）**：1.0 和 2.0 中间的横盘震荡时间更久，"以至于让你忘记了它才走下跌趋势"。
- **对照记忆**：21 年的白酒、医药（风光里还有酒、药）——1.0 和 2.0 之间的中枢震荡好几个月。
- **15 年的反弹段**：大家以为区间低点在前低，结果又下来刷新区间低点，然后又回去，也是一两个月，之后才走 2.0。

### 2.4 当下结论（2026-10-13 时点）

```text
科创/创业板（科技含量高的指数）：跌破 7 月前低 → 表面看像要走 2.0
  实际判：1.0 的延续（中枢以下仅 8%，时间与空间双条件均不满足）
大盘：高点下来其实才 10 个点，甚至没有走技术性不牛（"感觉跌了二三十个点"是结构性错位的体感）
短期剧本：跟 21 年案例一样，在这个位置上上下下，等待新的向下的驱动——
  不一定会有新的向下（可能晃悠几周、几个月甚至更久）
跌破平台需要很强很强的驱动，举例量级：海外端"干" 1.0 量级的指数下跌 / 科技巨头爆大雷；
  目前主要影响是"美债 + AI 叙事"，中东已惨不会再是主因
```
