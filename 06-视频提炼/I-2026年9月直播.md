## 一、本场行情复盘：一轮完整决策流程的现场演示 `[核心]`

这是全库少见的一次**从收集到验证完整闭环的自述**，可作为"决策六步"（03-rules 十六章）的标准教案。

```text
收集：一切看美债——"全球资产定价的锚"，机构体系待过或懂基本面的人都必看
处理：把"加息落地"处理成利空出尽？还是处理成美债仍在压制？（他判后者）
假设：市场假设="先破4000，再上4200"；他的假设="美债不支持继续往上嗨，看回调"
策略：做空（以纯空为主，另有一些对冲仓）
执行：加息落地后市场涨了几天 → 循环短暂跑通 → 出现与假设不符 → 上周最后两个交易日该及时刹车（做多的止盈/飞行员落地）
验证：出现末日轮 → 空单从轻仓加到正常仓，把握从七成升到九成 → 9/28 大跌兑现
```

- **"处理"环节出错 → 假设必然出错**。他明确指出本轮大多数人栽在"加息落地=利空出尽"这一步处理上。
- **不要在两个极端之间反复横跳**：涨了喊 4000、4200，跌了又看 3000——"一步一步看"。
- **温柔跌的时候不跑，就躲不过不温柔的下跌**（上周温柔调整时是给过反应时间的）。
- **9/28 跌幅超预期但不改判断**：小票跌幅符合预期，权重超跌（海外没怎么跌、我们跌这么多，"连做空的人都觉得今天跌的有点过了"）→ 有量化成分 → 定性为**超跌**，可博反弹。
- **跨市场补涨补跌**：港股跌是因为中秋节那天它开盘、A 股休市（补跌）；日股涨是因为它休市（补涨）；"A 股是全勤奖"。
- **当日操作**：空单平掉（"我坑今天算我坑"，推断=今天平空），原因有二——幅度确实大 + 不是纯空、有对冲仓要平。长线空单要**移仓**（合约到期）。

### 1.1 假期对冲的判别 `[单源]`

```text
IF 长假前海外大概率要跌（美债压着） THEN 机构会放空单对冲
IF 节后涨 THEN 平空单、股票赚钱；IF 节后跌 THEN 股票不动、空单赚钱
成败关键 = 资金分配是否匹配：股指收益能覆盖股票亏损，或股票收益能覆盖股指亏损
IF 两头都没覆盖住 THEN 这个对冲是失败的
```

## 二、新增规则（IF…THEN）

### 2.1 市场情绪的节奏：上涨只有三波——东西方共识 `[核心]`

本场主讲知识点。他给出两套同位框架：

| | 西方波浪理论 | 东方"一鼓作气，再而衰，三而竭" |
|---|---|---|
| 最强的一波 | **第三浪（主升浪）** | **第一波**（直冲冲干上来，连板大阳线） |
| 节奏 | 1浪涨→2浪回调（可深至1浪起点附近）→3浪主升→4浪→5浪鱼尾 | 第一波最猛→一波不如一波→三而竭没新高 |
| 适用对象 | **权重股/趋势股**（"很多权重趋势股给波浪理论就很符合"） | **妖股/题材股**（半年都不到就走完，哪来的回哪去） |
| 走完耗时 | 大半年到一两年（参考 2021 茅台/宁德/比亚迪） | 几个月内 |
| 顶部形态 | 5浪=鱼尾，MACD 红柱/上攻量明显背离；5浪≈双顶，B浪反弹再形成头肩顶（右肩可弹到5浪附近） | 三而竭后直接 A 杀 |

```text
IF 用波浪理论看权重趋势股 THEN 最猛的第三浪做完就可以走了（扛过四浪回调再做个五浪双顶再走）
IF 出现五浪/B浪反弹且量能背离 THEN 视为鱼尾，不留恋
IF 看题材妖股 THEN 按"一鼓作气、再而衰、三而竭"，第一波最猛，一波不如一波
IF 三而竭都没创新高 THEN 这轮情绪结束，不要再去博"二波三波"
```

**为什么"三"是共识（行为金融学解释）**：

```text
第一波：多数人看不到 / 不敢信 / 不愿做（尤其题材妖股）
第二波：开始犹豫，看到"之前不信的朋友都赚钱了"，忍不住跟进
第三波：之前不信的都信了 → 前期信得早的人正好卖给后知后觉者 → 见顶
```
> 题材炒作第一忌讳：**要么不信，要么早信**。第一波没早信、第二波还犹豫、第三波梭哈 = 标准接盘姿势。

**能走完三波已经很不容易**（强化认知）：
```text
IF 一个趋势股/妖股能走完两到三波 THEN 已经是市场给了莫大机会（给了前期解套、少亏的机会）
IF 板块很久没出现过涨停 THEN 该板块短期已被资金抛弃，短线不做
大多数标的实际形态是"直接 A 杀"，根本没有二波三波
```

### 2.2 末日轮：本轮做空的直接依据 `[核心][可计算]`

这是本场最有操作价值的新概念。

```text
定义：三波上涨走完 → 本该走 B 浪反弹（弹个 2、20% 就该死） → 却打出新高/多弹一截
      且**没有强力驱动**（基本面没变化、美债/流动性还在压制、成交量不支持）
      = 末日轮 = 情绪的最后一口气的透支

IF 多个高标/情绪指标同时走末日轮 THEN 市场不支持继续往上嗨 → 做空的胜率大幅提升
IF 上涨需要的钱在增加（越往上越费钱）AND 成交量跟不上（前期2.5-2.6万亿，本波最多2万亿）
  THEN 越往上涨越不可持续，末日轮必然回落
```

- 他给的两个末日轮实例：**药的高标**（权重 AI 熄火后，药靠高标反复走了一个多月，"有高标在反反复复地走，围绕药做不容易亏钱"；高标一倒，"药就容易成死狗了"）、**农业高标（"大米"）**（本该掉下去死，却反弹新高）。
- **末日轮反弹有时是逃命机会**（有的给末日轮反弹让你跑），有的根本没有（三而竭后直接连续地板）。
- **位置判别法**：
```text
IF 一个板块/高标已走到第三波 THEN 之前没参与就干脆不参与（"赌第四波基本是赌上头了"）
IF 参与 THEN 只在第一波、第二波参与；行情是走出来的，不是规划出来的
IF 要判断当下指数/板块能不能做 THEN 至少要确认：它不在末日轮，且没走完三而竭
```

### 2.3 打破常规：开启新周期的两个必要条件 `[核心]`

```text
IF 三波走完后想再走一波 THEN 必须同时满足：
  ① 有强驱动的重大变化（基本面质变，如 AI 产业链供给出政策/需求驱动）
  ② 有足够时间完成筹码交换（中间必须有一段消化期）
IF 三波走完没多久就接着上第四波 AND 无强驱动 THEN = 末日轮（不是新周期）
```
- 实例：AI 情绪股"剑桥"（2023 他就在玩，一直到 2026），三波之后歇一段，靠 AI 产业链驱动又开启新三波。
- 实操提醒：真出现新周期时，人们往往**忽略前面的行情、从中间重新开始数浪**——要回到完整图形上看位置。
- **科技/AI 走完三浪后的两种收场方式**（他对当下的判断）：
```text
IF 没有更劲爆的东西把 AI 宏大叙事续下去 THEN 按流程走：A浪下跌 → B浪反弹 → C浪阴跌
IF 想再来 THEN 要么用空间换（把 C 浪跌完）→ 要么用时间换（横半年到两年，妖股还两三年的债都有）
IF 你是冲短期逻辑去的 THEN 就按短期逻辑走，不要"短期变长期"
```

### 2.4 短线必备洞察力：灵魂板块 + 灵魂个股 `[核心][可观察]`

```text
灵魂板块 = 决定整个市场情绪的 1-2 个板块：它涨能把市场捞起来、让上涨家数/涨停数增多
灵魂个股 = 该板块里 1-几个核心票（每个阶段不一样，要持续更新）
```
**筛选标准**：
```text
IF 找灵魂板块 THEN 必须找**有容量**的（它能出涨停潮、对指数和上涨家数贡献大）
  容量太小的板块（传媒、农业、黄酒）即使涨停潮也影响不了全市场 → PASS
  例外：IF 大容量板块全都走不出行情（如不是牛市时） THEN 才看小容量
IF 判断灵魂个股 THEN 看"对它接下来的走势影响事关重大/这波上涨由谁做出主要贡献"
```
**实例（他现场测验观众）**：
- 9 月这波反弹的灵魂板块 = **元件（电子元件）**，其次**药**；光模块这波"没有太亮眼的表现"（说光模块≈没做短线）；农业、旅游酒店、传媒都不算。
- 美股灵魂个股的**轮换史**：英伟达（很长一段时间）→ 谷歌（某段）→ 存储系（美光那批）→ **本波是 Meta（Facebook）+ 某半导体**（Meta 的自动处理邮件新应用上线，炒"应用实际落地"）。
- 他对该应用的定性：**不算能引领多年的产业趋势**——"我们抄都不好抄"（它主要跑在网页端，国内全是移动端），对比"特斯拉新能源车好抄→走了几年新能源行情""ChatGPT 好抄→炒了几年"。
- **下跌日也要看灵魂**：9/28 大跌日，游资去挖了**汽车（整车）**和**风电**（"有一定体量"）→ 后续按流程观察它们处在第几波。
```text
IF 指数跌但仍有板块被资金点火 THEN 市场没死，把它列入观察池
IF 观察新板块 THEN 判断它处在一鼓作气（要信早信、先干为敬）/ 二浪分歧 / 三浪分歧转一致 / 五浪 的哪一段
```

### 2.5 游资点火的真实运作方式（破除"庄家神话"）`[重要]`

```text
游资是市场里洞察力、敏锐度最强的一批人，最喜欢"写新研究"（挖新东西）
  旧题材（元件、药）玩烂了 → 就去挖新题材点火
运作：点火 → 有人跟/有人接力 → 就格局、继续加仓干；没人跟 → 第二天反手砸
现实里绝大多数资金在拉一只票时**心里都没底**，只能根据市场情绪估个胜率
（"精准把一只票从几块炒到多少块再离场"的只占极少数，那是市值管理，不是常态）
IF 你做短线题材 THEN 别追求确定性，一边走一边试："打一枪看看情况，好就留，不好就走"
```

### 2.6 消息 vs 盘面：短线不要靠消息 `[核心]`

```text
消息是为行情服务的：涨了自然能找出消息（"某某板块历史大涨，原因竟然是它"）
技术派第一假设：价格反映所有信息（公开的 + 未公开的）
IF 你等到有足够的消息和理由说服自己 THEN 往往刚好接到三而竭 / 末日轮
IF 做几天到一周的短线（快枪手级别） THEN 多看盘面、多复盘，少看消息
IF 做几周~几个月的产业趋势 THEN 才需要跟踪产业链信息（例：光模块这俩月不行 = 海外产业链压制情绪）
IF 你全程不做一个题材 THEN 游资割不到你，但你也赚不到这个钱——要么不做，要么早做
```

### 2.7 指数与板块的错位 `[核心][可观察]`

```text
典型场景：沪深300 跌穿阶段新低，但微盘股、上证50（中字头/三桶油）已经止跌反弹 = 错位
IF 短期看错位 THEN 中期（周K/月K 拉出来）大多会**共振**（补跌或补涨，先后错开而已）
IF 长期不共振 THEN 只出现在牛熊转换/风格切换期：
   例：2021→2022 杀权重，沪深300 哗哗跌、中证2000 走震荡，因为主导资金从机构交棒给游资
```

**危险信号（他反复强调）**：
```text
IF 只有个别指数独亮、其他全跌（如今年 6 月只有科创/创业板打新高） THEN 极危险
  逻辑：把兄弟们吸干了、踩着兄弟们的尸体上去——"能走多远？"（6月底已验证一次）
IF 你产生"只有科创最亮、其他都得让路"的想法 THEN 这个想法本身就很危险
```

**操作含义**：
```text
上证50 / 沪深300 / 中字头（三桶油、移动电信）→ 当**信号**看，不要当标的做
  理由：不带杠杆的话弹性太小，没多大操作意义
IF 50/300 守住了 THEN 去做有弹性的品种（中证500 / 1000 / 2000）
IF 50 守住 + 龙哥态度明确 THEN 再去市场里找被挖掘的新板块
```

### 2.8 板块错位的核心驱动 = 资金偏好（不是基本面）`[核心]`

```text
IF 是增量行情（2万亿~3万亿） THEN 资金干最热的（还是去干科技）
IF 是存量/缩量行情（现在没钱） THEN 资金只能"借着偏锋"：去找**筹码少、机构少**的板块点火
  实例：整车、风电（都跌了很久很惨，好拉）、地产（基本面没有本质改善，只是减缓下跌，照样有人点）
  原因：机构多的板块你一点火，机构反手砸给你——白点
IF 判断板块错位的方向 THEN 核心看资金偏好，跟基本面有时没太大关系
```

**他的个人取舍（重申并细化）**：
```text
基本面决定做不做，技术面决定什么时候做（技术面不只是 K 线，还包括情绪）
IF 你很看好一个板块但一直跌、且里面一直没有高标、没有游资点火 THEN 短线不做
IF 一个板块很久没涨停 THEN 短线层面已被资金抛弃
长线两种做法：右侧（等游资拉涨停/机构拉权重）或左侧（越跌越买）
IF 左侧做板块指数 THEN 必须控制仓位：
   "不是所有指数都是红利，也不是所有股市都是美股"——仓位分配往往是决定身份的关键
   轻仓套 20% 和重仓套 20% 完全不同（心态承受能力 + 有无回旋余地：轻仓还能做 T、博段降成本）
IF 做板块指数 THEN 最好等右侧走出来再做（他等港股做双底，"要把自己宝贵的仓位花在刀尖上"）
```

### 2.9 龙哥三板斧的细化出手顺序 + 控跌速 `[核心]`（强化 03-rules 12.2 / 四十一章）

```text
龙哥三板斧（本场讲得最完整的一次）：
  ① 先买中字头：三桶油、移动电信、（电力/煤炭类中字头）
  ② 再买金融：银行/保险/证券里挑一两个
  ③ 再买宽基 ETF，顺序：上证50 → 沪深300 → 中证500 → 中证1000 → 科创/创业板
  ④ 还不得劲 → 发利好（盘后利好）
  ⑤ 实在不行 → 强力护盘（如去年关税那次；今年已三个月没用强力护盘，靠①-④这套流程把火续上）
IF 这一套流程走完仍护不住 THEN 才谈失守
```
**控跌速 = 情绪管理**（这是他讲"龙哥为什么要守 3800"的答案）：
```text
同样是上证一个月跌 5%：
  两天跌完 5% → 第二个月不一定止得住血
  一天跌一点、反弹一点、再跌一点，慢慢跌一个月 → 第二个月就不见得继续跌
IF 跌多了 THEN 老乡别走，发点镇静剂 → 牛回速归 → 嗨完再降温 → 慢牛走得更久
"守 3800"不是守点位（之前已数次刺破到 3700 多），而是在这个位置**提供流动性和信心**
```

### 2.10 胜率上限与交易模式 `[核心]`（强化 03-rules 19.3）

```text
IF 再有把握 THEN 只能说到九成，永远留一成 = "人算不如天算" → 必须对市场有敬畏之心
IF 你自称十成把握 THEN 就是没有敬畏之心
开仓节奏：第一天仓位轻 → 出现末日轮（验证点兑现）→ 加到正常仓 → 把握 7 成 → 9 成
胜率不是越高越好，取决于交易模式：
  他：开仓少、次数少 → 8 月做多赚一波、9 月做空赚一波，两个月看胜率 100%（因为次数少）
  量化：一天操作一两千只票，胜率 50% 也能赚 → 靠赔率（亏 3-5 个点，赚 10 多个点）
IF 你看到"职业/机构胜率一定很高" THEN 是误解，都是看模式
```

## 三、信号的两副面孔：趋势指标 vs 震荡指标（本场方法论精华）`[核心][可计算]`

**一句话：同一个信号，在不同市场环境下含义可以完全相反。先看环境决定"顺势用"还是"反着用"，再看信号本身。**

| 信号 | 趋势环境（有向上驱动、有钱、宏观宽松） | 震荡环境（被压制、没钱、宏观紧缩） |
|---|---|---|
| **指数共振**（上证涨2%、创业板涨3%） | 开启单边上涨的标配（"摔杯"） | **加速见顶**（拉小票半个月后 50/300 突然补涨 = 阶段顶） |
| **放量** | 好信号，开启单边 | 见顶（24年10月8日天量 3 万亿 = 坏；9·24 前一两万亿放量 = 好） |
| **中期买盘 >2%（到 3-4%）** | 该往上看 | 已短期超买，环境不允许 → 不往上看（6 月典型） |
| **基差（IF/沪深300，看加权）** | 牛市应为负数或个位数（近两年只遇到过两三次） | 变成**超买超卖指标**：越大越涨、空头越加，加到极限后一路向下；跌完空头平仓基差自然缩小（6月 200-300 → 9/28 为 114） |
| **涨停破百** | 情绪好，可跟 | **阶段情绪高点**（上周接近破百，干进去就是阶段高点） |
| **跌停 40+ 家 + 创业板 -4% + 上证 -2%** | 继续看跌 | 反而**短期超卖** → 可博反弹（9/28 当日） |

```text
判别方法（他给的答案）：看宏观——经济预期（增长 vs 负增长）+ 货币宽松还是紧缩
IF 趋势环境 THEN 顺势用：上证涨两个点 = 还要继续涨
IF 震荡环境 THEN 反着用：上证涨两个点 = 阶段见顶；上证跌两个点 = 阶段见底
IF 判断不了环境 THEN 先用宏观（经济+货币）定环境，再定信号的用法
单指标绝不能脱离环境使用——"单个指标的使用一定要结合当下的环境"
```
- 补充：他说趋势指标"用成了超买超卖指标"（中期买盘像 KDJ、基差像超买超卖），本质是**因为这一轮不是标准牛市**——"15 年以后就没有标准牛市，只有短暂的标准牛市，大家生不逢时"。
